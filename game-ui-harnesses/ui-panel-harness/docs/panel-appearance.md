# 自定义样式与布局编辑

编辑现有modern-v3面板时，可以指定实际面板/画布背景、控件底色、强调色、普通文字、次级文字、边框、按钮底色和按钮文字，以及面板、设置行/输入/下拉、按钮的统一圆角。布局继续使用已有的完整 `set-layout`，支持内边距、行/组/容器间距、宽度、高度上限与滚动；画布和控件可读尺寸限制仍生效。

例如：

> 面板背景改成#006400，普通文字白色，按钮背景#FFD166、文字#17352B，面板圆角24、按钮圆角20。内边距16、行间距8。保留控件、行为和当前输入。

> 只把按钮改成紫色，文字白色，其他保持不变。

> 清除全部自定义颜色和圆角，恢复当前目录主题的默认外观，保留当前布局和试玩值。

“绿色主题”选择绿色预设；“面板背景绿色”修改实际面板背景。已经相同的预设不会伪装成一次有效修改。

## 数据与兼容

新的 [EditContext 0.2](../schemas/panel-edit-context-v0.2.schema.json) 提供 `set-appearance`，每次修改须绑定当前需求的准确引文。该操作给出完整 `appearance` 对象，未指定字段为 `null`，表示继承固定目录主题；已有的未提及覆盖值须保留。`appearance:null` 清除全部覆盖。

第一次应用时把Spec 0.7升为 [Spec 0.8](../schemas/panel-spec-v0.8.schema.json)，使用Bundle 0.8和编译器0.8.0；不替换目录、不创建伪主题条目。旧Context 0.1保留摘要与能力，不能接受新操作；旧Bundle依原编译器重放。生成仍使用Spec 0.7，生成后可以编辑样式。

| 字段 | 含义 |
| --- | --- |
| canvasColor / panelColor | 面板外画布 / 实际面板背景 |
| controlColor / accentColor | 设置行与输入底色 / 滑条、开关、进度等强调色 |
| textColor / mutedColor / borderColor | 普通文字 / 次级标题 / 常规边框 |
| buttonColor / buttonTextColor | 全部按钮的底色 / 文字色 |
| panelRadius / controlRadius / buttonRadius | 面板 / 设置行、输入、下拉 / 按钮统一圆角 |

颜色只接受不透明 `#RRGGBB`；圆角是0..128整数，0为直角。显式改变按钮底色且没有按钮文字覆盖时，自动选择黑/白文字。指定面板背景或圆角时暂停绘制原纹理面板，资产和字节保留，清除这两个覆盖字段可恢复纹理。

预设主题切换默认保留自定义覆盖；明确要求恢复完整预设样式才清除。不同自定义样式的面板暂不能直接合成，组合器返回 `COMPOSITION_APPEARANCE`，避免静默丢弃样式。

## 范围与验证

Select弹出选项与Tabs头保持原生可读调色板。滑块、开关胶囊和进度条仍使用原生形状。四角独立圆角、透明度、渐变、字体更换与自定义动画尚不支持；整条需求含不支持项时要求澄清，不能只应用其中一部分。

样式和布局经同一原子校验、编译、呈现后提交，保留存活试玩值，可整批撤销。多项修改合计一轮，仍受每面板十轮限制；撤销和重开不退还轮次。

确定性测试覆盖编译节点、Unity导出文档、纹理恢复、旧包重放、引用证据、失败回滚、状态与轮次。浏览器夹具应用三批修改，澄清一条不支持请求，并检查撤销、刷新和真实下载。夹具不替代真实模型成功率，Unity原生编辑器验证单独记录。
