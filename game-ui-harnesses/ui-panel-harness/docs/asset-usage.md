# 按控件用途选图

`restrained-v1` 提供逐控件的默认选材建议，补充整段需求检索。
它不会改变 `lexical-v1` 排名协议、候选集合、PanelSpec 或编译器版本。
`recommendPanelIcons(spec, requestText, retrieval)` 验证规格与绑定的检索快照，返回 `ADVISORY_ONLY` 报告；
每行记录当前选择、建议的精确资源键或 `null`、匹配词和理由。
程序不会用建议悄悄替换 Agent 方案、用户指定的素材或已保存面板。

## 默认规则

- 只用当前 `row-icon` 候选。按控件可见标签匹配；按钮用 `buttonLabel`。
  ID、事件名、默认值和无关正文不构成图标用途。
- 菜单可用用途明确的图标。表单、弹窗及混合设置面板的操作区默认保留文字；
  正文和进度条默认不加装饰，已有符号标签不再叠加外部图标。
- 以行覆盖数、相关度和固定排序选共同素材风格；同样相关的替代项优先采用共同变体。
  不为补齐数量使用含义较弱的图标。同一分区默认最多三个不同图标，不重复堆叠。
- 同分不同含义且匹配词同样具体时保留文字；分数相同而匹配词更完整时优先更具体的词。
  例如“返回主菜单”优先主菜单图标，而不是仅匹配“返回”。
- 同组菜单任一项没有合适图标时，整组默认文字化，避免部分带图标导致按钮边缘不齐。
  没有资源可用属于正常文字回退，不把可选装饰缺失变成澄清问题。
- 显式同组按钮排列遵守现有外部行图标限制，不能为配图改变业务布局。

用户明确选择优先于默认建议，但仍必须符合公开协议；明确要求的素材不可用时需要具体澄清。
普通编辑保留已有精确素材引用，仅随已授权删除行移除相应引用。
生成与编辑的 Codex 提示共用 `iconUsageGuide()`；编辑指南不增加补丁操作权限。
这些是提示与程序建议，不是能证明任意模型选材正确的语义门禁。

图像仍走已有 24/28 逻辑像素 `contain` 槽位、主题徽章和间距，PNG 不染色。
本轮不修改旧编译器，不改变旧包的渲染或身份摘要。

## 本地验证

```sh
node --test tests/asset-usage.test.mjs tests/asset-retrieval.test.mjs tests/codex-planner.test.mjs
node scripts/check-asset-usage-browser.mjs --output output/my-asset-usage-review
```

浏览器程序使用随源码提供的核心图库，无需 Sharp。
六类程序夹具为声音设置、角色命名、删除确认、暂停菜单、主菜单和资源加载，各有浅/深色版本。
左侧为程序控件基线，右侧按默认建议选择素材；本页不是模型输出或旧真实面板的修改前后记录。
页面显示每行建议理由，可交互并下载真实交付 ZIP。

检查包含图标实际挂载、尺寸/间距/对齐、菜单按钮边缘、滑条/开关/重置、表单提交、菜单/弹窗点击、
宿主进度更新、390 宽度溢出、实际下载校验、无图库重导入和解包后的离线打开。
业务字段、默认值、动作、绑定及原布局声明必须保持一致；Unity 适配包生成，原生编辑器为 `NOT_RUN`。
夹具及模拟 CLI 不提交模型请求。固定请求的四份真实结果和实际下载验证已完成，见[真实验收结论](asset-usage-real-acceptance-2026-10-09.md)；后续新真实调用仍须冻结计划并取得新的单次授权。
