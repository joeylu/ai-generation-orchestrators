# 同类内容共用分组底板

新生成默认目录为 `modern-readable-game-section-panels`，主题0.28.0／0.28.1、Compiler 0.41.0。Studio与安装SDK共用默认。新增 `sectionSurface:panel-v1`，由已有语义section生成真实非交互Panel，将同类内容的标题、行标签、数值和控件放在同一底板中，例如音频组包含主音量、音乐音量、Slider和静音Switch；画面组单独包含画质Select和全屏Switch。分组并非依据文本距离猜测，也不逐控件套卡片。

内容底板使用主题control底色、border边框、12逻辑像素圆角与四周12逻辑像素内边距，分组间距保持20。组内可见小标题采用同一底板上的Text，不再单独叠加标题小框；主标题仍保留独立Panel及8像素留白。控件轨道与完整文字在减去分组内边距的空间重新测量，自动估宽计入内边距，短设置默认仍可保持420宽。正文与按钮24、主标题32及64按钮高度继续保持，明确尺寸和字体优先，不缩字掩盖越界。

包含Slider、Switch、Select、Input、图片、选择列表或其他非Text／Button内容的语义分组采用底板。纯按钮菜单、独立操作区和纯Text／Button确认正文保持简洁。既有v5标题显隐规则保持：不恢复冗余标题，不增加装饰Text，不因标题隐藏而去掉仍有内容的分组。分组底板不会成为操作按钮或新增状态字段；业务事件、状态、绑定和素材保持原合同。

本次分组规则来自用户对游戏布局的明确要求。ui-ux-pro-max搜索未找到直接适配的分组条目，未将无关结果作为设计来源；仅参考已核实的控件间距、对比度和文字完整性建议。运行时不加载skill。渲染验收使用本机Playwright／Edge，Browser plugin not available。
