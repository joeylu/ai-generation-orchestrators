# 通用图层父级规范 v1

父级表示显示职责，主题决定子层和素材内容。森林、雪山、沙漠、洞穴共用这套词汇，
不把古城、谷地、松树等样例主体写成所有项目的固定父级，也不强制每个项目都有五类。

| 父级角色 | 界面名称 | 内容举例 | 约束 |
| --- | --- | --- | --- |
| foreground | 前景 | 近处岩块、枝叶、遮挡 | 视觉前层，不因所属分组获得碰撞 |
| main | 平台 · 地形 / 环境 | 画刷格子、曲线、实体平台；同平面的树、拱门和摆件 | 碰撞由原地形和组合决定 |
| middle | 中景 | 近处树组、残墙、场景建筑 | 位于主场景之后，可有多张实际渲染层 |
| far | 远景 | 远山、城堡、森林、低处景观 | 按实际层次/视差拆子层，主体不固定 |
| background | 背景 | 天空、洞穴底色、远处背景底板 | 无需一定生成天空 |

编辑器按职责展示「前景→平台→中景→远景→背景」。这是父级词汇，
不是固定五张图片、固定素材数量、固定高度或一套所有风格都必须套用的构图。
同一父级可含多个真实图层，以分别控制视差、遮挡、显隐与锁定。

## 命名与项目继承

平台下分「地形」和「环境」。地形包含画刷、曲线、带地形格子的组合和带平台外壳
的实例。「画刷地形」入口显示作者格子数量，零格时仍可点击开始绘制。环境包含
主场景中可单独选择的摆件。其余同组子层使用「远景 1、远景 2」等中性名称，
具体对象使用项目素材名。没有放置对象的非地形层集中在默认折叠的「空图层」。

空白项目尚无资产和作者文档，不预置古城/谷地。复制项目会复制它的素材和图层；
在同一资产包内新建空白地图会保留该包图层定义，清除摆放/地形内容；导入另一个
包采用另一个包的实际定义。图层规范不会替新主题凭空补出某类主体。

素材显示名应随项目资产定义。当前旧样例仍有素材ID的显示别名，只有对应素材存在
才出现；它们不是通用父级规则，也不是对图片内容的自动识别。后续更完整的资产显示名
合同应单独版本化，不能依靠前端按雪山/森林/沙漠猜名称。

## 已落实的编辑器兼容行为

视图分组根据现有图层计算。浏览时沿用原 `layerId`、`kind`、`zIndex`、
`parallax` 和渲染顺序。
组合的平台外壳仍绑定其已验证的原层，主场景分组不会把普通装饰变成碰撞平台。

Studio 生成的普通环境素材可记录 `placementRole`，由用户选择的生成分组决定。它属于
素材目录，用于库内归类和默认放置。地图缺少对应图层时，首次放置会同时创建视觉图层，
保持原图层的相对顺序。新增图层和摆放可在同一步撤销。

历史包先用明确旧ID兼容映射，再根据 `kind`、实际放置的地形资产和视差作中性归类。
未识别环境层的横向视差≤0.4归远景、其余不足1归中景、单位平面归主场景；这是旧包
缺少父级角色字段时的显示回退，不是图片语义测量或所有美术必须遵守的硬视差值。

同一显示职责汇总到同一个文件夹，文件夹内按原图层前后次序排列。画布渲染仍以
作者图层的 `zIndex` 为准。

父级支持整体折叠、显隐和锁定。同一个作者层混放平台素材与摆件时，分别控制各自
的对象。部分子层隐藏或锁定时，父级显示混合状态。对象选择、双击定位、拖放和
地形操作沿用原层归属。显隐、锁定与折叠属于编辑器状态。

本次没有新增作者的显式父级字段，也没有修改已经冻结的参考/素材生成计划。后续若
让生成规划直接输出父级角色，需要版本化字段、编译/回放验证及新计划绑定；不能把
这轮编辑器分组当作生成器已经稳定提供显式父级元数据的证明。
