# 16 类组件动效审阅与接入

2026-10-15。调度器与基础 tokens 复用 `ui-component-harness/src/motion-system.ts`；Chain 的动作设计 2.0 集中在 `src/panel/motion-design.mjs`，由 `motion-profile.mjs` 合并基础 tokens，供组件库、面板预览和对照页共同使用。上轮补齐内部动作后，用户指出三套辨识度仍不足，因此本轮增加动作配方，不再只以小幅时长/缩放差别区分风格。上游文件和历史交付包未改写。

## 三套风格

| 风格 | 手感 | 入场 / 退场 | 值变化 / 滚动 | 使用规则 |
| --- | --- | --- | --- | --- |
| 轻快 | 中心弹出、明显按压、释放回弹 | 340 / 170 ms | 260 / 180 ms | 弹窗从 0.78 缩放弹入；按钮压至 0.90、释放峰值 1.08；条目错峰弹入。进度与滚动仍有界 |
| 精致 | 分层显现、柔和恢复，无整体缩放 | 420 / 240 ms | 300 / 220 ms | 弹窗遮罩先显现，底板随后、内容后显；Tabs 旧新页面交叉淡化，无位移 |
| 稳重 | 定向滑入、短促下沉、同步出现 | 200 / 140 ms | 170 / 160 ms | 弹窗横向 36 像素滑入；页签内容按方向横移 48；按钮下沉 3 像素，不缩放 |

不另建三份实现。`motion-design.mjs` 是本项目动作配方的唯一入口（含参数覆盖与配方类型），`motion-profile.mjs` 提供合并后的选择，`motion-runtime.mjs` 管根入场和 Button，`component-motion.mjs` 管控件内部通道。原样不附加动画；系统减少动态效果、页面隐藏、切换风格、编辑模式、禁用、销毁时收敛到确定状态。已有保存记录按稳定 style ID 解析当前设计，导出含 designVersion=2.0，不手改原保存记录。复制到外部的旧导出配置仍是其原版本。

## 逐组件设计

所有组件有初次展示/重播入场；以下为各自的内部动作，不再让整块 Select、Tabs 或列表反复缩放。

| 编号 | 组件 | 设计及实现 |
| --- | --- | --- |
| T01 | Button | 轻快压缩回弹；精致轻压柔和恢复；稳重下沉归位，松手恢复精确变换 |
| T02 | Switch | 滑块沿轨道缓动；标签不跟随缩放，逻辑值即时变化 |
| T03 | CheckBox | 标记渐显/渐隐与缩放；轻快弹性缩放、精致淡化、稳重短距滑入 |
| T04 | RadioGroup | 旧选中标记退出、新标记进入；保留实际选项位置与键盘选择 |
| T05 | Input | 保留原生文字编辑；不附加金色焦点框或文字/光标缩放 |
| T06 | Select | 三套均有界裁切；轻快条目错峰弹入且箭头轻回弹，精致条目错峰渐显，稳重条目同步短距滑入。收起反向缓动，不压扁文字；条目按压共享按钮风格 |
| T07 | Slider | 键盘/程序赋值时填充与滑块缓动；鼠标/触摸拖动直接跟手，滑块按压使用原皮肤状态与透明度反馈 |
| T08 | ProgressBar | 填充连续追踪最新目标；逻辑值及数值文字即时更新，动画不重复发值事件 |
| T09 | ScrollView | 滚轮/程序滚动有界缓动，内容和滑块同步；直接拖动不延迟，保留裁切及嵌套滚动归属 |
| T10 | List | 初次展示逐行错峰，选中行分别短距弹入/渐显/横移，条目按压；不缩放整张列表 |
| T11 | Dialog | 轻快中心缩放回弹、精致遮罩/底板/内容分层显现、稳重横向滑入。关闭反向退出；动画结束才释放遮罩，逻辑关闭和 closed 事件不延后 |
| T12 | Tabs | 轻快内容短距弹入、精致旧新页交叉淡化、稳重按切换方向左右滑动；双层底板保持稳定。交叉淡化旧页 eventMode=none，结束恢复隐藏，快速切页按当前 active 收敛 |
| T13 | Image | 淡入和短位移，不挤压图片；没有凭空添加点击语义 |
| T14 | Text | 淡入和短位移，保持文字比例；没有打字机或字体缩放 |
| T15 | Container | 整体入场并对子项错峰；保持透明，仅做布局分组 |
| T16 | Panel | 整体入场及直接内容错峰，底板与布局尺寸不被动画改写 |

## 状态与维护边界

- Select 与 Dialog 通过运行时 `motionDriver` 接口连接呈现层，原样模式仍走即时开关。关闭中的 Select 不再接收条目/滚轮输入；Dialog 不接受重复动作，模态遮罩保留到退场结束。重新打开替换同一通道并从当前值接续，不排队播放过期动画。
- 动画只写呈现参数，不更新作者 JSON，不为动画增加 valueChange/closed 等业务事件；Slider/ProgressBar 的实际值与视觉插值分开。
- 双层 Tabs、安全区、文本字色、九宫格和自动排版继续由原实现负责；调尺寸时先收敛动画再计算新几何。
- 列表错峰最多覆盖前 24 项，延迟上限 350 ms。不要因长列表把整个页面拖入数秒等待。
- 普通 Image/Text/Panel/Container 没有业务关闭动作，当前不把 `dispose()` 或任意 `setVisible(false)` 偷换为延迟删除。退场生命周期在实际有开关语义的 Select/Dialog 中实现。
- 新组件包及后续用新代码构建的面板具有内部动效接口；历史冻结面板包不会被原地替换，旧包只能使用其已有接口支持的动效。不要把 Studio 控制器更新等同于所有历史面板 runtime 已升级。
- 资产包仍无需增加图片。组件项目动效与面板动效独立保存，升级运行时保留用户已选风格。

## 验证

`tests/runtime/motion.test.mjs` 使用真实 PixiUI 与可控时钟，覆盖三套风格、全部 16 类根及组合子项、内部过渡的中间帧、反向重开、单次 closed 事件、模态遮罩释放、无拖动滞后、原样/减少动态效果/调尺寸/销毁恢复。配合既有 64 项组件检查、动效保存 Node 测试和 Studio 鼠标/移动尺寸回归。所有测试均离线，不调用生成模型。

2.0 追加相同归一化时间点的结构差异断言：缩放/横移/分层 alpha、Select 条目错峰与同步、Tabs 位移方向及旧页输入隔离、Button 下沉；确保不只是三套速度不同。临时“三套动效对照”入口已按用户要求从组件画布移除，日常使用现有动效选择和重播。对照页仅供开发回归，保留全部 16 类同步演示及直接试玩能力，不保存项目选择。维护检查 `scripts/studio-motion-compare-check.mjs <已验证 consumer 工作目录> [仓库外证据目录]`。旧冻结面板缺少内部接口时，界面明确提示需升级运行时，仍保留其已支持的根入场/按钮动效。

2.1：对照选项来自实际 cases，演示动作集中在 motion-demos.mjs。Switch/Slider/ProgressBar/ScrollView 的值过渡保持有界，三套分别使用 ease-out/ease-in-out/linear；直接拖动即时响应。Input 保留原生文字编辑，不附加焦点框（以执行文档 12.124 为准）。静态 Text/Image/Container 轻快短移回弹、精致渐显、稳重短滑，始终保持比例。窗口变化继续定位所选控件，切换恢复初始试玩状态。
