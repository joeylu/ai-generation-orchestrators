# 采用回答后直接提交

本地模型入口可用时，澄清按钮显示「采用回答并生成」或「采用回答并修改」。用户填写或点选全部答案后，
点击一次即可合并原需求和补充答案，复用原生成/修改流程提交一次。无需复制答案或再点击主按钮。
推荐项仍不预选，点选只填写；回答不完整、旧问题失效时不发送。模型再次追问后等待下一次用户提交，
失败不自动重试。版本核对、取消、范围保护、试玩值保留与最多10轮成功修改继续由原流程处理。

离线或模型入口不可用时，按钮保持「采用回答」，只合并文字，供手动准备及导出上下文。
不更改公共协议、存档格式、导出包或模型配置。测试全部使用程序替身，不消耗真实调用授权。
