## 目录职责

- 本 Harness 负责“场景意图 → 参考图 → 模块库 → 默认地图 → 可验证资产包”的产品链路。
- 通用资产包与 Pixi 消费适配分离；自带本地 Studio，目标项目仍负责自己的资源准备和集成。
- 不依赖兄弟 Harness 的 planned 能力，不复制其他项目的整份源码。
- 不包含角色、敌人、拾取物、独立交互道具、完整玩法或物理引擎。
- 私人输入、生成结果、计算记录和交付保存在仓库忽略的 `.local/`，历史试验保存在 `work/`。

本地 Studio 使用根 `AGENTS.md` 对本目录的明确范围，不包含部署、账号、数据库或
生成服务。画布工程验收与真实图片生成、人工美术接受分别记录。
