# Scene Kit 本地 Studio v1

本地画布始于 0.3.0，当前源码 0.55.0。启用项目工作区后从项目页进入/editor；项目与多地图见[本机项目](studio-projects.md)，图层父级见[通用规范](layer-parent-standard-v1.md)，地形共存见[分层规则](layered-terrain-v1.md)，当前交互以[画布编辑工作台](canvas-editor-v1.md)为准；
下文保留早期工程流程和宿主合同，旧属性面板与导航位置已迁入画布浮层。仅在本机编辑已验证的场景包，默认打开合成夹具；不调用模型，所有结果
保持 `visualAcceptance: not-assessed`。完整路线以 [执行文档](execution-plan.md) 为准。

## 启动

从本 Harness 目录执行，Node >= 22.18.0：

```powershell
npm ci --ignore-scripts
npm run studio
```

终端输出实际回环 URL，默认 `http://127.0.0.1:4176`。仅监听 127.0.0.1，不接受 LAN
监听配置。Ctrl+C 关闭。第一次安装使用公开 npm registry；工作台及测试本身不请求
外网素材。PixiJS 8.20.1、pixi-viewport 6.0.3、esbuild 0.25.12、Playwright 1.63.0
均固定版本，传递依赖和完整性由 `package-lock.json` 固定。

```powershell
# 构建静态前端（不是脱离宿主即可编辑的独立网站）：
npm run studio:build
# 启动时显式选择本地 kit 或端口；HTTP 请求不能选择文件路径：
npm run studio -- --kit ./tests/fixtures/synthetic --port 4177
# 启动时读取已验证的作者地图；v1—v5 均可，HTTP 不接受文件路径：
npm run studio -- --map ../../work/my-map.scene.json --port 4178
```

`dist/studio` 和 `node_modules` 被仓库忽略。开发环境可使用重复的
`--dependencies PACKAGE_ROOT` 显式复用已安装的依赖，但每个包必须匹配声明的版本。
常规安装和运行不依赖其他 Harness 或消费项目的目录。

## 固定项目编辑器版本

使用 `pwsh -NoProfile -File scripts/start-studio.ps1` 从本机配置启动完整项目。
[配置与本机目录](local-workspace.md)保存完整 Git 提交。把 `--release-commit FULL_SHA`
加到 Studio 启动命令，程序会在构建前核对实际 HEAD、Scene Kit 和可选适配器源码。
项目目录、风格和交换目录按
[环境素材与动画](environment-library.md) 在启动时配置。

复用端口时，先查 `GET /api/studio-version`。项目编辑要求
`releaseCommit` 等于启动器固定的值且 `mode` 为 `project`。未固定的 Studio
报告 `releaseCommit: null`。再核对 `/api/state` 的项目与素材风格和
`/api/environment-animation/generation` 的工作进程状态。检查失败时不要把该端口当作
当前项目交给用户。升级时显式改启动器的提交值，并从对应的干净工作树启动。

## 连续材质试样外观

0.8.0 增加启动参数 `--terrain-config LOCAL_JSON`。这是宿主启动时的显式本地配置，
不通过 HTTP 选择文件；没有配置时保留原合成画布。配置保存在私有工作目录，路径
相对于该 JSON 的目录解析，准确字段为：

```json
{
  "format": "ai_scene_terrain_preview_config_v1",
  "workflowRoot": "../my-scene-workflow",
  "materialPlanSha256": "MATERIAL_PLAN_SHA256",
  "originalRoot": "proof",
  "revisionRoot": "proof-v2",
  "studyRoot": "proof-continuous"
}
```

将占位摘要替换为实际材料计划摘要。`studyRoot` 必须是已构建的连续取样试样包，
不是任意 PNG 目录。启动命令（配置文件须已存在）：

```powershell
npm run studio -- --terrain-config ../../work/my-terrain/preview.json --port 4177
```

`loadTerrainStudyPreview` 从当前工作区重验材料源已接受、结构/画风仍有效、v1/v2
父包和连续取样包全部字节。失败即拒绝启动。成功后保留不可变的 752 张拼接片快照，
HTTP 只从固定允许列表提供这些字节；原图、工作区文件、配置路径、授权及尝试不提供给
浏览器。仅支持 64×64/1:1、锚点/偏移为零的地形；其他配置明确拒绝。

画布的“地形外观”可切换工程夹具与连续材质试样。试样默认开启；地形缩略图展示
角色形状，实际格子按完整邻域和世界格坐标正模 4 选片，摄像机和扩建不重排纹理。
环境/背景仍使用基础 kit 的工程标记，界面明确标注。外观切换是编辑器状态，不改变
布局、选择、镜头、地图修订、碰撞建议或撤销记录；载图失败保留原外观及地图，可由
用户再次选择来恢复。不会调用图片工具。

**保存地图仅保存布局**。JSON 保留基础 kit/rules 引用；“下载编译场景”和 CLI 的
目录导出也保留基础 kit，不能冒充已经包含试样。重新打开布局时仍须显式配置同一
来源外观。正式美术 kit、可携带的外观交付合同和目标项目安装继续后置。
原材料已接受与派生模块未评审分别显示；四格纹理周期仍存在。

## 编辑流程

0.9.0 的“曲线 C”提供丘陵、谷地、缓坡模板和控制点/切线编辑，操作与精确格式见
[曲线原型合同](curves-v1.md)。新增小样会一次扩建 16 列、显式升级为 v2 并添加曲线；
一次撤销可恢复。拖动期间仅为临时预览，释放提交，非法形状整次拒绝。曲线与格子
首版保持水平区间分离；曲线碰撞建议不等于已有物理运动或行走验证。

0.10.0 可以拖动一条曲线的端点靠近另一条曲线的相反端，出现吸附提示后松手，合并
成一条地面及一个共享点。已有近邻端点也可选中后点“合并附近端点”。一次撤销恢复
原两条；只点选、打开和缩放不合并。封底、材质、长度或形状冲突会整次拒绝。
合并范围及数据合同见上述曲线文档，不扩展为曲线/格子混接或 T 形分叉。

0.11.0 的 [混合地形](mixed-terrain-v1.md) 支持矩形格子平台接曲线：选端点后点击
“连接附近格子平台”，或拖近接头松手。新地图显式升级 v3，保留格子数据；材质及
碰撞建议由同一条链编译。“添加混合地形小样”可直接添加双侧平台和曲线，一次撤销
恢复。已连接的端点/封底锁定；平台变形前先解除连接。普通未连接区域按原规则编辑。

1. 默认地图包含 64×9 格、99 个地形节点、4 个环境视觉节点和一个组合实例。它是
   四屏宽的合成布局，可通过底部导航、全图、默认镜头和缩放按钮浏览。
2. 画刷 B / 擦除 E：左键按住绘制，稀疏指针事件补齐中间格子；释放提交一次原子命令，
   一次撤销恢复整条笔划。Esc、失焦、指针取消、丢失捕获丢弃未提交内容。过长笔划
   明确取消。越过地图边界由核心拒绝整次笔划，不隐式扩建或只保留其中一段。
3. 地形缩略图是 47 种角色的工程图示；点选后进入家族画刷，最终图片仍由邻接规则
   决定，不表示强制刷下该张缩略图。
4. 环境 / 组合库：选中后点击画布，或填写“精确放置”的列/行。组合重叠和越界
   均整体拒绝。组合内部地形须先展开才能刷改；展开保持外观数据及碰撞建议。
5. 选择 V：点击环境实例后拖动，或在实例列表中选中并编辑 X/Y；列表会跳转镜头。
   可复制、删除环境实例与组合。组合采用其声明的网格占地，环境位置使用逻辑单位。
   首版组合没有拖动/坐标移动工具，可删除重放或展开后编辑。
6. 平移 H 或中/右键拖动、滚轮缩放；纯预览只浏览并开启声明的视差，禁止修改。
   网格、碰撞建议、图层显隐、选择与当前相机属于编辑器状态，不改作者地图。
7. 向右扩建一屏会增加 `ceil(defaultCamera.viewport.width / grid.width)` 列；保留原点
   和所有旧实例坐标。它改变边界，不自动填充新增地面。
8. 保存地图触发浏览器 JSON 下载。打开地图使用用户选择的 JSON，先完整校验，再
   替换当前文档并清空历史；拒绝的导入保留原文档和历史。有未保存修改时先提示。
   下载动作不等于浏览器已经写盘，界面显示“已请求保存”。

Ctrl+Z / Ctrl+Shift+Z 支持地图撤销重做；字段内保留原生文本撤销。Ctrl+S 保存作者
地图。窄屏将模块库和属性移到画布下方；首版以桌面编辑为主，不声明移动多指操作完备。

“下载编译场景”供技术检查，不能代替作者数据。含原 PNG 与完整依赖的便携目录包
继续使用 [scene export/verify-export](authoring-v1.md)；浏览器不开放任意目录写入。

## 宿主与数据边界

本地宿主复用 `loadSceneKit/createEditor/compileMap`，启动时一次校验并保留 kit 字节
快照；可额外配置上述已验证的地形外观快照。图片仅从固定允许列表提供。GET/POST 路由固定，不接收请求提供的文件系统
路径、程序、提供商地址或脚本。POST 要求同源、JSON 类型与精确字段；请求限 2 MiB，
修订前置条件不符返回 409。失败操作不改变作者数据、历史或修订。

一个宿主进程只有一个内存编辑器。多个标签共享该文档，修订号拒绝过期标签的提交；
首版不提供协作、自动合并、跨重启恢复或后台保存。关闭前应下载地图。既有原 kit、
原始默认地图和 PNG 始终不被 HTTP 编辑操作改写。

前端不复制拓扑或碰撞生成规则。所有成功编辑后全量编译，不声明局部更新、大地图
吞吐或纹理内存上限实测。CSP 允许 Pixi 着色器所需的本地动态代码；没有远程脚本。
纹理最近邻采样可观察图块边界，但不能证明未来真实美术在任意缩放下无采样缝。

## 离线验证

```powershell
npm test
npm run fixtures:check
# 已安装的 Playwright Chromium 可直接用默认配置；也可显式选择本机 Edge：
$env:SCENE_KIT_BROWSER_CHANNEL = 'msedge'
npm run test:browser
```

不自动下载浏览器。可选 `SCENE_KIT_SCREENSHOTS` 指向仓库外输出目录，保留桌面与窄屏
截图；默认不生成截图报告。浏览器测试使用软件 WebGL，拦截回环地址以外的请求。
本轮 Browser 插件未提供，使用 Playwright + 已安装的 Edge；视窗 1440、1024、390。

当前核心/宿主回归为 255 项通过；37 项浏览器通过记录来自画布未变的 0.11.0。
0.12.0—0.14.0 新增长材质场与环境源离线流程，未接入画布或重跑浏览器。0.9.0 新增 17 项核心和
7 项浏览器曲线回归，具体见 [曲线合同](curves-v1.md) 与执行文档第 27 节。
0.8.0 的 5 项快照/按节点选片/启动配置/HTTP 边界用例，以及浏览器主流程与 6 个子用例仍通过，验证切换外观不改文档、
稀疏笔划一次撤销、扩建和镜头往返像素一致、三种缩放下若干连续接口没有背景间隙、
保存打开仍保留布局、窄屏不横溢，以及资源加载失败后的显式恢复。像素抽样不是所有
缩放/显卡的完整认证。测试仅使用合成来源，未将真实森林材料作为夹具。

浏览器视窗为 1440/1024/390，截图可保存在仓库外。既有锁定地形与无效导入各产生
一次预期 HTTP 422；新增失败页刻意阻断一张合成试样 PNG，界面保留工程外观，恢复
由用户选择触发。正常页无未解释的错误/警告、空白页或外网请求。构建、55 文件夹具
字节重放和默认地图合同校验通过；没有新增生图或 GPU 模型计算。

曲线测试另含一次预期的点顺序错误 422，保留作者及历史。浏览器启动失败时也清理
测试宿主；默认 Chromium 未安装时可显式选择已有 Edge，不自动下载安装浏览器。

0.10.0 新增 18 项核心连接回归、7 项浏览器连接回归。软件 WebGL 的浏览器测试文件
现在串行运行，避免多个含 752 张材质图的页面同时加载；原断言和超时门限不变。
并行全量时曾有三页 readiness 超时，串行全量 30 项通过；不据此声称并发性能已验证。

0.11.0 追加 20 项核心、7 项浏览器混合地形回归，串行全量 37 项通过。覆盖双侧接头、
统一表面/材质、三种缩放的接口像素抽样、锁定端点、解除/重连、四种取消、矩形变形

公开 Pixi 呈现入口及消费示例见 [Pixi 消费适配](pixi-consumer-v1.md)。本地浏览器通过

0.15.0 增加“游戏视口”选项。勾选后进入纯预览，画布按作者 defaultCamera.viewport
固定逻辑宽高，以留边适配面板，限制相机不越过地图边界，关闭滚轮缩放。可拖动、

远景的边界；固定视口不自动认证任意资产的覆盖或用户扩建后的地图。

夹限、滚轮锁定、桌面/390 窄屏、编辑镜头恢复以及作者/历史不变。核心/宿主全量
257 项通过。真实美术只用于私有人工组合预览，未进入测试夹具。

0.16.0 增加自包含候选 kit v2 与“下载场景资产包 ZIP”。位于右侧“当前文档”区域，
用户点击后只打包当前 revision 的作者、编译数据与配置 kit 的完整依赖；不写服务器
文件、不接受请求选择路径、不调用模型。与保存地图 JSON 不同，ZIP 同时包含 PNG
和 kit 自带曲线材质。外部试样模式会明确提示仍导出基础外观。

候选包默认含 752 地形相位，但库中只展示每个角色的 phase 0，共 47 缩略图；实际
画布由世界格自动选相位。材质直接来自 kit，不再需要 --terrain-config。地图仍可
画刷、预设、曲线/接头编辑及保存/撤销；全部曲线材质由相同消费适配器加载。
新增浏览器流程验证导出 ZIP 后严格重开、实际纹理、曲线编辑/撤销和窄屏；全量
39 项浏览器、261 项核心/宿主通过，另有系统 ZIP 解压与完整重编译的私有互操作证据。
