# 整块地形移动

源码0.53.0的确定性编辑命令；既有作者版本、素材、审阅和生成记录保持。

0.53.1的鼠标入口在松手后保留最后预览，等待唯一一次命令接收；正式场景同步
接替，拒收才清除预览。待接收外观不是已保存作者，释放后的失焦不取消已提交请求。

```json
{"type":"move-terrain","target":{"curveId":"hill"},"dx":64,"dy":-64}
```

命令严格只允许type、target、dx、dy。target只能有一项：`curveId`、`assemblyId`
或`cell: {x,y}`；引用当前作者内已存在的曲线、含地形组合或占用格子。dx/dy为
世界单位的有限整数，绝对值不超过1048576；含格子片时须为相应网格边长的倍数。

程序重新从当前作者确定移动片，客户端不能自行列出一部分格子绕过连接保护：

- 格子以四邻接连通；一个完整组合中的多块格子属于同一移动组。
- 显式terrainConnections把曲线与格子片连起来，移动整个连通组。
- 完整组合保留包装和内部装饰；已展开的直接terrainSkin外壳随附着格子移动。
- 控制点、封底、连接格子、相关检查点统一平移；普通独立环境素材保持原位。

移动、合并各来源和完整几何校验发生在一个草稿事务内。冲突、越界、曲线水平域、
连接矩形或平台外壳隔离等任一既有检查不通过，整次回退，保留原作者及撤销/重做。
不扩建边界、拆组合、自动断接头或改PNG，也不把技术成功记成美术接受。

0.54.0的[作者v6](layered-terrain-v1.md)以实体交叠替代上述旧水平域隔离；上下独立
的地形不会因为横向重合而并入同一移动组，显式连接和完整组合的联动保持。

Studio选择工具按可见层级命中：上方前景/环境仍优先，地形在低层背景前可选。
纯曲线逐像素、含格子组整格吸附；画布预览同时移动真实网格/网格外壳/曲线网格，
释放提交一次，取消恢复预览。锁、显隐和选择保持编辑器状态，由Studio约束鼠标
入口，核心仍按作者语义与事务校验。独立组合原有选择、浮条与删除入口保留。
