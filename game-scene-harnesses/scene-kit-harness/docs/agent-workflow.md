# Agent 执行入口

新项目使用 [整体观感主链](coherent-v1.md)。先把自然语言内容与风格整理成一个
brief JSON，列出本次主体和层次。先区分“只借画风”“保留场景意图”与“按点复原构图”：
普通参考场景以职责、景深、遮挡和可编辑性为主，允许合理的比例与细节变化；
只有明确要求复原或功能对齐时，才把相应坐标误差作为硬门。默认来源
把上传/手绘图用于画风；参考保持任务按下述结构合同绑定明确部件关系，不把整图
构图直接当素材画布或关卡坐标。
可参考 `examples/coherent/desert-citadel.brief.json`，但不要把8层11主体固定成所有
主题的模板。普通主题不需要新的 JS/Python 组装脚本。

新项目还需在每个 ground 来源职责里登记[地形完整性 v2](terrain-completion-v2.md)，
区分设计直边/曲线、自然起伏以及材质内的接缝，并明确有限材质研究或完整画刷。
CLI 的新 `init` 默认要求 v2；程序入口显式设置
`terrainIntentPolicy: 'explicit-terrain-completion-required-v2'`。完整画刷在来源冻结前
登记七类周边职责，素材完成后通过 `terrain-source-review` / `terrain-freeze`
准备绑定当前来源的七项计划；真实调用仍另行确认、持久预约和单次回收。
`surface-review --terrain-rendering JSON` 绑定意图及测量，`deliver --terrain JSON`
核验实际周边来源与原生并集拼接配置。缺项停在 `awaiting-terrain-perimeter`，
不会把仅有 body/cap 的候选交付为完整画刷。有限材质研究继续走 shared-field，
历史 v1 计划保持[原合同](terrain-intent-v1.md)。
Studio 验收需包含新画的连续面、阶梯、凹角和开口，不能只看默认回拼图。

对已验证素材的完整场景，如显式选择同源材质网格＋曲线地形，采用
[v2地形交付入口](shared-terrain-delivery-v2.md)的`scene terrain-deliver`及
`terrain-verify`，保留完整默认图和环境素材，再进行真实Studio验收。它是已验证
kit之后的确定性交付阶段；复用来源必须说明，不得当成所有素材新生图。旧v1纯
网格原型保持原合同，混合patch仍不支持，技术闭环不替代最终人类美术接受。

1. `coherent init` 到全新目录，展示结构、画风、整体观感规则。取得分别绑定
   spec/style 摘要的设计决定，经 `design` 登记；不要代替用户接受。
2. `compute-review` 导出参考图完整提示和输入。用户确认准确摘要后 `authorize`。
   用显式宿主适配器 `run`，或 `reserve`→内置图片工具一次→`receive`。
3. 查看准确原图，按实际画面输出粗层次/包络/表沿/七标准观察，用 `assess` 生成
   审阅包。它不是 Alpha 或像素对应。用户接受图片及 packet 后 `review`；不凭技术
   接收推定美术接受。不合适则记录拒收并新规划，不自动重试。
4. 新的参考驱动来源计划或明确修订来源 brief 时，先按
   [参考图职责拆分审图](reference-responsibility-review-v1.md)登记体块、遮挡、接触、
   独立编辑需求与推断。先解决职责缺失和无法回拼的合并，再做覆盖检查。
   由人或 Agent 查看准确参考，
   按主体、层和主要可见体块分别建立显式观察清单与来源职责映射；执行
   [参考观察覆盖检查](reference-observation-coverage-v1.md) 并把检查过的同一份
   requirements/sourceScopes 用于后续规划。遗漏、错误层或其他失败先停止对应新计划，
   改输入并重跑；保留既有计划与证据。该工具不识图，清单本身可能遗漏内容。
   若独立固定组的比例需要视觉提示，可显式选用[素材画框导图](source-frame-guide-v1.md)
   并审阅准确第二输入。不要套用连续背景带的边界职责；若已复核原图坐标修正，
   将同一 `featureCorrection` 带入新来源 scope、导图及 v6 回拼，保留原结构与容差。
   已冻结结构漏记已有 owner 的内部特征时，用单独审阅的
   [`featureSupplement`](reference-feature-supplement-v1.md) 追加并重新审阅导图；
   它不替换原结构，也不放宽旧点容差或免除失败检查。
   然后程序按实际主体冻结全部来源。展示完整批次，只请求一次准确批次计算决定；
   批次内每项各预留一次再调用，同参考输入、独立素材画布，不要求原画布原位。
   技术失败/未知立即停止，保留剩余授权；新尝试走 `revise` 与新准确确认。
5. 齐套后 `deliver`→`verify`；只使用本批原生素材和确定性派生。不得借历史 kit、
   原图裁片、CPU 分割或手工重写清单补成一次“端到端成功”。
6. `capture` 产出实际 Studio 回拼对照，`studio` 打开可编辑默认图。展示完整参考
   与实际画布；明确局限，整场景美术由用户最后决定，再用 `art-review` 记录。

继续已有 Studio 工作区时，核对当前作者文档和现有功能配置，不只检查新素材能否
显示。启动回拼预览或重启服务时，保留用户已启用的项目能力；环境素材生成需要
准确的项目风格/锚图绑定、交换目录和独立工作进程，不能仅启动编辑器后就称原
工作流完整可用。来源替换后复核锚图仍属于当前素材包且摘要匹配；不为显示按钮
绕过绑定或擅自给未配置项目启用生成。检查实际入口和弹窗，离线回归使用替身；
恢复配置本身不授权新的模型或图片调用。详见[环境素材库](environment-library.md)。

首次回拼若有漂浮、露空或层序问题，可先输出绑定批次/目标的显示摆放JSON，
通过`deliver --composition JSON`生成新候选再验。只调整显示位置、比例、明暗
与层序，保留旧候选和全部PNG，不临时编辑原图/Alpha或重写报告；不需要为每个
主题编写新的组装脚本。需要新增图片时仍重新冻结并取得单次计算授权。
单项来源替换后，按[职责审图的局部替换复查](reference-responsibility-review-v1.md#局部替换后的复查)
重新核对受影响的遮挡、开口后景和接触；旧摆位与层序只作比较基线，不沿用旧图的通过结论。

自由笔刷若要求单格或其他短跨度，完整打包前先执行显式的
[笔刷尺寸预检](terrain-brush-footprint-v1.md)。固定设计所需的最小跨度、转角深度、
保留主体宽度及底边周期预算；可用 delivery API 的 `footprintPolicy` 在派生前拦截。
单项替换后仍检查完整组合，不因局部变窄就通过整套笔刷。预检只量测控点，不能
代替原图/接管线校验、大形与材质接头、完整周期回拼或实际 Studio 美术检查。

需要按点复原的参考任务采用[参考结构与部件标定](reference-feature-layout-v1.md)：
冻结同一参考的关键部件点和结构检查，来源修订保留其准确摘要。出现悬空时不能
靠新增参考没有的主导地貌悄悄改变目标。显式量测来源原生部件，先用 v6 composition
及 `features-review` 做零生图形状/结构预检；不匹配、缺少或不确定的观测先阻断，
之后才完整 `deliver`。不以 A>0 整图粗包络代替桥塔、步道等部件标定，也不删除
弱 Alpha 修形。旧计划/旧 composition 保持原解释，实际画面和最终人审仍独立。

用户明确允许构图差异时，可用[参考意图审阅](reference-intent-review-v1.md)为已有
技术通过的原 PNG 创建新 v6 composition。原误差、旧失败与来源计划保持不变，
只把明确审过的几何差异列为可接受；职责、遮挡、独立编辑、开口与接触仍需通过。
先用现有素材回拼看整场景，不为次要坐标差异反复生图。此操作不代表最终美术接受。

已配置可信分析器和图片适配器的宿主，可由 `continue` 一条入口串联上述步骤。
决定仍来自用户，适配器只返回数据/原生媒体；测试自动决定只用于替身。未配置
分析器时，Agent 提供符合版本合同的观察数据，不执行模型生成的代码。
对需要该检查的新参考计划，必须在 `review` 或 `continue` 显式提供
`--defer-source-plan true`。它先登记参考审阅并暂停来源冻结；`observation-coverage`
通过后，`advance` 会使用当前准确参考与最终 source scopes 重放报告。已冻结旧计划、
默认 `review` / `continue` 及独立来源修订不会自动得到此门，需按文档显式检查。

默认验收看主题与材质身份、明暗层次、构图大关系、地形清楚、前景清晰和场景
可编辑。不要恢复旧逐点木/雪覆盖门，也不要声称新流程满足旧一比一试验。
不需要为每项素材接受、透明 RGB 诊断或正常编辑操作重复请求授权；实际新图片
计算、失败后的新尝试及人类美术决定仍遵守仓库准确计划合同。

前景混入主地形时，优先修正生成请求的主体边界：用独立单项`subjectBrief`
描述只要的近景装饰，参考图仅约束画风/材质/光照，不把粗包络当成要完整复制
的场景块。显式修订可用`isolated-foreground-v3`。Agent必须检查原生输出是否
仍含主岩壁、连续可玩台面或其他层；技术透明检查无法完成这个语义判断。
不再用Alpha/颜色/轮廓后处理弥补本次前景混层，不将已有清理试案接入交付。

回拼默认保留生成素材原色（白色tint、正常不透明度），不要为了突出层次自行
加深前景或调色。额外明暗/染色属于独立美术选择，仅在用户明确要求时加入；
与尺寸、摆放调整分别说明。原生PNG未改不代表画布/导出场景没有额外调色。
