# Game UI harnesses
This category covers HUDs, menus, controls, icons, and UI decomposition.
The UI-decomposition line now has an isolated opt-in experimental Harness. It is
not a default route and still requires semantic planning and visual review.

- [UI decomposition](ui-decomposition-harness/) — implemented, experimental opt-in.
- [UI components](ui-component-harness/) — implemented local compiler, 16 PixiJS
  component types, portable bundles, separate motion, Web acceptance and offline
  CLI/Skill. Online vision is unconfigured. See [tasks and evidence](ui-component-harness/docs/tasks.md).
