## 后续规则与边界

完成原始审计后，先按批准计划中的指纹保存 `common-game-panel-prompt.mjs` 原版，再向concise-v4实验提示增加三项约束：表单完成动作使用关联Input的submit；确认文案与确认／取消放在同一可操作区域；示例文字只提面板实际提供的内容／动作。同时进一步明确普通游戏大厅指单个游戏的主页导航。

这些提示更新发生在37次真实测试之后，因此尚未证明能让模型稳定避免上述问题。用户原口令保持简短，不要求用户描述内部组件或布局规则。本轮没有采用新开源skill，也没有切换日常Studio、SDK默认目录或发布新版本。

每项仅运行一次，重复输入稳定性未测，人工内容验收未记录；Unity原生引擎和实际游戏后台未测。列表与静态说明的联动、游戏跳转、购买、好友及存档等仍须按公开宿主合同接入。下一轮真实调用需要新的冻结计划与单次授权。
