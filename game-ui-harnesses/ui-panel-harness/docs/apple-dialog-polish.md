# 退出确认细节精修试稿

用户认为恢复底板后有所改善，但仍偏简陋。本轮只继续打磨退出确认，保留其他面板和上一版源包。入口为 `output/apple-dialog-polish-v2/review/index.html`；左侧是原v4退出弹窗，右侧是紧凑精修，支持浅深色、实际按钮和候选下载。

## 设计改动

- 整板从500×351收紧到428×269，保留20px圆角，标题与正文、正文与操作区形成连续分组。
- 标题从32px降为24px；正文16px，降低正文对比，突出标题和主要操作。系统字体族保持。
- 取消与退出同处底部一行，两者均为179×48，间距14；按钮圆角10px，取消使用中性灰、退出使用较克制的红色。
- 整板和按钮补充1px细边线；整板使用现有轻量投影，深色以较亮边缘区分表面与背景。

参考本机 `ui-ux-pro-max` 的通用交互、排版与视觉一致性规则。其本地UX检索仅返回确认交互与模态焦点建议，没有找到可直接采用的美术版式；上述具体尺寸、色调和组合为本地设计试稿，不能视为Skill审美验收。

## 实现与边界

`examples/apple-dialog-polish-v1/fixture.mjs` 只接受指定的0.24.0程序退出夹具，将原正文和两个按钮合入同一段，以既有 focused 排版和 refined-v1 / compiler0.18.0 呈现。仅在独立目录采用这套已有能力，没有改编译器、PanelSpec协议、Pixi运行时或UGUI适配器。

原标题、每个行对象、正文、事件、动作、绑定、状态及素材闭包保持。目录令牌、标题样式、分组、尺寸及按钮样式的改变由夹具明确声明。普通生成默认、原五类样本和4951服务保持；没有新增模型或媒体调用，也没有推送GitHub。
