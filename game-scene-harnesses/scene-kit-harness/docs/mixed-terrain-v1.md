# 矩形格子平台与曲线连接 v1

0.54.0的[作者v6](layered-terrain-v1.md)支持接头上下方另外摆放不相交的地形；显式
连接仍使用本页的矩形/封底/端点规则，不因投影重合或边界接触自动合并。

源码 0.14.0，混合地形实现仍同 0.11.0。首轮支持“矩形格子平台 → 曲线 → 矩形格子平台”，也支持只连接一侧，
或用一个矩形平台连接左右两条曲线。连接后共用连续表面、石土/草沿网格与闭合碰撞
建议；作者格子和曲线均保留。没有新增生图或正式美术接受。

## 作者数据与版本

显式 enable-mixed-terrain 把 v2 作者地图升级为
[`ai_scene_document_v3`](../schemas/scene-document-v3.schema.json)，新增必填
terrainConnections。v1 先显式 enable-curve-terrain；多个命令可组成一次原子手势。
v1/v2 的 Schema、编译格式、原内容和导出重放不改变，不在打开时自动升级。

一个连接的准确字段为：

```json
{ "curveId": "ground.hill", "endpoint": "start", "cell": { "x": 3, "y": 7 } }
```

每个曲线端点最多一个连接，整图最多 32 个。start 连接格子平台的右上角，cell 指
平台最右列、最上行；end 连接平台左上角，cell 指最左列、最上行。点的 X/Y 必须
准确等于格子角坐标，切线为 0，曲线 baseY 等于平台底边。材质家族须相同。

首轮网格为 64×64 逻辑单位。每个被连接的四向连通格子分量必须是填满的矩形，
支持至少一格厚的实心台地；L 形、洞穴、T 形和重叠区域暂不允许。台阶、悬浮台、
复杂地形仍可在没有连接的普通格子区域按原规则编辑。沿用曲线的横向分区限制，
仍不支持曲线上方相同 X 区间另放格子平台。

v3 允许曲线和格子边界接触，内部面积仍禁止重叠；只有显式连接才会合为共同网格
和碰撞轮廓。解除连接保留位置，接触的两部分恢复独立呈现/轮廓，不再保证共同草沿。
原 v2 连共享边界都拒绝的规则保留。

## 编译与材质

核心按格子四向邻接求连通分量，验证完整矩形、接头与封底。连接构成无分叉的水平
链，按 X 排序，合并矩形平顶与原曲线控制点，去除相同接点的重复。导出的共享表面
在每个接点只采样一次，曲线水平端与平台平顶具有相同切线。

每个混合链横向最多 8192 单位。沿用曲线采样：控制点到弦阈值 0.5 逻辑单位、最长
弦 32、递归最多 16、最多 2048 样本、1e-6 量化、向内 8 单位草沿；超限/草沿折叠
整次拒绝，不截断或降低质量。8192 是本轮单链预算，不是无限地图或分块系统。

`ai_scene_compiled_v3.mixedTerrains` 包含 source.curveIds/gridCells、body/cap 网格、
surface/contour/samples、baseY、bounds、patchId、MIXED_TERRAIN_PROFILE 和地形层。
原格子节点及曲线描述保留作来源，terrainNodes 仍是格子数，不把网格数混进该计数。

Pixi v3 呈现只替换混合链覆盖的完整格子分量和曲线，避免重复绘制；其他图块与独立
曲线沿用原入口。混合区域以统一 Mesh 采样已验证的 body/cap 材质场，石土 UV 为
世界坐标 / 256，草沿为整链累计距离 / 256。接头没有独立图块边角或草沿相位重置。
连接区域外仍使用原 47 角色/16 相位图片；没有改写冻结派生包或重切原图。

这会把被连接的矩形区域从原图块边缘表现换成统一的平顶、实心侧面。当前不保留
图块外角圆化/边缘阴影，仍有四格材质周期；这是新版本显式混合几何试样，不是原
47 图块在任意曲面上无损拼接的声明。无材质时使用工程色，视觉验收继续未评审。

碰撞编译从普通格子集合移除已由混合链覆盖的格子，从独立 curveContours 移除已
被覆盖曲线，由 mixedContours 提供一条闭合轮廓。连接处没有内部竖边，不读取
图片 Alpha 猜碰撞。walkability 始终 not-assessed，尚无物理运动或可达性验证。

## 编辑与撤销

- connect-curve-grid：准确字段 type、curve、endpoint、cell；curve 是完整移动方
  作者提案。要求 v3；关闭字段校验后，将选定端点吸附到目标角，再整图验证。
- disconnect-curve-grid：准确字段 type、curveId、endpoint，解除该连接并保留位置。
- 删除曲线会同时移除其连接，保留所有作者格子。合并两个自由曲线端时，保留外侧
  格子连接并更新被移除的右曲线 ID；正在连接格子的端点须先解除后才能合并。

普通替换曲线、格子画刷、预设编辑、范围变化等操作也要通过共同验证。改变已连接
平台为不规则形状、移动/删除其锚格、修改封底或移动锁定端点，均拒绝整个命令，
保留作者、历史和重做分支。要改平台形状，先解除连接；没有隐式删连接的画刷行为。

Studio 的曲线工具增加“连接附近格子平台”“解除格子连接”与接头提示。选择自由
端点，或拖近矩形平台角即可连接。手势至少移动 3 屏幕像素，目标在 12 屏幕像素内
且不远于 64 逻辑单位；与曲线合并候选按距离选择，等距优先曲线。拖动期间只是
临时预览，释放后一次提交，四种取消丢弃。已连接的端点与封底字段锁定。

“添加混合地形小样”一次向右扩 16 列，添加两个 3×2 格平台、一条曲线和两侧接头，
必要的 v1→v2→v3 升级包括在同一手势中；一次撤销恢复原地图和版本。地图须至少
4 行高。新区域与原内容保留空列，避免改变原格子的连通分量。

保存/打开使用 v3 作者文档；外层目录导出仍为 ai_scene_export_v1，但读取者须支持
0.11.0 的 v3 编译。基础 kit 原字节闭包保留，外观仍来自独立显式配置，导出不包含
森林试样纹理。严格重放不等于正式美术交付或目标项目接入。

## 验证与后续

20 项新增核心回归覆盖版本关闭、双侧共源几何、原子升级/撤销、候选、无效连接、
平台编辑、删除、曲线合并连接迁移、单链预算、负坐标相位、保存导出和 Pixi 替换。
7 项新增浏览器回归覆盖按钮/拖动双侧连接、三种缩放的接口像素抽样、端点锁定、
解除/重连、四种取消、非法刷图、普通区域编辑、模板、保存打开及窄屏。

实际运行证据由执行文档第 29 节维护。测试使用合成材料；真实森林材质仅在私有预览
和人工核对中使用。下一步应转回派生地形的自然轮廓/周期改善、远中近景和可携带
美术 kit，再扩不规则格子接头、跨分块连接或完整物理运行时。
