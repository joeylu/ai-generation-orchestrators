## 使用约定

描述玩家要做什么，以及已确定的初值、范围和按钮行为。缺少业务约定时回答澄清；不要求用户认识控件名。修改基于当前已生成面板，整页修改前取消控件选择。成功修改最多10轮；失败与澄清不占轮次，撤销不退还轮次。存活字段保留试玩值，创作默认值修改不直接覆盖正在试玩的输入。

同一浏览器与地址会保存最近面板、草稿、试玩值和已用轮次。文件迁移、清理浏览器数据或更换地址前下载PanelBundle备份；新地址不会自动继承旧地址的本机记录。部署、账号和云同步不属于本版。

## 明确保留的边界

- 标题、主题引用、明确色值、标题/按钮字号、唯一控件默认值和几何短句可以独立核对。全部短句明确识别时才强制检查“其他保持不变”；未识别内容不会冒充语义验收通过。详见[属性核对](panel-edit-property-checks.md)。
- 现有颜色覆盖优先于预设主题。主题引用符合请求，不保证所有像素都改为同一颜色；字体变化和比例变化也不保证像素位置不动。
- 任意嵌套、绝对定位、动画、复杂富文本和所有可能的自然语言都没有保证；结果可能需要澄清或被拒绝。
- 最新输出的原生Unity运行仍未验证；导出的控件为UGUI，共享适配器承担状态/事件与有限外观。Cocos、Godot、UE适配未实现。
- 模型响应、网络与服务可用性不是本地回归能证明的；点击失败后不自动重试。批量计算按仓库规定单独授权。
- 本地产物不随Git克隆。可复现启动方式见[使用入口](start-here.md)，不提交临时输出、机器代理设置或认证文件。
