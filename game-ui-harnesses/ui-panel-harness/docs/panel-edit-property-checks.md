# 明确属性与修改范围核对

Studio另有[要求已满足时本地提示](local-satisfied-edit.md)：完整明确项与“其他不变”已经匹配当前Spec时，不提交模型编辑。它只提供客户端反馈，不修改本文公共方案核对语义。

Studio 的新修改采用 EditContext 0.14 / `explicit-properties-v4`，在本页原0.12属性策略上增加[精确按钮文案核对](button-copy-checks.md)及[同名按钮分组定位](scoped-button-copy.md)。程序从本轮
原文和基础面板的稳定 ID 生成 `requestChecks`，重算时同时验证内容和摘要；模型
不能删掉漏项、换目标或关闭“其他不变”检查。保存的0.11几何策略、0.12属性策略及0.13文案策略原样保留。
Draft 0.3、Proposal 0.1/0.2 和最终 Spec/Bundle 版本没有因为核对规则而改变。

可直接测试：

> 面板标题改为“角色资料”，改成蓝色主题，面板背景色改为#EAF4FF，标题字号30，
> 确认按钮字号20，角色名默认值改为“蓝莓旅人”，其他保持不变。

这需要基础面板已经包含唯一的角色名输入框和确认按钮。检查范围：

- 面板标题：引号内原文，包括空格、标点和 emoji；只匹配明确的标题赋值。
- 按钮文案（0.13起）：唯一名称或点选ID的明确赋值；0.14支持分组限定及点选后的同名原文。漏改、缩短或顺带改行为均独立核对，文本仍须满足组件合同。
- 预设主题：绿/薄荷绿、蓝、紫、橙色家族在当前固定目录中的精确引用，保持原
  明暗模式。已有自定义颜色继续按原规则覆盖预设；主题引用通过不代表所有像素
  都变成该色。缺少或不唯一的目录条目不猜版本。
- 明确 #RRGGBB：面板背景、强调色、文字、控件背景和边框。最终值包含主题继承。
- 标题字号、唯一命名或选中按钮的字号：读取最终覆盖值或继承字号。
- 唯一控件的数字、布尔、带引号字符串默认值：不把“50”强行转成数字。修改
  创作默认值仍保留当前试玩输入；此检查不承诺自动操作游戏业务。
- 原有明确几何短句继续检查，缺项、写错或虚假的“无需修改”均整轮拒绝。

“其他保持不变”只有在全部短句都能明确识别、且至少存在一个修改目标时，才
强制比较未被指定的创作属性。允许协议升级产生的空继承容器，以及固定尺寸
生成的画布尺寸；控件、按钮行为、其他默认值、其他布局/外观仍受保护。需要
加高标题才能容纳字号时，必须明确要求高度或返回澄清，不能擅自修改后宣称其余
不变。检查的是创作属性，不保证主题/比例变化后每个渲染像素的位置不动。

复杂描述、改口、示例、回答记录、重复目标和无法唯一匹配的名称保留为未核对。
存在未识别短句时，“其他不变”标记为 `NOT_CHECKED`，Studio 明确提示尚未自动
核对；不会假装通过，也不会把未识别的正常自然语言禁用。通用语义审核始终
`NOT_RUN`。失败不改变面板、试玩值、历史或已用轮次，不自动调用模型重试。

新增回归和浏览器方案均由程序编写，本阶段没有真实模型调用。
