# 单按钮文字与符号字号

在 Studio 选择按钮后，可输入“把这个 icon 放大”“只把文字改成 24 号，按钮尺寸不变”。内联播放符号属于按钮文字，可以单独调字号；外置图片图标不通过此操作缩放。

`set-button-font-size {rowId,fontSize}` 只改一个现有按钮的文字。字号为 8–96 的整数逻辑像素；`null` 恢复主题字号。不改变按钮大小、圆角、位置、内容、事件或动作。超出当前按钮可用空间的字号会在编译阶段拒绝，不会自动扩大按钮、缩小字号或截断文字。失败不替换当前面板、不增加修改轮次。

首次设置字号升级为 PanelSpec/Bundle 0.11，编译器 0.11.0，通过 `buttonFonts:[{rowId,fontSize}]` 记录覆盖。原 `buttonStyles` 八字段合同保持原样。清除字号只删除该项覆盖；清除颜色和尺寸不清除字号。删除按钮会删除对应字号覆盖。组合面板按稳定 ID 重映射字号目标。

modern-v3 的新修改上下文采用 EditContext 0.7（字号能力从 0.6 起提供），`selection` 为 null 或 `{rowId}`，并声明 `buttonFontPolicy:per-button-font-size-v1`。选中对象时，原生输出 schema 将字号操作目标固定为所选按钮。公共验证器独立检查能力、作用范围、当前请求依据及摘要。保存的 Context 0.1–0.6 和 Spec/Bundle 0.1–0.10 继续按原合同回放，不自动获得新能力。

Pixi 的按钮及居中文字使用相同字号，标签按实际字形边界居中。Unity 导出到已有 UGUI Text.fontSize，保持一份居中标签及共享运行时结构。此次验证包含结构导出，未进行 Unity 编辑器原生导入或新增真实模型调用。
