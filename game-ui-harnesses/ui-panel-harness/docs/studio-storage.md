# Studio 本机保存

需求描述、修改要求、需求标识与资源风格会自动保存。面板生成、导入或修改成功后保存版本，试玩值也随之保存；修改失败保留上一版。刷新或重新打开同一地址会恢复最近工作，无需重新调用模型。

日常使用[一键启动](studio-start.md)的固定地址，同地址重启、升级与保存后刷新继续读取这些记录。
更换构建目录不改变存储键；显式改端口或浏览器仍是独立工作区。

每个面板最多成功修改10轮。一次修改请求可能包含多个操作，整份修改成功提交后记一轮；失败、过期、渲染失败、需要澄清及无需修改不记轮次。自然语言修改、方案导入、高级属性和补丁共用限额。第10轮之后，修改入口关闭，仍可试玩、撤销和导出。撤销、恢复历史、导出后重新打开同一面板都不返还已用轮次；只有成功生成新面板才重置该面板的轮次。

轮次按PanelSpec的面板ID记录在本机工作区中，独立于历史版本与撤销栈，不进入引擎通用PanelBundle。工作区格式0.2保留原存储键，兼容读取旧0.1记录。旧记录没有可信的累计轮次，从启用新规则后开始计数。该限制是Studio的本机工作流规则，不是账号计费或防篡改配额；更换浏览器、清除本机存档或导出到其他环境不会携带该记录。自动保存失败时须先保留备份，本次会话仍执行上限。

「面板操作 → 历史版本与本机存档」可恢复旧版本。恢复包含该版本最后保存的草稿和试玩值，不会删除后来的版本；从旧版继续修改会保存新的结果。拖动滑条、开关及输入文字不会为每个动作新增面板版本。

记录使用浏览器 localStorage 的单个原子写入键 `ui-panel-studio.workspace.v1`，没有数据库或后台存储服务。最多保留8个不同创作版本，总记录不超过1,800,000个UTF-16代码单元。图片较大时优先移除最早的非当前版本；当前面板单独仍过大或浏览器空间不足时，显示保存失败，保持上一次成功写入的记录。输入有250ms去抖，正常离开页面会同步保存最新内容；浏览器崩溃或进程被强制终止仍可能丢失尚未写入的变化。

恢复面板须通过现有PanelBundle验证、状态验证和确定性编译，成功渲染后才应用草稿。不持久化模型调用、授权、传输信息、未完成任务、方案上下文、澄清流程或撤销栈；不会自动重发生成或修改。创作默认值与试玩值分别保留，恢复默认时才采用创作默认值。

检测到其他标签页更新同一地址的存档时，本页暂停自动保存，减少覆盖风险。浏览器存储没有跨标签页事务，极短时间内同时写入仍以最后成功写入的记录为准。请先导出仍需保留的本页面板，再在历史版本中「重新读取本机存档」。损坏或未知版本的记录不会被自动改写，可下载原始存档备份，或经过二次确认重置并从当前工作继续。存档备份仅作原始记录保存；恢复完整备份尚无专用导入入口，单个面板请使用普通面板导出和打开功能。

本机记录仅属于当前浏览器和完整网址的来源（协议、主机、端口）。更换端口、浏览器或清理浏览器数据不会自动迁移；不保证直接打开file网址时的存储行为。长期保存和换设备请使用「导出当前面板」或下载交付包。
