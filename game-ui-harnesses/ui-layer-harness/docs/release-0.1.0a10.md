# UI Layer 0.1.0a10

标签：`ui-layers-v0.1.0-alpha.10`；CLI：`0.1.0a10`。发布日期：2026-10-14。

## 改动

统一背景与前景的输出归属提示，明确空底板、固定插画、普通文字移除和精确保留文字的边界。默认 context v14 / board v7；显式选择 v15/v8、v16/v9，及已审核快照的逐合板 v10/v11 变体。保留历史版本提示，不能把试验选项理解为默认质量保证。详见 [输出归属提示](OUTPUT-ROLE-PROMPTS.md)。

正式交付入口支持冻结并校验合板变体，整图复审检查底板中被遮挡的重复控件。自动交付增加源图与最终结果的双栏对比。视口归档完整性校验直接读取内存中的内层归档，避免依赖系统临时目录写入，同时继续核对像素重组、原图、路径、尺寸和校验和。

## 真实样本验证与限制

- 装备商店：35/35 素材，16 次生图，1 次独立整图复审，自动诊断交付完成。
- 森林暂停：5/5 素材，2 次规划，3 次生图，1 次整图复审。背景锐度高于原图，记录为警告。
- 极地装备：44/44 素材，3 次规划（含一次结构修复和独立复审），27 次生图，1 次整图复审。仍有底板残留另属按钮、水壶槽变形、相邻槽边框残留和图形尺寸偏差。

以上均为 `diagnostic_complete`，包完整性通过不等于严格视觉质量通过。极地结果尚未人工验收。没有自动重试；本次发布不追加真实模型或生图调用。赛车样本仅准备提案，未执行。

## 升级与验证

下载源码和 viewer 附件并校验 `SHA256SUMS`，安装到新版本目录。离线检查的实际范围和结果见发布附件 `offline-regression.json`。fixture 不代表真实视觉质量验收。

旧任务继续使用原不可变版本；不要覆盖旧快照、授权、原图、回执或失败状态。新任务仍明确使用 sheets；素材保持独立，合板仅用于分组。规划、生图及一次整图复审分别绑定显式预算，失败或结果未知不自动重发。没有部署、私有服务设置或额外计算授权。
