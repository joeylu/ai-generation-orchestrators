# Studio 源码收尾 · 2026-10-10

本次保存 UI Panel Harness 已完成的源码、公开程序夹具与使用说明。继续沿用自然语言生成和在现有面板上修改的链路，Pixi/Web预览优先，PanelSpec为通用协议，Unity提供UGUI导出工具；暂不接入游戏项目。

## 本次完成

- 默认提供12个自有核心图标，按用途给出选图建议；没有合适素材时保留文字，同组菜单统一表达方式。建议不自动改写模型方案或已保存面板。
- 日常纯文字菜单采用完整底板、居中标题与按钮列；设置、表单、弹窗及Tabs保留各自排版。Apple方向的对齐声音设置等美术样本及用户反馈独立保留，不宣称全部试稿已切换为默认。
- 编辑在本地预检已满足要求、同名目标选择及选中控件的明确范围冲突。普通编辑保留现有素材、动作、绑定及存活试玩值；最多成功修改10轮，撤销和恢复历史不返还轮次。
- 在线「采用回答并生成/修改」直接合并完整答案并提交一次；缺答不提交，追问等待用户再次回答，失败不自动重试。离线可继续导出上下文。
- 「新建面板」先保存当前面板再进入持久化空白任务，旧面板、草稿、试玩值及累计轮次可从历史恢复。尚未生成面板的纯文字草稿不另外归档；存储失败或冲突不丢弃当前面板。
- 修复响应正文读取中断及损坏/过大返回的反馈；修复隐藏重复标题后单按钮菜单分组不足80px而被拒绝的问题。已保存的失败方案可在修复后本地重新编译，无须重新调用模型。

## 使用

在同仓库安装好的共享组件开发环境中，从 `game-ui-harnesses/ui-panel-harness` 运行 `npm run doctor`，通过后运行 `npm run studio`。默认固定地址为 `http://127.0.0.1:4951/`，启动不调用模型；同一浏览器与地址保留本机存档。完整说明见[使用入口](start-here.md)和[依赖边界](structure.md)。
