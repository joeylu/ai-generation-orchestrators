# 面板分层与材质消费

新面板把外框、内容卡片和数据区分开，复用组件项目中的真实 PNG 和可选 S05 材质。模型负责语义和用户要求的结构，程序负责底板、安全区、尺寸、文字与资源闭包。纯排版节点不因嵌套而自动增加边框。

## 文档合同

PanelDocument 0.3 的可选节点字段 `surfaceLayer` 支持 `frame`、`content`、`inset`，适用于 Panel、Dialog、ScrollView、Tabs、List。该字段与显式 `surfaceStyle`、自定义 `backgroundRef` 互斥。模型无需输出这个消费者字段。

| 层级 | 用途 | 资源 |
| --- | --- | --- |
| frame | 主面板或主弹窗外框 | `skin.surface.panel`，并按包内原参数消费可用的 S05 panel 配方 |
| content | 有意义的信息组、帮助卡片、仓库区域 | `skin.surface.content`，避免重复外框装饰 |
| inset | 标签和值、紧凑数据区 | 从同一 content PNG 的安全主体区域派生纹理帧，避免重复装饰边框 |

标题继续使用 Text 的 `surfaceStyle: title/section`，有 S05 时使用已绑定材质。缺少 S05 的旧皮肤沿用真实核心底板；不会用程序图案冒充已生成材质，也不会自动补图。基础资源、纹理参数和皮肤摘要不因消费层级改变。

新标题可显式设置 `surfaceTextInsets` 四边留白，避开材质纹饰。该字段只适用于带 title/section 配方的 Text，不能小于原配方的安全区，原有配方和无覆写的旧标题保持原样。内容框额外保留切片边界与留白，避免历史零内边距导致格子或文字盖住边框。

安全区、切片最小尺寸和派生纹理坐标来自经过校验的皮肤元数据。文字颜色按实际基底角色计算，作者显式颜色优先。派生 Texture 只释放自身，不能销毁共享皮肤源。

## 16 类组件的使用边界

| 组件 | 底板与纹理规则 |
| --- | --- |
| Container | 只排版，保持透明 |
| Panel | 按 frame/content/inset 语义选择；不把每一层都当主外框 |
| Dialog | 主弹窗使用 frame，保留遮罩、关闭和按钮行为 |
| ScrollView | 滚动区可选 content，滚动和遮罩不截断外部按钮 |
| Tabs | 页签保留正常/选中皮肤，内容区域按需选择安静底板 |
| List | 库存区域和详情按需有底板；格子消费正常/选中 PNG，保持固定格尺寸 |
| Text | 主标题、分组标题使用独立配方；正文继承所在区域的可读字色 |
| Button | 使用主/次按钮自己的 PNG，避免再为每个按钮包主外框 |
| Input | 使用输入框正常/聚焦 PNG，保持原生编辑和安全区 |
| Select | 使用字段、箭头及弹出列表自己的 PNG，保持弹层命中 |
| Switch | 使用轨道和滑块 PNG，分组底板由所在语义组提供 |
| CheckBox | 使用框和选中标记 PNG，分组底板由所在语义组提供 |
| RadioGroup | 使用圆环和标记 PNG，保持选中对齐；不改变当前规划能力边界 |
| Slider | 使用轨道、填充和滑块 PNG，按实际拖动验证 |
| ProgressBar | 使用轨道和填充 PNG，进度和数值不因装饰改变 |
| Image | 保持已绑定图片和裁切语义，不发明未绑定资源 |

当前自定义规划消费八类行语义：文字、按钮、输入、勾选、开关、滑块、下拉、进度。Container、Panel 和滚动结构由程序编译；完整 16 类运行时检查与模型可输出能力分别记录。

## 版本与验收

新展示由冻结的消费者配置显式选择。旧配置、旧提示词、旧 conversion 版本和无 `surfaceLayer` 的文档继续原有规则。历史响应重放写入新的派生目录，原始计划、响应、回执、转换产物、皮肤和已保存编辑副本不覆盖。

六套风格参考共同用于比较标题重点、外框装饰、内容对比和留白。参考图数量不等于已验证皮肤数量；验收记录应列出实际皮肤摘要及其是否含 S05。

48 条验收矩阵包括当前九种预设的横竖两版与三十条自定义短需求。每条真实生成绑定独立不可变计划并仅提交一次；结果不明不自动重投。检查分别记录原需求语义、转换、实际渲染、局部交互、导出与资源证据。最终状态与截图以验收程序输出为准，不把离线替身记为真实模型成功。
