# Studio UX审计与阶段收尾

日期：2026-10-27（Asia/Shanghai）。源码0.55.0。面向桌面鼠标搭图流程；窄屏检查
抽屉与布局，不等同于完整触控支持。本文是执行文档的支持性审计记录。

## 本轮修复

| 问题 | 影响 | 已落实的行为 |
| --- | --- | --- |
| 图层树选择对象后画刷/素材高亮可能残留 | 实际工具与用户看到的选中状态不一致 | 控制更新统一同步卡片状态，放置结束后也取消旧高亮 |
| 曲线库单击立即扩图并添加远端小样 | 用户只想选中却修改了地图 | 与其他素材一致：先选后点画布，或直接拖入；Esc/选择工具取消 |
| 普通素材点击放置被吸到格子，拖放则自由定位 | 同一素材两种鼠标入口落点不同 | 普通素材使用鼠标位置，组合按格；曲线左端按格、高度按鼠标 |
| 属性与选项可叠开，窄屏抽屉缺少统一退出 | 挡住画布，关闭抽屉还可能顺带绘制 | 浮层互斥、点外侧/Esc关闭；抽屉外侧画布点击只关闭，不编辑 |
| 项目容量/下载错误显示在模态弹窗后面 | 看不到失败原因或正在处理的反馈 | 弹窗内显示容量、失败和打包状态，处理时禁用重复操作 |
| 自动保存与下载副本含义不清，断连露出原始错误 | 不知道是否已保存，可能重复操作 | 项目按钮为「下载地图」，显示保存中/已保存/结果待核对，断连给出核对指引 |

选中、抽屉、浮层、工具、镜头与保存提示仍属于编辑器状态；不会改作者或素材。
每个真实编辑仍由现有核心验证并形成一个可撤销批次。失败不自动重试。

## 审计范围与当前边界

| 流程 | 检查内容与边界 |
| --- | --- |
| 项目入口 | 搜索、新建、进入/返回、复制、重命名、项目ZIP导入下载及空白状态 |
| 地图与保存 | 多地图独立、自动保存、刷新、JSON副本、ZIP导出、失败保留原状态 |
| 模块库 | 真实组合缩略图、画刷单入口、点击/拖入、选中同步、放置后选择、取消 |
| 画布 | 对象移动/缩放、透明穿透、整块地形、无回弹交接、表沿双击加点与接头 |
| 地形约束 | 分层实体判断、封底吸附、画刷解除失效矩形接头、原子撤销与失败回滚 |
| 图层 | 通用父级、对象选择/定位、显隐、锁定、折叠；不改实际渲染顺序 |
| Play Mode | 游戏视口、框外裁切、视差、长图浏览、退出恢复镜头；不是角色物理试玩 |
| 反馈与布局 | 选中/禁用/焦点、弹窗内错误、浮层退出、窄屏不横向溢出 |

此阶段不把未实现能力作为交付：多选/框选、批量变换、图层拖动重排/重命名、
多材质画刷、格子与坡体布尔合并、完整触控与屏幕阅读器树导航仍是后续项。
刷新后镜头、折叠与工具状态尚未按地图持久恢复；撤销/重做属于当前宿主会话，
重启恢复保存地图但不恢复会话历史。本机服务仍由显式启动脚本运行，不是常驻服务。
当前回归覆盖功能正确性，不作为大规模场景的帧率基准或无障碍认证。

## 验证

新增离线UX回归覆盖选中同步、零编辑的卡片选择、曲线原位放置且不扩图、环境像素
定位、互斥浮层、抽屉外侧不误画、Play Mode退出、弹窗内错误、保存等待及网络失败
不重发。全量覆盖75项浏览器检查：其他68项通过，旧混合组更新过时预期后7项
整组复跑通过；55不可变夹具只读重放及4个修改模块的语法检查通过。

新增核验发现工具状态属性曾与现有按钮选择器重名，以及details异步toggle会延迟
关闭属性浮层；分别改为独立active-tool属性与同步点击处理，原UX断言完整通过。
这些是本轮开发中已修复的问题，没有放宽断言或交付到旧窗口。

实际第63版项目在1440/760/390宽度核验选中、零编辑曲线选择、浮层互斥、Esc退出
预览、抽屉外侧关闭、项目弹窗和项目页。0写请求、错误、警告、外部请求与媒体计算，
新旧作者/历史及workspace指纹不变。第131节记录交付，截图和程序收据在工作区外
editor-r18。当前阶段可收尾，后续以拆分层的生成语义问题为主。

## 转入拆分层优化

编辑器的通用父级目前是显示分组，不等于生成器已输出明确图层语义。代码审计确认：
`isolated-foreground-v3`目前只能用于有父计划的前景修订；新批次默认仍走旧来源
提示，既有技术检查也没有自动识别混入平台/主墙的能力。

下一轮应优先把单层职责做成新版本的规划数据和默认生成合同：每个主体有独立的
正向内容、排除项、所属父级、完整性/透明策略与回拼锚点。先解决前景混入平台，
再检查地标、中景、谷底的相邻层污染；内容由当前主题决定，父级词汇通用，数量不固定。

成功的前景隔离提示需要迁入新项目默认路径，保持旧冻结计划逐字重放。来源审阅
先查「是不是只有该层内容」，再回拼比较整体观感；不回到枝条/像素一比一，也不靠
事后算法裁掉混入的主地形。现有PNG技术检查仍保留，不能代替语义和最终整图审阅。
本轮只确定下一轮的工作顺序，没有修改生成合同、接受历史图片或提交新图片计算。
