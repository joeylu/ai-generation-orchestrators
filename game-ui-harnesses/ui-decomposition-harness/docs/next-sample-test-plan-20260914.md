## 每张图的执行规则

1. 记录原图路径、字节SHA、尺寸；盘点实际组件和观察状态。未知范围、选区、
   滚动值不猜测，不能把推导交互状态写进reference-state的observed字段。
2. 在生成前列出合同和适配器支持矩阵。横向ScrollView、任意缩放注册、非等高Select
   行、未接通编辑类型等能力不能因为消费端某条路径支持就声明拆分端已完整验收。
   遇到缺口先补合同/适配器或明确报告，不能暗中排除区域。
3. 默认系统字体规范，优先大小、颜色、布局、透明边缘及控件切换。背景不烘焙动态
   文案/图标/旧状态；Tabs、Switch和逐选项Select复用正式版本化合同。
4. 可显式提出内容底部留白，报告已知内容高度、视口高度、留白和实际范围，用户
   授权后通过现有contentHeight确定性应用；不默认20px、不由短滑块反推内容。
5. 对冻结计划取得新摘要授权后才生成；旧授权不能转用于新图。每张使用新目录，
   保留失败与素材来源；回归使用本地夹具，不调用媒体或私有模型服务。
6. 真正测试控件组合：内容起始拖动不能误点List/Button/CheckBox/Select；Slider保留
   自己的拖动；弹出菜单开关后无残留图标或点击面；Dialog遮挡与关闭后焦点恢复。
   轮、拖、键盘分别测边界、事件次数和可见像素/内容位置，不只setValue截图。
7. 输出自包含v2 ZIP；隔离ZIP官方导入、实际Studio、保存/重开/再导出/官方再导入。
   原图字节、映射、状态、验收范围和素材引用完整保留。
8. 报告技术结果、视觉差异及未知证据，human_visual_acceptance保持false；后续用户
   人工接受以绑定具体ZIP摘要的独立记录保存，不回写历史包和自动测试结论。
