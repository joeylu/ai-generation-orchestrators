# 本机项目与多地图（0.51.0）

启用项目工作区后，`/` 是独立项目管理入口：卡片显示项目名称、地图和素材数量，
提供搜索、新建、项目 ZIP 导入与每个项目的重命名、复制、下载。卡片封面直接展示
该项目的一张原素材，并标注「素材预览」，不声称是当前地图截图。首页只取摘要，
不创建 Pixi 画布，不改作者或历史。点击「进入项目」后打开 `/editor`，左上角
「返回项目」回到首页。浏览器前进/后退会更新状态，避免恢复已销毁的画布或忙碌按钮。

项目包含一套资产与多张地图。顶部项目按钮管理新建空白、复制、重命名、切换、
打开/下载项目 ZIP；地图按钮管理新建空白、复制、重命名与切换。左侧只显示当前
项目素材，右侧仍为图层，其余编辑在画布完成。

## 启动与保存

```sh
node scripts/studio.mjs serve --kit /local/verified-kit --projects /local/ignored-workspace --project-name "场景项目" --port 4176
```

`--projects` 是启动时明确配置的专用本机目录，应位于被忽略的工作目录。可选 `--map`
只作为首次种子。工作区已有内容时验证并恢复，不覆盖；损坏快照阻止启动。未提供
`--projects` 时保持原单包内存编辑模式。同一目录同时只运行一个宿主。

成功操作先写临时文件、同步并原子替换 `workspace.json`，再采用新文档和版本号。
保存失败保留原作者、撤销/重做和版本。版本号持久化，旧窗口不能绕过重启/切换覆盖。
资产按 SHA 存放，项目 URL 独立。复制可共享不可变资产字节，布局互不影响。

同一宿主会话中切换地图保留各自历史；刷新/切换重置浏览器工具、镜头、选择，重启
恢复作者但不恢复撤销历史。项目不包含浏览器显隐、生成授权或人工美术通过结论。
原 PNG、原色、资产包身份保持。没有数据库、账户、云端同步或自动生成接口。

## 导入、下载与新主题

空项目没有素材或有效编译场景。导入 Studio「导出资源」生成的场景 ZIP 后，校验
ZIP、清单、文件 SHA/长度、资产来源及编译回放，再带入素材和自带初始地图。
已有素材项目不允许直接换包；新建空项目导入以避免原引用失效。新主题生成仍走
独立 CLI、准确计算计划确认与美术审阅；这个项目入口不触发生图。

项目模式下「打开地图」JSON 导入为新地图，不替换当前地图，须匹配当前项目资产。
空地图保留网格、边界、相机和图层定义，清除地形/实例/曲线；复制地图保留布局。

项目 ZIP 包含 `project.json`、可选 `assets.zip` 和程序生成的校验清单，带齐全部
地图。重新打开创建独立项目和地图 ID，不覆盖同名项目。「导出资源」仅导出当前
地图及其资产依赖。只支持 Studio 原样导出的 stored ZIP32，重新压缩、加密、分卷、
路径穿越、链接属性、重名或校验错误均拒收。不执行包内内容。

## 边界与验证

单工作区最多8项目，每项目16地图；单资产 ZIP 64 MiB、项目上传128 MiB、引用
资产共256 MiB、布局快照16 MiB，单地图仍受核心2 MiB限制。达到上限保留旧状态；
可下载项目另开工作区。首版没有删除项目、项目内追加素材或多材质画刷功能。

HTTP 只接受固定操作、版本号、不含路径的项目/地图 UUID 和上传字节：

- `POST /api/projects`：创建、复制、切换、重命名及地图 JSON 导入。
- `GET /api/projects`：项目列表摘要，不返回作者或编译场景。
- `GET /project-previews/UUID.png`：该项目固定原素材封面，无请求选路径。
- `GET /api/projects/UUID/export?revision=N`：不切换当前项目即可下载指定项目。
- `POST /api/projects/assets?revision=N`：为空项目绑定资产包。
- `POST /api/projects/import?revision=N`：新增经过验证的项目。
- `GET /api/projects/export?revision=N`：下载当前完整项目。
- 原 `/api/edit`、`/api/export` 作用于当前项目的当前地图。

同源检查和请求读取后版本复检覆盖全部修改，不接受请求指定的路径、命令、适配器。
列表中的复制显式绑定来源 UUID，允许复制非当前项目的全部地图和素材；下载不改变
当前选择。浏览列表和搜索不写工作区，进入项目只更新当前选择和全局版本，不改作者。
失败导入保留现有作者和历史；验证临时目录仅在配置工作区内，验证后安全清理。
未引用不可变文件不自动删除。运行测试只用合成资产/替身及独立软件 WebGL；
真实场景检查只核对当前项目、作者指纹和显示，不更改美术验收或生成记录。
