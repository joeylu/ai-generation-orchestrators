# SDK rc.8：仓库网格

发布标记为 `ui-panel-harness-v0.1.0-rc.8`，版本合同为
`release/contract.json`。使用该标签下的完整SDK归档，并按 `SHA256SUMS` 与
`release-receipt.json` 校验字节数及SHA-256；不要将工作区候选当作正式归档。
rc.7及更早标签、归档和保存面板保留原字节。

默认目录更新为 `modern-readable-game-grid-layout`。固定库存行一次声明行列、
格尺寸、间距、内边距和填充方向，程序展开全部格子。10×10精确得到100格，
未提供物品时为空；缺省容量为5×6，格尺寸72×72，间距及内边距8。
每格有独立Panel，物品名称或固定图标及数量可显示；单选状态、宿主事件、
尺寸编辑、导入、撤销和交付包往返保持一致。小容器横向滚动，固定列数不折叠。
当前单面板库存容量上限144格；超限请求需澄清。

库存面板使用PanelSpec/Bundle0.17、Compiler0.46和编辑上下文0.17；
默认规划上下文0.12、原生意图0.13。普通面板仍使用0.16/0.45的内容排版。
复用既有16种基础组件，不新增基础运行时依赖。UGUI源适配器更新为0.1.9，
库存选择通过既有枚举事件对接宿主；原生Unity导入与交互未执行。

四条短口令真实验收为三份交付和一次正确超限澄清，四次调用、零自动重试。
原始三份结果通过浏览器首格点击、键盘末格选择及固定SDK精确重开；
10×10还通过390宽屏幕横向滚动后的末格点击。离线完整回归2152项通过。
发布重建包的安装、浏览器、样本往返及CI证据以标签下报告为准。

运行时不读取外部skill，不生成美术，不连接实际仓库服务。物品移动、拖拽、
堆叠、排序和持久化业务需由游戏接入另行实现。固定样本不等于任意口令或
重复生成稳定率的保证。详见[库存合同](inventory-grid.md)、
[真实验收记录](inventory-grid-real-results-2026-10-16.md)及[SDK使用](sdk-release.md)。
