# 静态正文换行与内容高度

modern-v3 面板支持首次生成和后续编辑的静态 Text 正文自动换行。用户可以说：

> 生成角色命名面板，包含下面三段说明、角色名输入框、确认和取消按钮。说明原样展示并自动换行，面板宽480，高度上限560；确认提交角色名，取消仅通知。

> 把提示正文改成下面这段话，自动换行，后面的输入框和按钮随内容下移；其他内容和行为不变。

程序按当前正文可用宽度分行，再计算行高和正文行的高度。英文优先在单词之间换行，长网址可在完整字素之间断开；中文常见开闭标点随相邻文字。显式空段落保留。原文完整保存在 Spec 中，显示时不绘制行尾空白，行首缩进转为位置。超出已有面板/画布高度时沿用 `layout.overflow`：scroll 允许滚动，error 拒绝整批，不使用省略号截断。

## 协议

首次生成使用 PlanningContext 0.9 / PanelIntent 0.10，声明 `textWrap: static-text-wrap-v1`。每个原生 text 行必填 `wrap:"word"|"none"`。程序将 word 映射为 Spec 0.13 的 `textLayouts`，保留完整正文并测量高度，不要求模型计算行高或渲染行。没有换行条目的新方案仍使用合适的旧 Spec 版本。全局行序号包括所有正文和按钮，跨分组及页签连续；正文换行不会改变提交或重置引用。

Studio 自动启用新协议。直接调用 `createPlanningContext` 时用选项 `{actionLayouts:true,textWrap:true}`；省略选项仍生成旧上下文，已有文件及其摘要不自动迁移。长正文不会参与未指定面板宽度的无限扩展；显式宽度、视口上限及 overflow 继续受确定性布局门禁约束。生成仅接受 modern-v3 主题的正文换行。

新编辑使用 EditContext 0.8，声明 `textWrapPolicy: static-text-wrap-v1`。新增操作：

```json
{"op":"set-text-wrap","rowId":"intro","wrap":"word"}
```

`wrap:null` 清除该行换行设置。只有现有静态 Text 行可作为目标。可以同轮 `set-text` 加 `set-text-wrap`，也可添加 Text 行后同轮为新行开启换行。点选一个控件时仍限制为该控件；选中输入框或按钮不会得到正文换行操作。

启用后升级为 Spec/Bundle 0.13、编译器 0.13.0。必填 `textLayouts` 为 `{rowId,wrap:"word"}` 的唯一目标列表。已启用换行的正文最多 1000 个 Unicode 码点，允许 LF/CRLF 和 Unicode 段落分隔符，拒绝其他控制字符和孤立代理项。没有启用换行的正文仍为单行、最多 120 码点；新版本还检查单行可用宽度。清除换行前需确保正文能放回单行，否则整批拒绝。

正文标签放在正文上方。每行降为独立 Text 节点，第一行保留原控件 ID，后续派生 `.line1` 等 ID；空段落占用一个行高。Pixi 和 Unity UGUI 导出复用相同分行与位置，不依赖两套引擎自行决定折行。组合时按来源命名空间重映射 `textLayouts`。现有输入值、字段、动作和事件保持原样。撤销及十轮计数沿用原规则。

## 验证与边界

`tests/text-wrap.test.mjs` 覆盖中英文、网址、表情/组合字符、标点、空段落、增删、回缩、滚动、整批拒绝、旧上下文回放、组合、状态、撤销及 Unity 数据映射。`tests/codex-planner.test.mjs` 用替身验证实际 CLI 输入 schema、指导和返回路径；不会调用模型。

本轮使用程序方案在后台 Studio 应用修改，验证实际 Pixi 渲染、输入/提交、刷新和交付包。证据位于本地 `output/text-wrap-accepted-v1/`。它不代表真实模型已经能稳定理解所有相关表达，Unity 编辑器原生导入本轮未运行，跨机器字体像素一致性未承诺。

首次生成补充测试在 `tests/initial-text-wrap.test.mjs`，覆盖三段正文、空段落、网址与字素、宽度和滚动、跨页序号、提交范围、按钮横排共存、继续修改、撤销和组合。CLI 入口使用内存子进程替身，不产生模型调用；这证明生成通路接受合同内方案，不证明真实模型对所有表达的理解成功率。浏览器与交付证据另存于 `output/initial-text-wrap-accepted-v1/`。

按钮、标题、普通行标签的换行，多行输入、条件显示和动态文案不属于本项能力。旧版本 Spec、上下文和交付包按原版本重放，历史失败报告不改写。
