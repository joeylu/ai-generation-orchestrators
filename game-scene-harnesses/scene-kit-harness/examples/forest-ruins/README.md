# 森林遗迹首图草案

主题“森林遗迹”和画风方向“清爽手绘：轮廓清晰、低纹理噪声”来自用户选择。
配色、光照、具体环境构成和工程数值是待审建议；本目录没有用户接受记录或计算授权。

- [结构草案](spec.json)：纯侧视，林地、固定遗迹结构、连续地形、台阶、缺口和实心悬浮台地。
- [画风草案](style.json)：规则预设，无风格锚点；不能冒充已经有图像样本的风格包。
- [能力声明](capabilities.json)：本试样只声明文生图/PNG；不声明精确尺寸或模块透明能力。
- [首图选项](reference-options.json)：最多一张完整原生画布，横向、短边至少 256、单边最多 4096。

建议画面为浅青绿远林、苔绿植被、暖灰残墙和拱券，柔和日光，主要地形边缘清楚。
主视觉展示一屏内容；不在一张图中挤入四屏地图、模块图集或标注。
64 格宽地图和 1024×576 视窗沿用工程候选，不是原图尺寸或正式像素密度承诺。

从 Harness 目录准备一个新私有目录：

```powershell
npm run reference:prepare -- --inputs examples/forest-ruins --out ../../work/my-forest-reference
```

程序只创建三份草案、可审阅的完整提示词和非执行 proposal。工作区事件数为 3，
已接受设计、冻结计划、授权、尝试和实际生图均为 0。程序拒绝覆盖已有目录。
宿主声明不证明任何服务或具体模型已实测；4096 是接收上限，不是输出尺寸保证。

后续先审准确结构/画风摘要，再冻结原生参考计划，按新计划取得一次计算确认。
实际图片须保留原字节并另行审阅；接受参考图不授权模块生成。原生参考图协议与
精确模块合同的边界见 [生成交换说明](../../docs/generation-v1.md)。
