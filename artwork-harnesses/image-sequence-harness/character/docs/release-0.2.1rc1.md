# 0.2.1rc1 — Docker 验收候选版

本版冻结固定 4×4、16 帧的 character Harness，供后续 Docker 环境验证。
这不是已经完成生产验收的稳定版，不包含 Docker 镜像或部署脚本。

## 封版范围

- 普通参考图准备、已有透明前景复用和指纹绑定的参考审核。
- 固定布局与动作计划、单次授权、异步提交回执、查询及失败状态。
- 严格尺寸校验、整板透明结果校验、切帧、连续 alpha、时间线和审核后交付。
- 可选的 queued_image_mcp_v1 provider 适配器；服务端点和密钥环境变量在私有配置中提供。

MCP 是当前实现的可选 provider 接入形式，不是生图模型名称，也不要求 Codex 宿主。
当前并没有实现任意 provider 的动态加载注册机制；新增 provider 仍需适配与回归测试。
运行时可通过 HTTP MCP 调用服务；宿主原生 MCP 转发只做过私有验收实验，实验脚本不随包发布。

## 实测边界与已知限制

一次参考图生图 MCP 调用已取得真实图片，但要求 1024×1024 时返回了 1254×1254。
程序正确以 board_dimensions_mismatch 拒绝结果，没有把失败改成成功。
本版继续要求原图严格匹配计划尺寸，不自动重采样或绕过校验。

用户手动提供抠图结果后检查过独立播放预览，动作效果得到认可，抠图边缘质量一般。
这不是正式 PNG/GIF/manifest 交付验收，也不是自动云抠图验证。
手动图片不能伪造为 cloud_matte_handoff_v1；本版尚无手动抠图来源的正式导入入口。

Docker 中的网络、鉴权、工具发现、实际生图、参考图及整板云抠图均仍需验收。
尤其需验证 provider 实际输出尺寸、16 个角色保留、透明边缘、循环与最终打包校验。
遇到客户端访问拒绝应记录错误并排查服务准入，不能通过伪装请求特征绕过。

## 分发

wheel 用于安装运行时；源码 ZIP 包含 Agent Skill、文档、示例及离线测试。
SHA256SUMS 校验文件用于核对这两个候选制品。源码 ZIP 使用明确文件白名单。
私有配置、密钥、原图、生成结果、任务日志、宿主桥接脚本、缓存与旧构建均不包含在制品中。
候选包仅供验收；正式生产推广仍需通过验收并以不可变版本标签和摘要发布。
