# Artwork harness contract
- Preserve the user's subject identity, proportions, materials, and requested
  asset type. Do not invent a missing character part or silently change a prop.
- Agent instructions, deterministic tools, model/provider adapters, fixtures,
  and generated run artifacts are different things. Never commit run artifacts
  or private model configuration as Harness source.
- A planned Harness is documentation only. Do not add a discoverable Skill,
  executable claim, or success example before its implementation and tests exist.
- Existing nested contracts may tighten these rules for background removal,
  image sequences, or video sequences.
