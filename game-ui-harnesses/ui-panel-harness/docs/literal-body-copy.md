# 完整说明正文

首次生成支持保留完整的多句说明；句号、分号和说明中提到的确认、取消行为都不能成为截断位置。
静态正文按实际可用宽度换行，输入框和按钮随内容高度排列。

可以自然描述，也可以明确标出需要逐字展示的范围：

> 说明正文按原文完整展示并自动换行：“角色名会显示在排行榜和好友列表中。确认之前可以继续修改；取消只通知宿主，并保留本次输入。”

包含较多引号或换行时，可用 `【正文开始】` 和 `【正文结束】` 包住内容。
外层范围标记不显示，内部文字、缩进及空段落保留。

当前原生生成边界在既有来源校验之后，检查明确的完整正文声明。
引号、正文标记，以及后面单独开始的已命名输入框属性句可限定内容范围；单个句号或分号不能。
没有明确边界、存在修正或历史示例时仍由模型解释，不能据此声称所有自然语言都已自动核对。
程序只拒绝缺失或缩短的明确正文，不补写、不修复模型输出、不自动重试。
澄清仍是合法结果，已保存的意图和 PanelBundle 不自动迁移。

回归使用固定请求和进程替身，覆盖多句正文、分号、嵌套引号、换行、指令样文字、缺失正文、澄清和旧文档兼容；不调用模型。
