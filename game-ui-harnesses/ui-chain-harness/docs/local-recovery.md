# Studio 本地自动恢复

2026-10-16。此机制只继续必需图集收齐后的确定性处理：四张组件图集，以及启用材质模板时的第五张 S05。它不调用模型，不自动补图，不改变已有生成授权或失败记录。

## 用户会看到什么

新建项目确认生成后，四张组件原图全部收到；若批次包含 S05，还须收到其完整回执。随后自动进入组件定位、拆分、切线、组包和检查；S05 按独立固定槽位提取并绑定材质。关闭制作页面不取消处理。Studio 中断后再次启动，会检查已保存记录，并继续可以安全恢复的本地步骤。

暂时性的文件占用、执行超时会自动恢复；等待期间显示“正在自动恢复本地处理”，不显示重复处理按钮。通过后的节点复用原回执，未完成节点产生新的尝试记录。组件完成后进入可预览状态，外观验收仍保留。

以下情形停止并显示原因：质量检查失败、源图/产物/回执改变、工具版本改变、旧锁无法确认归属、未知处理错误或自动次数用尽。需要时仍可手动“继续本地拆分与检查”。工具更新后手动继续会从原始图集创建新处理记录；已完成的包不会重建或切换。损坏的证据不能靠手动继续绕过。

## 自动边界

| 情况 | 行为 |
| --- | --- |
| 必需四图未收齐，或批次包含的 S05 未收齐；模型失败/结果不明 | 不自动处理，不重投模型 |
| 已有通过回执 | 校验摘要/依赖并复用，不重复该节点 |
| 本地处理进程仍活着 | 等待，不抢锁、不扣启动次数 |
| 拥有锁的进程已不存在 | 安全回收本机锁后继续 |
| 无法确认进程状态、旧版空锁、回收保护锁异常 | 保留文件；需要检查，不按锁的年龄猜测 |
| `EBUSY`、`ETIMEDOUT`、本地命令超时 | 有限续跑，不涉及模型 |
| 检查失败已记录、流程摘要尚未保存就崩溃 | 恢复时读取失败证据，仍停止质量/未知错误 |
| 用户明确补生成后，最终计划或原图摘要改变 | 来源修订改变；为未完成的旧任务创建新任务，不续跑其冻结旧图 |
| 已完成组件、历史面板调用 | 保留原包；面板调用不自动重投 |

补图需要新的计划摘要和一次明确确认。已收到但原始检查为 `rejected` 的图集也可显式单张补生成；原图、检查、回执和失败结果全部保留。成功补图后，Studio 以有效图集的 `sheetId / planSha256 / rawSha256` 计算来源修订；批次摘要不变也能识别新来源。旧失败任务的输入和回执不改写，新来源开启新的有限本地处理轮次。已完成包继续保持不可变。

模型结果已记录为 `returned`，但本地接收中断、缺少 receipt 时，使用“检查并恢复已返回图片（不生成）”。程序核对冻结计划及已保存原图摘要，只补缺失的接收文件；已有 claim、原图或 inspection 不一致会停止，不覆盖、不重投。此操作属于显式原图接收恢复，与本节的自动本地拆分恢复分开。

这是单台机器的进程互斥与有限定时回调，没有后台服务、队列或分布式锁。Studio 退出后不会启动新的恢复；重开 Studio 才继续。跨主机搬运运行中目录、极端磁盘写入损坏、PID 重用导致无法确认状态等情形仍可能需要维护处理。

## 维护入口

- `configs/local-recovery-policy.json`：默认最多 **3 次自动启动**（含第一次）、暂时错误间隔 5 秒、已有进程等待间隔 10 秒，最多检查 90 次。等待不增加自动启动次数。显式手动继续会开启新的恢复次数区间。
- `flow.json.localRecovery`：程序维护批次摘要、有效来源修订、自动启动次数、最近的分类原因，重启不清零。`processingSourcesRevision` 标识当前冻结任务使用的来源修订。它们是流程索引，不替代 DAG 原始回执。
- `auto-process.json`：保留最初的自动处理批次绑定；文件存在不再意味着“永远不能恢复”。绑定不一致时停止，不覆盖。
- `src/studio/auto-process.mjs`：新项目 opt-in、四图或五图收齐条件、重复事件合并和有限等待。只使用生成 `status`，没有生成/恢复收图/补图调用入口。
- `src/studio/pipeline.mjs` / `local-recovery.mjs`：冻结任务复用、有限恢复、错误分类与用户提示。HTTP 仍仅暴露既有操作，不能由请求参数指定自动调用策略。
- `src/skins/local-lock.mjs` / `task-dag.mjs`：本机进程锁与不可变步骤回执。只有确认原进程不存在才回收，互斥保护回收竞争；不使用超时抢占存活进程。
- `scripts/studio.mjs`：成功监听端口后才恢复项目。第二份 Studio 因端口被占用而启动失败时不会触发处理。

政策、程序更新仍进入工具摘要。旧的未完成任务不会忽略版本变化自动继续。未设置 `automaticProcessing: true` 的历史项目不会被自动加入。

## 验证与局限

离线回归覆盖实际强制结束 DAG 子进程、回执字节不变、并发抢占只有一份成功、失败后重启、持久次数上限、质量失败跨崩溃保留、旧包不被重建和零生成调用。浏览器检查使用测试替身，覆盖恢复提示、暂停原因、手动继续及完成后项目库状态。

这些验证证明本地恢复行为，不代表模型总能返回全部合格图，也不代表任意美术风格都能自动通过切分、九宫格、材质和可读性检查。因此仍不能承诺所有新项目全程零干预；离线回归与真实模型生成证据须分别记录。
