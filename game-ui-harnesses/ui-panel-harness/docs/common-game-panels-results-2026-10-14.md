导航、键盘焦点可以把滚动区域中的按钮带入视野，因此交互PASS不能推出首屏可见。交互前测量发现G02、G18、G21、G26、G41、G59的按钮被面板、画布或页签视口裁切；G43、G44还存在默认主体滚动。页签标题观察现只统计当前页；其他页的首屏单独记录，避免把隐藏页标题误报为当前可见标题。

## 已完成的离线优化

1. 当前PanelIntent原生接口允许混合Text/Input等内容区携带actionLayout，最终Spec却要求该排列只包含独立Button。已将0.11上下文的原生schema区分为普通区(actionLayout:null)与纯按钮区，保持返回结构及校验门。原始无效意图仍拒绝，不修补内容、不重试。原生行名称增加与现有Spec一致的非空、长度和非空白约束。
2. 为action-layout、target、rows、size、circle及Text wrap错误增加固定诊断代码和允许的字段路径。实际夹具可以复现action-layout-rows，现在保留该代码与 `$.actionLayouts[0]`；原始私有消息与未知字段仍被抹去。
3. `fitDraftPanelLayout`新增显式 `draft-content-fit-v2`，支持逐页测量及验证的内容图片闭包，保留List内部滚动；v1及固定尺寸边界保持。原始41份重放中只有8份尺寸变化，状态、动作、绑定、标题、内容、资源与业务字段均保持，失败项仍保留为失败。
4. 自动生成的0.16方案使用concise-v3/visible-v3主题，且maxHeight与canvasHeight均为null、overflow:auto时，默认高度按完整内容测量。明确高度、明确滚动及历史主题仍走原行为。这是当前主题的确定性几何调整，不是模型失败后的修复。Studio默认目录仍为历史版本，没有切换或重启日常Studio。
5. 实验提示约束按钮使用自然动作名、实现说明不进入玩家面板、未知错误原因和解锁条件不作断言。用户口令保持原样；这项提示改动尚未做真实模型复测。
