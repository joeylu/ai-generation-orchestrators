# UI Reference Harness 0.8.2

修复 Codex CLI 转发已生成图片后，较大的 PostToolUse 回执被统一 2 MiB 输入限制拒绝、缺少审计凭据的问题。

- PostToolUse 有限上限为 96 MiB，与现有 CLI 单条结果边界一致；PreToolUse 请求维持 2 MiB。
- 严格 UTF-8、完整 JSON、会话及工具调用身份、原始图片独占保留、冻结参考摘要检查继续执行。
- 后置凭据仅保存身份字段，图片响应正文不进入凭据或执行日志。超限、截断、错误身份仍终止，不伪造成功。
- v0.8.1 已完成图片继续可检查、验收和交付；旧计算计划不可派发。未知尝试保留原图和记录，不自动补凭据或重投。
- 延续 v0.8.1 的项目主参考与隔离风格预览流程。API、前端操作和修改预算不变。

消费方安装新的不可变标签、完整提交及附件摘要，逐文件校验并核对 runtime 与 Hook 字节摘要后更新启动信任。不要编辑 vendor 或放宽全局信任。

新增回归使用合成回执和真实本地 Hook 子进程，覆盖 2.19 MiB 回执、请求/响应边界、无效 UTF-8、截断 JSON、错误身份、原图缺失、重复回执和参考图变更。
发布过程不调用图片模型。离线测试不代表 Docker 实际生图已验证。

完整边界见 [Hook 输入合同](relay-hook-input.md)。
