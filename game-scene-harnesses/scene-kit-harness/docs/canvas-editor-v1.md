# Scene Kit 画布编辑工作台

交互版0.57.0（Harness源码0.78.0）。从[项目管理页](studio-projects.md)进入/editor，左上角可返回项目页。组合卡片展示按真实素材与相对布局编译的缩略图，原点纹理相位可随实际落点变化。右侧按[通用父级职责](layer-parent-standard-v1.md)组织，主题名留给实际素材。用户主要通过鼠标在画布中搭图：左侧是模块库，右侧只保留图层树；
文档摘要、工程证据、地图元数据与常驻数值属性不占用编辑区域。Studio 仍是确定性的
本机编辑器。项目可启用[环境素材生成入口](environment-library.md)，由独立本机进程按确认的计划执行，
Studio 负责审阅和入库。

## 鼠标操作

| 位置 | 操作 |
| --- | --- |
| 左侧环境/组合库 | 拖到画布释放，或先点击素材再点击画布放置。 |
| 左侧画刷库 | 启用「地形画刷」后卡片高亮并显示勾选，左键拖动画布绘制；切换其他工具时取消标记。也可拖入画刷绘制一格并继续选用。最终图块由邻接规则决定。 |
| 左侧素材分组 | 素材和组合按图层职责折叠浏览。「平台 → 环境」列出主场景摆件，「平台 → 地形」收纳画刷、曲线和带地形的组合。生成素材的卡片保留发起分组，放置时优先选对应图层，缺层时随首次放置创建。场景中的实例按实际图层显示。其他素材优先按地图上的使用位置归类，未放置时沿用资产包首选层。 |
| 左侧曲线库 | 拖出丘陵/谷地/缓坡，或先点击条目再点击画布放置；单击卡片不修改地图、不扩图。 |
| 画布对象 | 选择工具下点击不透明部位选中，可自由拖动或按住 Ctrl 按格移动；角点等比缩放。透明区域尽量穿透选择。 |
| 整块地形 | 选择工具下拖动地形实体；相邻格子、已连接曲线、附着外壳一起移动。格子按整格、独立曲线按像素移动。 |
| 曲线封底 | 整块拖近地图底边或相邻封底时显示吸附线，拖远解除；端点合并自动对齐小幅封底差，一次撤销恢复。 |
| 对象浮动工具条 | 复制、删除、缩小/放大、恢复尺寸；组合先展开再编辑内部地形。 |
| 画布顶部 | 选择、画刷、擦除、曲线、平移、撤销、重做；无需快捷键。 |
| 画布曲线 | 曲线工具下双击表沿加点并选中新点；拖动圆点调整表沿、方点调整切线；端点靠近兼容接头显示吸附，松手提交。 |
| 曲线上下文工具条 | 添加/删除点、合并端点、连接/解除格子平台、删除曲线。 |
| 画布浏览 | 滚轮缩放，中/右键拖动或使用平移工具；右下角有缩放、默认镜头与全图按钮。 |
| 图层树 | 点击对象选择，双击聚焦；眼睛控制显隐，文件夹控制展开，锁控制该层编辑。 |
| 文件区 | 项目模式每笔自动保存到本机，「下载地图」另存JSON副本；非项目模式使用「保存地图」。另可导出素材ZIP和切换Play Mode。 |

对象与曲线的数值输入收在画布内弹层。画布选项收纳扩建、地形外观、曲线模板和按格
放置。输入数值后可按 Enter 应用。空值、非整数坐标或超出范围的斜率会在对应字段下
提示，焦点回到该字段。撤销用 Ctrl/⌘+Z，重做用 Ctrl+Y 或 Ctrl/⌘+Shift+Z。
输入法组合期间保留文字输入，编辑字段内保留原生撤销。

按住 Ctrl 拖动独立素材时，横竖位移按地图的格宽、格高取整，保留素材原本在格内的偏移。
拖动中松开 Ctrl 即恢复自由移动。松开鼠标时提交当前预览的位置。

窄屏用顶部模块库/图层按钮打开抽屉。手指在素材卡片上纵向滑动可浏览列表，从卡片
横向拖向画布可放置，也可以先点卡片再点画布。编辑中第二根手指触碰会取消未提交
的笔划或放置；抬起后可以开始下一笔。

0.55.0统一选中与放置反馈：从图层树选择对象后，原画刷/素材高亮随实际工具更新；
素材放下转入选择工具时取消库内放置高亮。普通环境点击放置使用鼠标位置，组合仍
按格；曲线左端按格、表沿高度按鼠标确定。Esc可退出待放置状态，选择工具也是鼠标
取消入口；旧向右扩建小样仍在曲线工具的明确按钮中。

属性浮层与画布选项互斥，点外侧或Esc收起。窄屏抽屉点画布外侧先关闭，该次点击
不会同时绘制或移动；按钮公开展开状态，进入Play Mode收起抽屉，Esc可退出预览。
项目弹窗里的导入失败/容量超限/打包反馈在弹窗内可见，不依赖后面的画布提示。
正在保存时明确显示进度；连接中断后显示「保存结果待核对」，不会自动重发编辑。
提交画刷笔划后，画布保留该笔预览并提示等待，保存完成后可继续绘制。
静止画布复用上一帧。镜头、选框、笔划、显隐、调色预览和动画画面变化时触发重绘。
另一个窗口先保存时，旧窗口显示「版本已变化」。可以从「下载 → 地图 JSON」保留
该窗口里的副本，再刷新读取最新版本。地图 JSON 读取期间若编辑已保存了新版本，
会提示重新选文件；连续选择文件时只处理最新一次读取。

双击加点只命中距表沿10屏幕像素内的位置，不在地形实体内部随意加点；缩放不改变
鼠标命中半径。新点沿原Hermite曲线计算高度与切线，整数坐标舍入误差约半单位。
已有圆点/切线柄保留选择与拖动；单击不写文档。相邻点至少32世界单位，每条最多32点；
太近、满额或局部切线超出既有范围会提示并保持地图和历史。隐藏、锁定及Play Mode
不能插入。双击一次对应一个可撤销命令，原有工具条“加点”使用同一规则。

整块移动选择的是四邻接格子片及其完整组合、显式格子/曲线接头的连通组。纯曲线
移动所有控制点和封底，保持坡形；含格子的组同步移动连接坐标、附着平台外壳与
组合装饰，保留作者ID、包装、切线和原PNG。普通背景、前景等独立素材保持原位。
贴着落下的格子可能成为新的连通片，下次会一同选择。拖动时显示整块预览，松手
单次提交；Esc、右键、失焦或丢失捕获取消。锁定/隐藏的关联对象会阻止整块移动。
地形仍受地图边界、横向域和不重叠规则约束；非法落点整批回退，不自动扩图或断接头。

0.54.0的[分层地形](layered-terrain-v1.md)允许平台位于曲线上方或下方，共用横向
范围而不撞实体。相关编辑与显式v6升级一批提交、一次撤销；旧文件不因浏览而升级。
上文水平域规则仅适用于旧格式。组合预览按真实表沿和占格提前判断，实体冲突显示
红色；边界接触不自动接头。独立上层平台不会被并入下方曲线的移动片。

松手后保留最后的移动/缩放外观，等待本次编辑校验：成功时正式场景在同一次更新
接替预览，避免回原位闪动；校验拒绝或请求失败才清除预览。此期间不修改客户端
作者，也不重发请求；输入暂时禁用。已经松手提交后失焦不会取消待接收外观，拖动
尚未释放时的取消语义保持不变。

## 画刷列表

主库按画刷显示条目，不把自动拼接编号当成不同工具。当前只有「地形画刷」，缩略图
取当前家族的顶面拼片，点击仅改变编辑器选择，不修改地图。按住拖动绘制，擦除和
整笔撤销继续调用既有核心。图层锁定/显隐、边界和地形附着限制保持。

曲线连接的格子平台可直接加台阶或擦除。Studio按整笔最终占格检查固定矩形接头，
需要时先显式解除失效接头，再编辑格子；两步放在同一原子批次，一次撤销全部恢复。
曲线坐标与其他格子不改，仍有效的接头保留；解除后的平台与曲线可分别移动，画布
会显示提示。锁定/隐藏的曲线不能被隐式断接；无效或实体相交的笔划整批回退，
不会留下已解除的接头。普通画刷不切割坡体，独立平台应位于曲线实体外。

宿主生成 `brushes` 定义数组，每条含稳定 `brushId`、`kind`、名称、说明、`familyId`、
缩略图ID及只读拼片ID列表。`src/studio/brushes.mjs`集中注册类型对应的工具和命令，
界面按列表渲染；当前只注册terrain，不展示未知类型。增加其他画刷时需实现对应处理器
及核心命令支持；仅增加名称不代表能力已实现。现有核心仍绑定单个地形家族。

画布「… → 拼接预览（高级）」保留47种只读形状，首次打开才加载，不参与工具选择。
原图、变体、规则和导出资产均保留。外观切换会更新画刷缩略图和高级预览，不改变
作者家族或把试样自动写入导出。画刷选择属于编辑器状态，Play Mode下仍明确禁用编辑。

组合卡片显示中文名及真实形状/平台原图缩略图。库内拖拽使用页面指针捕获，移动超过
6屏幕像素才进入拖放，点击放置仍可用。拖动中显示整组占格，基础检查通过为绿色，
超出地图或与已有格子地形重叠为红色并说明原因；最终仍由核心完整验证，绿色不代替
全部曲线/贴图约束。含地形组合优先选择指定的1倍视差环境层，再选择当前或其他1倍
视差层，避免背景/前景视差破坏组合。普通素材的自选图层行为保持。

Esc、失焦、pointercancel、lostpointercapture取消库拖放；预览不改地图，一次松手
只提交一个批次。Play Mode下卡片明确禁用，退出后恢复。地形锁定和显隐仍受尊重。

## 文档与状态

一次拖动在释放时提交一个原子命令批次，一次撤销恢复整次操作。拖动预览不写文档；
按住左键时用右键取消，或 Esc、窗口失焦、pointercancel、lostpointercapture 均丢弃
未提交手势。非法位置/几何整批拒绝，保留地图与历史。
点选素材后的画布放置也在画布内释放时提交。按下后拖离触点或移出画布可取消这次放置。

作者结构合法也可能超过原生地形的mesh/三角/工作预算。构造、命令、撤销、重做和
导入均需先完成候选编译，再修改文档与历史；HTTP会话在fork上准备完整响应，
项目保存先验证候选state，再落盘和推进revision。编译失败沿用原错误并保留文档、
历史、版本号及上个可读场景，不能先提交再因生成响应失败而返回422。

Studio 的增量编辑请求同时校验编辑版本和浏览器持有的编译场景摘要。可复用的地形网格以旧场景
中的索引随响应返回，浏览器据此重建完整场景供 Pixi 和编译 JSON 下载使用。导入、旧
客户端和可复用网格很少的操作仍可接收完整场景。

普通独立视觉实例可等比缩放至基础显示尺寸的 0.125—8 倍，UI 精度为 0.001。
首次缩放使用 `enable-instance-transforms` 加 `transform-instance` 显式升级为
`ai_scene_document_v4`；升级和变换是同一个可撤销批次。v4 继承 v3 的曲线/混合地形，
增加 `instanceTransforms: [{instanceId, scale}]`。没有变换的旧地图继续按原版本保存，
取消手势和只浏览不会升级。编译、JSON 与 ZIP 重开保留变换。

0.48.0 的 `ai_scene_document_v5` 允许普通独立视觉素材的锚点落在地图外。首次框外
拖入、移动、复制或缩放时，同一手势先执行 `enable-free-placement`，保留已有曲线、
连接和缩放；一次撤销恢复升级前地图。框外素材也是作者内容，保存/导出保留坐标，
重新打开仍可选中、移动回地图。数值仍受既有有限坐标及资源预算限制；旧v1—v4不
隐式放宽语义。固定预设内部、网格、曲线及绑定地形的terrainSkin仍遵循地图规则。

## Play Mode

顶部只需点击一次 Play Mode，立即按 `defaultCamera.viewport` 的长宽比进入游戏
视口，不再额外勾选游戏视口。入口使用地图默认镜头，鼠标左键拖动浏览长地图，镜头
约束在地图内，启用已有视差。网格、碰撞建议、选框、编辑工具和浮层不进入预览。
渲染遮罩取游戏视口与地图边界的交集；框外可继续暂存素材，跨框素材只显示落在
实际视口内的部分，不修改PNG或作者坐标。退出 Play Mode 恢复原编辑镜头与缩放，
不改作者、选择或撤销记录。这是场景画面预览，不增加角色或物理模拟。

地图尺寸恰好等于游戏视口时，两轴都没有游戏镜头移动空间。0.56.0在Play Mode
顶部提供「自由镜头」切换：开启后拖动画布可平移、滚轮可缩放，镜头可越过地图
边界；再次点击恢复真实游戏视口尺寸与边界约束。按钮只在预览时显示并以按下态
标记自由镜头。游戏/自由镜头之间切换不会覆盖进入预览前的镜头快照；从任一状态
退出Play Mode都恢复该编辑镜头与缩放。此选项不扩建地图、不更改默认相机或作者。

地形网格、重复条带、绑定格子的 terrainSkin 和完整组合不支持自由缩放，避免破坏
邻接与碰撞语义。组合可整组拖动，内部地形须先展开。首次打开有限场景不会自动扩建。

相机、工具、选择、图层/对象显隐、折叠和锁是临时编辑器状态，不写作者文档或导出。
图层树当前用于选择与显隐/锁定，尚无跨层拖排、旋转或多选变换。对象锁定范围为所属
图层。地图JSON仍可下载；未启用项目工作区时只在内存编辑，启用工作区后每次成功
命令原子保存到本机，见[项目文档](studio-projects.md)。

普通组合地形可直接擦：Studio按实际擦到的格子规划显式展开，并和擦除合为一次命令
批次，一次撤销恢复原组合、装饰和地形。擦到空隙不拆组合，重复绘制已有格子不请求
修改。锁定/隐藏与取消保护保持。整张平台外壳不逐格裁切或换材质；可选择删除整件
平台组合，已展开为外壳实例时先移除外壳再编辑底下地形。核心CLI仍须显式展开。

只调整显示几何，不改原 PNG、Alpha、tint 或 opacity。原色来源不会因编辑布局自动染色；
生成计算、来源与最终整图美术接受继续独立管理。宿主的回环、路径白名单、同源和
严格 CSP 边界沿用 [Studio 合同](studio-v1.md)。

## 验证

新增核心用例覆盖显式升级、非法变换的原子回滚、原图/颜色身份、导出重开、撤销重做
与角点比例。鼠标浏览器用例覆盖原生库拖拽、角点缩放、移动/取消、鼠标历史、显隐/锁、
复制/删除、下载及桌面/窄屏；合成夹具和软件 WebGL，不调用图片模型。

既有浏览器回归改为从可见画布工具进入；纯渲染像素比较暂时隐藏 DOM 编辑浮层，保留
原有纹理/接缝断言。全部接缝采样保留，通过鼠标将采样域移入视口，未跳过边缘样本。
浏览器只放行当前测试宿主的回环端口，外部请求被拦截，不降低 CSP 或宿主路径限制。
