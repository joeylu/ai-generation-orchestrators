# Video sequence contract
- One generation authorization permits one plan-bound provider submission. Never
  automatically resubmit an accepted or indeterminate request.
- Deterministic processing may repeat from the same raw-video SHA-256.
- A 4x4/8x4/8x8 atlas family shares one raw source, one probe, one decode, and
  one semantic interval. Grid capacity does not force an exact frame count.
- Preserve the rational source timeline and the loop/one-shot endpoint semantics.
- PNG alpha is authoritative; GIF and spritesheets are derived artifacts.
- Character and prop profiles need separate prompt and visual acceptance evidence.
