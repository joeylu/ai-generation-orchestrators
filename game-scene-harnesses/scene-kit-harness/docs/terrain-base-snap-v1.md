# 曲线封底吸附

源码0.54.1的Studio手势策略，不新增作者字段或放宽核心合并规则。
`terrain-base-snap-v1`：12屏幕像素，封底修正最多8世界单位；邻侧检测最多64世界
单位且同受12像素限制。界面缩放不扩大到远处吸附，大幅高度差仍需用户编辑。

## 整块移动

鼠标实际拖动至少3屏幕像素后，在原有整数偏移上寻找封底参考：相邻兼容曲线优先，
然后是地图底边。只修正整体Y平移，点、切线与封底相对关系保持；含格子组不能
因此获得非整格位移。地图上界、下界和曲线控制包络仍约束候选。

绿色底线与“封底已吸附”显示当前目标，拖出范围即解除；松手只提交原move-terrain
命令，一次撤销恢复。点击、加载、取消或浏览不归一已有封底。已释放预览继续
使用既有待接收交接，不提前写作者，不增加提交或自动重试。

## 端点合并

小幅封底差导致CURVE_JOIN_BASE时，Studio先规划自由曲线的封底修正，并预览合并。
移动侧自由时将其封底对齐静止侧；移动侧连着格子时，保留其固定封底，显式替换
自由目标的封底后合并。两条命令仍在一个原子批次里，一次撤销恢复双方和原接头。
其他控制点不因封底修正平移，正在拖动的端点继续遵循原来的接头吸附。

双方固定、差距超限、材质/轮廓不同或修正后深度不足不自动对齐。核心仍要求准确
相同封底并执行完整几何/连接验证；失败保留作者及历史。现有严格CLI/来源计划
不静默获得此策略。吸附是编辑器状态，原PNG、颜色、生成与美术审阅记录保持。
