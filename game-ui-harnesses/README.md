# Game UI harnesses
This category covers HUDs, menus, controls, icons, image layers and UI components.

- [UI references](ui-reference-harness/) — implemented local source preview:
  panel prototype intake, project style revisions, six default/custom UI packs and user style PNG,
  digest-bound generation exchange, native-resolution coordinate mapping,
  human acceptance and same-style PNG/ZIP sets.
  Real generation requires an external adapter or host tool. Six default samples and
  one same-project three-panel pilot have been accepted for reference use; a reusable
  project-plan command freezes pending panels after the first accepted anchor.
  The optional [local reference workbench](ui-reference-harness/web/README.md)
  provides project/style/prototype management, explicit generation exchange,
  visual review and validated ZIP downloads on loopback only.
- [UI panels](ui-panel-harness/) — implemented natural-language panel prototypes,
  interactive preview, structured specifications and portable panel delivery.
- [UI layers](ui-layer-harness/) — implemented source preview: reference planning,
  image generation exchange, foreground registration and PNG layer ZIP delivery.
  Visual results require acceptance. The old decomposition producer is
  [retired](ui-layer-harness/docs/DECOMPOSITION-RETIREMENT.md).
- [UI components](ui-component-harness/) — implemented local compiler, 16 PixiJS
  component types, portable bundles, separate motion, Web acceptance and offline
  CLI/Skill. Online vision is unconfigured. See [tasks and evidence](ui-component-harness/docs/tasks.md).
