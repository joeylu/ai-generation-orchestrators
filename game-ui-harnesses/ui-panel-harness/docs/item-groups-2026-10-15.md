# 同一条目的信息和操作共用分组

Studio／SDK新生成默认使用 `modern-readable-game-item-groups`，主题0.32.0／0.32.1、`concise-v6`／`visible-v6`、Compiler0.45。正文与按钮24、主标题32，普通单列420、按钮菜单360，既有数据底板和语义分组底板保留。0.44及更早的目录与保存包不自动迁移。

本轮修正的是一件商品被拆散的问题：模型曾把两件商品的名称、价格、购买按钮全放在同一section。内层数据底板已生效，但商品归属仍靠顺序和留白区分。

- 默认生成提示明确：重复条目如果跨多行，每个条目使用一个语义section，包含自己的说明、数据、进度和相关按钮。商品、任务、成就适用同一规则。
- 页面余额、总体统计与条目分开；条目自己的操作留在条目内，页面级／独立操作才放在Button-only组。单个List或综合Text已经表达完整条目时不必拆成更多section。
- 编译器按声明的section生成真实Panel，不根据中文标签、按钮名字或相邻行自动猜测归属。用户的短口令无需额外填写分组清单，也没有运行时skill注入。
- concise-v6保留v5标题规则，并在普通数据section标题与本组已有settings.text标签或完整值完全相同时隐藏重复的标题显示。含Image的卡片保留原有标题和居中规则。标题和数据原文仍保留；不会按部分相似、关键词或语言推断。明确要求显示标题可选择同主题visible-v6。

这次将刚完成的0.44真实商店样本明确重分为余额和两个商品组。五条数据、两个购买按钮、原文、行序、行ID、事件、状态和素材保持；只改变分组及对应几何。其他9份真实样本采用0.45后的编译画面文档与原版精确相同。0.44原始回答、bundle、ZIP及授权记录没有改写；新产物是明确的离线修复，新增模型调用0。

夹具 `tests/fixtures/item-groups-regressions-v1.json` 仅含公开Spec、状态、目录、原包摘要和明确审阅的行归属。它不参与运行时规划，也不作为模型答案。新版默认提示是否在新真实调用中自然生成正确的条目分组，尚未复测；后续模型调用需要新的固定计划授权。Unity原生尚未运行，rc.7仍未发布。
