# UI Reference Harness 0.8.3

优化同步 PNG 验证及项目状态、运行状态、DAG 查询中的重复计算。API、前端 UX、生成、验收和修改预算合同不变。

- 解码保留全部 CRC、格式、尺寸、输出上限、五种过滤器和支持的色彩模型。无过滤扫描行批量复制；RGBA 无须逐像素重建临时数组。
- `verifyResult` 保留原图/规范化 SHA-256、逐像素 alpha=255、非空图、尺寸/坐标映射，以及 level 9 重新编码后的完整字节一致性。不同原始编码还比较解码后的全部 RGBA。
- 同一同步遍历只验证一次相同证据。按内容摘要复用规范化计算；原图与规范化字节相同只需一次解码。
- 缓存不跨请求/await。缓存命中重新读取依赖文件，比较完整字节、路径链接安全及缺失状态；同尺寸/恢复时间戳的篡改仍被拒绝。返回对象与私有缓存隔离。
- 0.8.2 已完成结果继续可检查、显式验收与交付；旧计算计划不能派发，未知尝试不补造记录或自动重投。
- 包含六份历史样本 ZIP 的 CI 修复：仅提交松散合成夹具，测试时临时重建并核对原始摘要。

大图离线回归与实测结果见 [验证与性能回归](validation-performance.md)。真实模型调用为零，不包含 Docker 实机部署验证。

生产须安装新的不可变标签及源码附件摘要，逐文件校验并核对 runtime 与 Hook 摘要。保留旧运行时、项目、原图、会话和交付，不修改 vendor。Hook 字节、API 与前端合同未改，Web 无需为本次优化调整 UX。
