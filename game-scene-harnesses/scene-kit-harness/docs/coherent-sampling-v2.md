# 显示密度与派生分辨率 v2

0.57.0新增 `ai_scene_coherent_composition_v2`。公开 `deliverCoherentPipeline` / `coherent deliver`
未传显示配置时，自动冻结一个空transforms的v2配置并写入交付。旧交付验证从它自己
绑定的配置重放；没有配置及显式v1配置仍保持原派生规则，不更写历史产物。

## 修复的问题

旧规则先将整个Alpha包络放进参考图中的粗包络，再测平台表沿并拉到网格宽度。
薄平台周围存在Alpha=1的零星像素时，包络包含大量几乎透明的空间。沙漠实例
2172×724的原图因此被缩成135×50，实际表沿93px再放到192世界像素，导致模糊。
环境主体经作者放大也会出现同类问题。改采样模式无法找回已经丢失的细节。

## 封闭配置

v2延续v1的batchSha256、targetSha256、transforms和可选layerOrder，增加唯一固定值
`sourceSampling: "display-density-2x-v1"`。transforms可为空，其余身份、位置、比例、
白色不透明背景、图层排列及禁止变换物理平台的约束不变。无Alpha阈值、轮廓清理、
任意文件、代码或自选滤镜字段。该配置是确定性派生/作者数据，不提交图片计算。

## 分辨率规则

- 环境/背景保留旧逻辑适配尺寸，用最终显示缩放计算约2倍存储像素；源像素与4096px
  边长为上限。尺寸使用最多1/16的公约比例，保持横纵比例一致，模块显示比例反向补偿。
- 平台在未缩小的原PNG上测量原有Alpha≥128表沿，仅用于落脚基线与尺寸测量，不修改
  RGBA。以网格落脚宽度×2决定派生像素，直接从既有完整内容包络重采样。新表沿再次
  测量，模块显示比例将其严格映射到原网格宽度，碰撞占用与位置保持。
- 派生只从原PNG取样，从不放大旧小贴图；不超过原生分辨率，不下载或调用模型。
- 原内容包络及原Alpha不改，Alpha=1像素不作为自动清理目标；仍使用连续Alpha加权
  重采样、透明处RGB归零和派生图2px透明边距。原PNG逐字节保存。
- 平移、层序、tint与opacity沿用作者数据。地形连续材质的47角色/32取样派生不变。

placement证据记录源裁区、逻辑适配尺寸、实际PNG尺寸、目标和实际像素密度。
来源不足时仍可按原显示比例使用，但密度不足不能被报告为额外细节或生图成功。
2倍密度是初始作者显示尺度的目标；用户继续大幅放大仍受原图分辨率限制。

## 验证

合成薄平台包含远处Alpha=1像素，重现先缩小再放大的退化；检查新表沿像素密度、
严格网格落脚宽度、原PNG字节、连续Alpha、透明RGB、环境逻辑尺寸、闭合配置及
旧规则重放。浏览器使用软件WebGL，核对实际截图与地图/ZIP下载；不执行真实生图。
