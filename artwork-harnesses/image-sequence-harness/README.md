# Image sequence harness
**Status: character profile implemented; prop profile planned.**

Create coherent transparent animation frames directly with image-generation
tools, without using a generated video as the temporal source. Character and prop
profiles have separate maturity levels. The [character profile](character/README.md)
provides the released fixed 4×4, 16-frame contract, CLI, Skill and offline tests.
The [prop profile](prop/README.md) remains documentation only. Character support
does not imply arbitrary frame counts or an implemented prop runtime.
