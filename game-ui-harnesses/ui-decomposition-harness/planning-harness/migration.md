# 与现有实现的关系

本次只精简合同设计，没有实现新入口、删掉旧检查或迁移默认链路。
此前十模块设计中的参考登记、坐标解析、分组预算、编译和 preflight 收入三个模块内部。
v3 移除了 v2 的 textRegions；v4 进一步允许无冲突的同层素材，由程序派生唯一绘制编号。
当前 v5 将裁片区域直接放入 materials[].bboxNorm，objects[].bboxNorm 默认 null。
M2 改用素材标框；同层碰撞按素材框保守检查。历史 v4 仍保留对象框检查及包络派生语义。
历史 v2/v3 仍按原唯一层级规则验证，没有自动迁移，也不修改历史实验数据。
固定文字排除沿用原 assets-only 生成提示词策略，不引入 OCR 或逐条文字定位。
当前目标固定默认 static-composite，宿主仅附加用户明确的局部独立编辑要求。
independent-assets 尚未验证，保留为未来议题，不自动路由或宣称已支持。

## 接旧链路必须明确的缺口

简化视觉合同不含 foreground_support、visual units 的拆分说明和全部关系。
现有 v2 要求这些证据，因此不能把新 JSON 直接换名为旧 brief 后冻结。

兼容适配需要消费 M2 实际复核/测量得到的具名证据，按旧规则检查完整性。
缺失时返回问题，不填零留白、不把框换算当测量、不自动设置 reviewed=true。
若认为某项旧要求应取消，另行评估并修改规则、补充回归；本次不做这种改变。

首版不做复用或素材板：重复对象按独立素材计数，多个固定对象可共同组成一份素材。
这可能增加生成调用数，M3 必须展示预算并尊重上限，不能为了过预算静默改变分组。
原有复杂优化路线仍可使用，新路线暂不追求覆盖全部能力。

## 实施与验证顺序（待实施）

1. 实现 M1/M2，先能得到可复核的视觉 JSON 和标框，不进入生图。
2. 实现 M3 适配，用离线 fixture 验证指纹、字段映射、复核绑定、失败定位与旧门禁。
3. 复用现有 freeze；新入口先 opt-in，原入口的行为与测试保持。
4. 固定图片、目标、模型设置、环境，再测请求接收、回答落盘、修订、编译、冻结耗时。

不以结构通过声称视觉保真，不以更少字段声称更快，不用不同拆分目标计算加速比。

## 当前实验实现补充

独立 experiments/ui-planning-m1 已实现 M1/M2 调用、可选一次局部补丁及 M3 离线候选编译。
M3 产出真实参考裁片、提示词、位置和兼容旧结构的计划候选；旧证据缺失时明确阻断冻结。
上述未实现事项仍包括生产入口、完整辅助证据适配和 M3 冻结集成，原生产链路未迁移。

实验已增加独立快照冻结（ui_visual_frozen_experiment_v1），保存并校验请求内容；
它不是旧 batch 冻结或生产执行适配。仍缺旧证据，不允许用该快照绕过原生成质量门。

独立实验执行器已获用户选定并实现（experiments/ui-planning-m1/experimental_executor.py）：
使用独立 job、授权和串行图片交换状态，不适配或降低旧执行门槛。只能到原始图片接收，
抠图/归位/视觉验收不在其完成范围。已准备任务不代表已授权或实际调用图片服务。
