# SDK rc.6：简短口令默认规则

源码和本地安装包统一使用 `modern-compact-message` 目录，保留 16 种底层组件。
默认生成采用经过真实短口令测试的共享草稿提示；日常入口不再依赖测试脚本替换提示。
未知业务事实仍需澄清；预览数据属于示例，按钮通知游戏宿主。

分组标题采用 concise-v4；明确要求显示小标题时使用对应 visible-v4。
无标签确认正文选用 `message.text@0.2.0`，保留内部语义标签与完整正文。
编译器 0.36.0 按正文测量高度，居中短句和操作组，长段落保留左对齐。
明确给定的尺寸、按钮顺序、状态和事件保持；其他完整组件面板使用 0.34.0。
静态角色占位图保持中性，不声称跟随选择变化。
内部规划提示补齐每组 Select、Radio、List 恰好一个默认选项和 Tabs 初始页的约束。
明确指定的默认值保留；不支持的无选中／多选要求应澄清。严格校验仍拒绝无默认或多个默认，不自动补选。

旧目录、旧编译版本和保存包不自动迁移；显式选择旧目录仍保留其原规划提示。
Studio 的已打开静态构建需重新启动；SDK 消费者需安装匹配的新归档。
发行标记为 `ui-panel-harness-v0.1.0-rc.6`。下载完整归档并核对随附的 SHA256SUMS 和 release-receipt；旧 rc.5 归档保持原字节。

上一轮工作区记录 `docs/compact-message-results-2026-10-14.md` 的 8 次真实测试验证了这组规则；该批历史运算记录不属于安装包。
默认接入阶段使用本地夹具。随后的日常 8 类真实复验交付 7 份，背包因选择默认项约束失败；调用 8 次、重试 0。
