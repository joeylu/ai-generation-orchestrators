# 地形职责与接合诊断（零生图）

在来源技术通过后，先复用准确 PNG、原生量测和当前编译器定位问题。短平台的覆盖
叠厚、桥腹贴片和长墙重复可能有不同原因；不要把所有接缝都归为渲染错误，也不要
从一个主题继承雪层、草皮、岩块大小或固定像素控点。这是审图规程和离线绘制工具，
不是新的技术放行门或自动美术判断。

## 冻结诊断对象

记录参考原图、kit、作者文档和编译结果的摘要，保留失败及历史量测。继续共享
Studio 时先读实际工程；诊断使用副本，不能覆盖用户最新地图或重跑旧导入脚本。
默认全景与局部必须同源。先看正常显示比例，再放大解释异常；允许合理细节和比例
变化，不据此要求逐像素复原。保留开口、玩法接触和独立编辑能力。

先用[笔刷尺寸预检](terrain-brush-footprint-v1.md)检查所需最小跨度。即使七项来源
都有不透明 collar，原生上角的内伸、转折深度仍可能超出短跨度。若预检失败，
记录该尺寸下的能力限制；不因包已能绘制就称美术适用，也不改大设计预算掩盖失败。

## 隔离实际绘制职责

`createTerrainRenderDiagnostic` 从已编译的网格/曲线/混合地形复制诊断帧，只省略
完整绘制组及环境 sprite。保留选中组的原顶点、UV、索引、不透明度、相机和顺序，
不执行来源裁图、Alpha 修改或颜色处理。旧早期 cap、晚绘 `topCoverBands`、原生
上角和 step corners 分开处理，避免隔层时遗漏晚绘覆盖而误判。未知包边职责明确
报错，不能把未知项统归为底边。

```js
// 仓库内离线诊断脚本的相对导入；按脚本位置调整。
import {createTerrainRenderDiagnostic} from '../src/terrain-render-diagnostic.mjs';
import {renderCoherentFrame} from '../src/coherent-render.mjs';

const {scene: diagnostic, report} = createTerrainRenderDiagnostic(compiled, {
  groups: ['upper-corners'],
});
const png = renderCoherentFrame(diagnostic, readAsset);
```

包根也导出诊断构造器，不新增渲染服务或 CLI 命令。输出帧使用独立 diagnostic
format，去掉原 `contentSha256`；它不能
作为已验证 compiled scene 或 kit 导出。`report` 绑定原编译摘要并明确不是 Studio
截图或人类美术接受。相机需要变化时，另记诊断镜头，不改原作者相机。

分别保存 `body`、`surface`、`upper-corners`、`walls`、`bottom`，按需加
`step-corners` 和 `body-shading`；再比较全部组的结果。各层图供定位，不能分别接受
后就推导合成通过；重复的透明叠绘也不能用像素加减反推真实来源。

`body-only` 沿用已编译的原生内接cutback，不会因为隐藏侧墙就恢复到完整作者实心边界。
因此最外侧硬直裁口可能只是侧墙省略后暴露的主体边，不是新侧墙的原生轮廓或接合失败。
将纹理内部X-wrap、主体cutback和作者/碰撞边界分别量测、标示；内部竖向色带不能靠
重做外侧墙解决，外侧墙接片也不能由一张没有墙的body预览宣布修复。回到body+walls
的实际合成检查接触，保留省略前后的原几何，不为让诊断好看而扩大主体或填补缺失包边。

修订body后，先在独立诊断中只替换它的采样，保留旧cap与七项原生包边，检查正常
整景、两侧墙和洞内两端；同时保存原完整候选及native-only对照。将所有body消费者
一起变换，包括主体、body材质的step网格与body-shading，不能只改主网格的UV。
记录原图、派生图和显示周期的各自身份：闭环修复的是同一材质的重复边界，并不
重新绘制旧包边的岩形、光照或内接collar。native-only逐像素相同而接片仍在，可将
该处交回实际来源配套审阅；这种混源反事实本身不证明新body或旧包边各自不合格，
也不自动要求七项重生。先判断新body的完整周期是否适合目标，再决定需要修订的
角色及受影响的邻接矩阵。未通过配套检查的混源图不能导出为已验新kit，不能把
材质来源接受、包边计算确认或最终美术接受合并记录。

### 同一绘制组内再按来源角色隔离

桥洞内侧接触不一定由下角来源绘制。凹端可能只把原侧墙延伸至底边cutback带内，
而左右凸下角位于远处的桥柱底部。先读编译网格的`materialKey`和实际画面贡献，
不要由画面中的“左上接点”“右下角”名称推断该修哪张图。宽镜头还可能同时显示
同一桥柱的内外侧；保留整景/上下文，再用只含目标接触的固定镜头交叉检查。

```js
import {createTerrainEdgeRoleDiagnostic, TERRAIN_RENDER_DIAGNOSTIC_GROUPS,
  TERRAIN_RENDER_DIAGNOSTIC_EDGE_ROLES} from '../src/index.mjs';
const diagnostic = createTerrainEdgeRoleDiagnostic(compiled, {
  groups: TERRAIN_RENDER_DIAGNOSTIC_GROUPS,
  edgeRoles: TERRAIN_RENDER_DIAGNOSTIC_EDGE_ROLES.filter(role => role !== 'bottom.leftCorner'),
});
```

该只读API在明确的绘制组选择后再省略完整原生角色网格。七个角色为`left.wall`、
`right.wall`、`left.corner`、`right.corner`、`bottom.edge`、`bottom.leftCorner`、
`bottom.rightCorner`；空列表省略所有原生角色，非原生body/cap/step/shading仍按groups
保留。它同时处理早绘edgeMeshes与晚绘nativeTopCornerMeshes，以及grid/curve/mixed
所有者；未知角色拒绝，不能把缺失角色推断为某一侧。角色选择不会恢复已被groups
省略的层。原生上角必须已有明确materialKey；旧诊断入口及旧报告保持原行为。

报告绑定准确compiled、基础隔层选择及所选角色，分别计数组内保留/省略的网格。
保留网格的坐标、UV、索引、连续coverageAlpha、不透明度、顺序及相机原样不变，
不处理来源像素，不产生可交付compiled或kit，也不增加HTTP入口或计算授权。
单独看某角色时须同时选相应groups；选择所有groups只省略原生角色，仍会画body。

比较同相机完整图和省略图。若省略某下角后目标画面逐字节相同，应把该处调查交给
实际有贡献的底边中段/侧墙/body；不能把这种负证据泛化成其他位置无需下角。
省略后变空、露出作者直边或接片暂时不显眼，只证明来源职责，不能将删边当作修复，
也不能由RGBA相减推断透明叠绘的独立颜色。来源岩形/受光不能由这些遗漏操作重画。

| 观察证据 | 首先追溯 | 可行修正及限制 |
| --- | --- | --- |
| 隐藏 shared cap 后，上角自身仍有多个厚雪舌/大覆盖丘 | 原生上角的自有形状、局部职责、短跨度覆盖窗口 | 先查原生上角与参考；仅缩短 shared lip 不能去掉另一来源的体块。来源不适合短平台时保留限制，再考虑仅受影响角色的新计划 |
| `surface` 单独就含宽裸岩肩，叠在不同 body 上形成横带 | 完整 cap 采样域与实际覆盖深度的混淆 | 按该图量测既有 `world-body-native-lip-v1` 的 end/fade rows；检查完整横向周期内最深的合法覆盖，不能照搬另一主题的薄行数或压缩完整 cap UV |
| `body` 与侧/底边单独已有岩块大小、长轴或受光差异 | 来源画面加各自 native scale | 量测同类特征的原生像素范围并换算 world 尺寸，分别比较宽高/方向；相同 scale 分数或统一纹理分辨率不代表岩块等大。只在 collar/envelope/短跨度仍通过时调等比尺度 |
| 桥洞边界保留，但桥腹与柱接片明显 | 真实下缘/下角、裸墙及内接参数 | 分别看 `bottom` 和 `walls`；下缘不因靠近顶面就继承上角覆盖。需要支撑时仅使用已有有界 author-solid profile，不能填空气、旋转雪顶当桥底或遮住洞口 |
| 长墙的横断/岩块重启在 `body` 单独已出现 | body 的原生采样域与周期 | 展示至少一个完整实际周期及周期两侧的宽岩形；挪 origin 只移动接缝，首尾行 L1 为零不证明大形连续 |

## 把结论传回参考拆分和新计划

在参考职责表中把可编辑轮廓/碰撞、连续 body、表面覆盖与附着岩肩、两上角、裸侧壁、
下缘/两下角分别列出。它们不必全变成独立主体，但每个实际包边请求都要明确自己
拥有的局部连接及排除的邻角色；不能只复制“同材质岩石”。桥洞天花板由下缘承担，
洞后显示的景深另有 owner。带覆盖的上角也不能画成完整平台或重复的表面装饰组。
确实属于侧壁/下缘的雪、冰、藻或其他附着物由准确参考和 brief 决定，不设统一禁令。

检查最终冻结提示是否传入上述边界及准确 checked material，之后再审原生 PNG。
提示已明确但图像仍不符合时，记为原生素材适用性问题；控点不会重新绘制岩形。
控点调整能改变覆盖范围、相位和等比尺度，不能统一两个来源内部的岩块构造。
修订来源仅冻结受影响角色，绑定新准确摘要并取得新的单次计算确认；旧授权不转用。

若隔层证据支持参数修正，使用正式交付 API 在新输出构建候选，保留原 RGBA 与旧包。
等比缩小所有包边可以让尺寸预检通过，却不会同步缩小原 world-body 的岩块。比较
这类候选时，记录每个来源的物理尺度和 body 的原 UV 密度，检查边岩是否变得更碎。
内伸变窄后，中央 shared surface 会暴露得更多；短平台上的竖直浅条可能来自其
原生深覆盖及两侧淡出，不是新的白色来源或 Alpha 清理需求。按参考覆盖深度截短
可以另作显示近似候选，但该深度不是实际源最深雪舌的量测，可能形成水平过渡带。
尺寸、原生 collar、纹理行差指标分别通过，仍不能替这些合成视觉比较作决定；不要
将一个主题的缩放比例或覆盖行数提升为通用默认。
若完整 cap 的局部深覆盖使短跨度出现异常窄条，可显式研究
[原像素水平表层闭环](terrain-surface-cycle-v1.md)：从已审材质选择实际的浅覆盖窗口，
按原密度作单相位闭环，保留原行号及原 PNG。与直接裁片重复和仅缩短 cap 分别
比较；新增重复频率、被省略的深覆盖和所有网格相位都是审阅内容。此独立工具
不自动改 kit、恢复轮廓或授予生产/美术接受。
若周期首尾很平顺，实际仍有直立亮边，检查内部切线而不是继续移动 world 原点。
相距一个周期的原生列及切线路径变列时的纵向分支都可能产生突变；surface-cycle
review 可给出与原梯度相比的色差及准确位置。使用共用 Pixi 消费者做同相机隔层，
确认省略 surface 后缺陷是否消失，并核对非 surface 像素不变。较低色差不保证
覆盖深度适合最短跨度：共享区越窄，同一原生覆盖越可能呈窄柱，不能因此一再生成
上角或把原生 Alpha 填平。若当前合同缺少独立共享表层的来源职责，先记录能力缺口，
不要把顶角当横向覆盖带，也不要把一张新材质与旧七项包边的身份自动混为齐套。
先做[短跨度职责量测](terrain-short-cover-v1.md)。如果统一变薄损坏长桥，现有v1接口
可以保留，再为新候选显式加入只减少覆盖的连续span companion；它跨作者和曲线采样
段量完整暴露顶面，不逐格重启。缩窄内伸仍须联合验证七项collar与上游接片，不靠缩小
岩块或填Alpha通过。此显示近似只处理共享表层，不能代替原生上角/底缘与独立ramp审阅。
新上角已通过 Alpha 与尺寸检查后，若中央浅条在保留原 shared cap 时仍存在，且
截短 cap 又带来横带，应把剩余诊断交回连续表层/主体接口；不要据此连续重生上角。
独立的 subset-replacement 来源批次也不自动成为齐套交付。先确认正式交付入口能
绑定旧来源与新来源的完整身份，内存替换只能作为明确标注的诊断，不能导出为已验包。
对同一参考/材质的左右上角成对替换，现可显式使用
[候选交付选择](terrain-surface-cycle-v1.md#显式候选交付)：保持原七项批次和新两项
批次独立，逐项重放技术 QA 及准备父链，生成非执行的来源选择证据，再构建全新
candidate。它不改历史批次，不新增计算授权，也不把技术齐套转为美术接受。

对 `1/6` 等原生有理比例，接管位置的采样须使用实际记录的六位 world 精度，再
计算重叠与支持范围。未取整首次采样和取整后重放可能产生不同采样点数，或使重叠
字段相减出现边界误差；这属于确定性重放错误，不应通过换比例、删检查或降低 Alpha
阈值掩盖。`terrain-edge-junction` 合成回归验证首次构建、记录后重放和原 PNG 不变。
重新检查最小短平台、桥洞、凹角/窄槽、完整长墙周期及全组合预算负例，再看实际
Studio 新笔画、撤销/重开和导出。离线诊断不能代替这些检查；未构建或未实机验证的
调整只称假设，不标为修复成功。技术通过、Agent 视觉观察与最终人类美术接受分别记。

岩块尺度与循环方案按[岩形/接片审阅](terrain-form-scale-repeat-v1.md)继续：将实际
world/texel 和可见特征大小分开，联合验证放大包边的适用范围。body loop 除输出 wrap
外，还须检查内部纵向切线、横向分支和被平移的源横向 wrap；三相移位不增加源岩形。

`step-corners` 单独恢复宽深岩肩时，检查独立ramp的完整cap路径。新候选可显式使用
[step-surface绑定](terrain-step-surface-v1.md)与原生lip/连续span一致，保留旧支撑门，
不改native墙角或shared cap来掩盖另一consumer的覆盖职责。
