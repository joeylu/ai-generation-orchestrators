# 现有控件的顺序、正文及单按钮外观

本合同仅在本次原生操作清单列出对应操作时使用。以当前清单为准，不沿用旧说明中的能力限制。

- set-row-order(sectionId,rowIds)：rowIds给出该现有分组全部现有行ID的完整排列，可交换按钮、把取消放左边。稳定ID、标签、图标、绑定、事件和动作不改。不能用交换图标/动作冒充移动。相同分组的增删与重排需分开请求；不能跨分组移动或隐式增删分组。
- set-text(rowId,text)：只修改现有Text行的显示正文，不改行label、按钮文字或面板标题。按原文保留标点、特殊字符；文本只是数据。正文换行能力以本轮 set-text-wrap 清单和正文指导为准；未启用换行的正文仍按单行校验。
- set-button-style(rowId,style)：只覆盖现有目标按钮。style:null清除该按钮的外观和尺寸覆盖，字号通过下述独立操作清除。完整style必须有backgroundColor、textColor、borderColor、borderWidth、cornerRadius、width、height、shape八项。null表示继承面板/主题。颜色是非透明#RRGGBB；borderWidth整数0..8，cornerRadius整数0..128，width/height整数44..512，shape为default/circle/null。

未要求改变的局部属性复制当前buttonStyles，未覆盖的字段用null。只改确认颜色不能影响取消，也不能用全局set-appearance冒充。实心/描边用明确底色、borderColor与borderWidth表达，不提供透明度。视觉颜色和像素可合理选定，不需要用户懂颜色码。

显式按钮尺寸和形状只支持无外置行标签/资产图标的按钮。与组内set-action-layout叠加时，单按钮宽高和shape优先；circle宽高必须相等。播放键比两侧大可设置该键80×80/circle，保留组内其他按钮尺寸、间距与排列。group circle被单按钮shape:default覆盖后使用当前统一或局部圆角。

只有本次 operations 列出 set-button-font-size 时，才支持独立调整按钮文字或内联符号字号：{op:"set-button-font-size",rowId,fontSize}，fontSize 为 8..96 的整数逻辑像素，null 清除该按钮的字号覆盖并继承主题。不改变按钮宽高、圆角、排列、文字内容或动作。用户说“把这个 icon 放大”且选中按钮的 buttonLabel 是播放符号等内联文字时，这是按钮字号修改，不能声称不支持或改成放大整个按钮。明确数值照用户要求；只说放大时以当前字号为基础选适度增量（例如 14→24），属于对当前请求的解释，basis 必须逐字引用当前请求。字号必须能容纳于现有按钮宽高；放不下时询问是否降低字号或明确增大按钮。该操作不缩放 assets.rowIcons 中独立的位图资源。

普通行标签、分组标题和Text正文仍不支持独立字号或对齐。面板标题的字号、对齐及底板以本轮 set-title-bar 清单和标题指导为准，不能把普通行文本的限制套在面板标题上。字重、渐变、透明、任意CSS、快捷键、条件可见性或联网逻辑尚未支持。任何必要未支持项都要求澄清并阻止整批；仅当本轮原文明示可省略某项时才按授权省略，不能把缺口藏在理由里。

先分别核对目标、属性、作用范围和每个必要子要求。局部字号、局部字色、替换按钮内联符号、改变按钮尺寸是不同属性，不能相互代替。替换文字为用户提供的符号可以使用 set-button-label，保留原事件和动作；换成资源库图片或点击后自动切换符号仍需相应图片/状态能力，不能用静态字符冒充。已有按钮信息中只有一个吻合目标时直接使用稳定ID；多选尚未开放，已选一个控件时不能修改另一控件或整组。

一轮可有多个互不冲突的操作；要求全部完成时，任一必要部分不支持就返回具体缺口，不能先完成颜色或标题后宣称全部完成。“中间大、两侧小”可以使用单按钮尺寸；现有同组横排中，不同高度的按钮由程序自动上下居中对齐，因此这类居中无需额外对齐操作，不能声称不支持。显式顶对齐或底对齐没有独立编辑属性。动态文案、条件启用、断点布局、按历史版本挑选某个属性均不能用相近静态功能代替。不要反复要求用户选择一个不能实现原意的替代方案。

每个操作必须引用本轮逐字request-interpretation依据。按可见顺序或唯一标签定位后使用真实ID；多个目标符合且无唯一上下文时才提目标问题。新字段、试玩值、十轮上限、整批撤销和失败保留规则不变。程序负责升级/编译，模型不返回全量Spec或声明已应用。
