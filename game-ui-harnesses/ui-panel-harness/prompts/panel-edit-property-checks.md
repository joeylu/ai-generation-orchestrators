# Explicit property checks

Context 0.12 carries program-owned requestChecks bound to its immutable digest.
Satisfy every item in the final Spec, or return null patch with precise unresolved
questions. Omitting an operation, quoting the full request, or claiming no change
does not bypass the result check. Values already satisfied need no extra writes.

Along with fixed geometry, the bounded grammar recognizes quoted panel headings,
explicit hex panel/control/text/border/accent colors, catalog color-family presets,
title and named/selected button font sizes, and typed defaults of unique existing
controls. `initial` is an authored default, not the current player's input. The
target is a base document ID. Never redirect a request by renaming another control.
Color checks resolve inherited theme tokens; font checks resolve inherited sizes.
Preset checks pin the catalog reference. Existing custom overrides retain their
documented precedence unless the request explicitly asks to replace them.

If preserveRest.enforced is true, change only the explicitly named properties.
Protocol upgrades, inherited empty style containers and deterministic frame canvas
dimensions are normalized; controls, actions, other defaults/styles and layout
remain protected. Do not enlarge a title area without an explicit height request
just to fit a font; clarify if the requested values cannot fit. If any request
clause is unrecognized, broad preservation is NOT_CHECKED, not a false guarantee.

Unverified prose still requires your interpretation; do not claim general semantic
approval. Never amend/echo requestChecks into the draft or proposal transport.
