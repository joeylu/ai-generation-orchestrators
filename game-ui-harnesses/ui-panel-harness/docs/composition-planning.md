# 分类型构图提示与编辑输入检查

沿用[当前排版参考](visual-baseline.md)，将设置列表、独立动作菜单、确认弹窗的不同构图原则接入现有 Codex 原生生成、旧版生成运输与编辑提示。实现为 `src/composition-planning.mjs`，由 `src/codex-planner.mjs` 在三条提示路径调用；没有新增 Studio 选项、PanelSpec 字段或第二套 Harness。

设置列表强调标签/滑轨的阅读边界及数值/开关的操作边界；独立菜单强调居中构图和适当按钮比例；确认框保留完整底板、完整说明和均衡操作区。表单、页签、资料与混合内容继续遵守各自的现有展示规则，不强制套入这三类。用途由 Agent 根据完整内容与交互解释，程序没有增加标题关键词分类器。

这些是当前目录与协议范围内的设计建议。用户明确要求的对齐、宽度、方向、顺序与形状优先。未指定的几何仍由已固定的目录和编译器决定，不推断“Apple”就应切换版本、增加图标或删除内容。普通编辑保留未涉及的构图与业务；“好看点”只支持保守的装饰调整，不默许换主题或重做整个面板。必要的业务歧义或不支持的改动仍沿用整批澄清规则。

本次没有将 grouped-v3、字体候选或手工样本参数设为日常默认，没有迁移或改写任何保存包。提示接入不等于自然语言生成已能复现样本美术。独立静态样本页不会因提示变化更新。
