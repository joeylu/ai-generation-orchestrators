# 上下分层地形

源码0.54.0。`ai_scene_document_v6`继承v5的作者字段和自由视觉摆放，新增地图级
地形共存语义；字段仍闭合。v1—v5保持原曲线水平分区政策，加载、验证和重放不升级。

显式命令`{"type":"enable-layered-terrain"}`只接收早期作者，保留旧字段并补齐曲线、
连接和变换数组。Studio在含曲线的相关地形编辑及首次新增曲线时，把升级与操作
放在同一批次，去掉已被v6包含的中间升级。成功一次历史；失败保留旧作者和重做，
一次撤销恢复旧版本。只浏览、改普通景物或打开旧文件不会因此升级。

v6编译为`ai_scene_compiled_v7`，记录`layered-terrain-solids-v1`：

- 格子实体为其网格矩形，曲线实体为编译表沿到封底的闭合多边形。
- 表沿使用现有自适应采样、六位量化后的渲染轮廓，不用总包络或PNG Alpha。
- 不同实体的内部不能相交；相同横向范围内上下分离可放置。边界接触允许，仍需
  用户显式连接，不能因接触或投影重叠而自动合并。
- 相交容差为1e-6世界单位，横向零宽或纵向零深接触不视为实体重叠。现有点间距、
  曲线16条/32点、4096跨度、2048采样、折边、地图范围、接头矩形及外壳隔离规则保持。

每列格子按高度索引，逐列求曲线真实表沿最低位置，检测矩形内部交叠；曲线间
沿双方采样断点扫描交集，检查固体纵向区间。工作量受现有曲线、采样和格子预算
限制，不增模型或服务。`CURVE_GRID_OVERLAP`在v6指实体重叠，`CURVE_SOLID_OVERLAP`
指两条曲线实体重叠；旧版本的同名旧错误保留原含义。

组合预览用相同的轮廓/格子检查，在释放前显示红色和明确文字；可行位置显示绿色。
仍由核心检查完整提交，前端预览不是成功状态。固定平台外壳仍用原格子矩形表达
几何，不把图片透明轮廓当碰撞，也不修改PNG。上下不同层地形保持独立移动片，
已有格子/曲线接头及外壳只在其显式连通组里联动。

v6保存、场景ZIP和项目工作区均重用现有校验/重放，保留原素材及来源指纹。
编辑/相机状态、技术通过和美术接受保持分开，不增加生图或物理引擎。
