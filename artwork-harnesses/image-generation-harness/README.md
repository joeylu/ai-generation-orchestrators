# Image generation harness
**Status: planned**

Create one game-art reference image from an Agent-understood request. Initial
profiles are expected to cover characters and props. This is not the direct
sequence-frame generator and is not implemented by the current repository.

Planned inputs include subject description, style, view, and canvas constraints.
Planned outputs include the original generated still, provider-owned attempt
evidence, and a reviewable manifest. No CLI, provider contract, Skill, or quality
gate is published yet.
