# 0.2.1

首个正式发布的 character image-sequence Harness。公开核心保持 provider-neutral，
只在当前独立目录内提供固定 4x4、16 帧的角色动作图片链路。

## 发布内容

- 固定 4x4、16 帧、row-major 的生成与确定性切帧合同。
- 参考图云抠图或已验证透明前景复用，以及可移植的
  `ai_reference_preparation_handoff_v1`。
- 生图、参考图抠图和整板抠图分别使用不可变计划绑定的单次授权。
- 异步 MCP 提交、查询、终态回执和不确定提交保护。
- 原始整板、透明整板、候选帧、审核记录、manifest、校验和与交付包验证。
- 可选 `bottom_y` 与 `bottom_center` 对齐，保留未对齐帧并记录每帧锚点和位移。
- 可选 16 项 `pose_blueprint` 与正整数 `timing_weights`，用于动作职责和确定性时长分配。
- 透明 PNG 为权威产物；atlas 和 GIF 为派生产物，GIF 不作为 alpha 质量来源。

## 兼容性与边界

- Python 3.11 及以上。
- 生图来源只要求正方形且保持 4x4 结构，不限制模型返回的具体像素尺寸。
- 不包含 Docker、部署、登录、数据库、队列或私有服务配置。
- 云端适配器是可选集成点；发布不包含真实端点、凭据、模型路径或私有工作流。
- 正式使用前，安装方仍须针对自己的适配器和供应商执行独立在线验收。
- 实验性的 8 帧模板、生图样本和媒体预览位于忽略的 `.test-work/`，不属于本发布。

## 验证

发布前执行完整离线单元测试、CLI self-test、wheel 构建以及对构建产物的隔离安装验证。
测试只使用几何 fixture 和传输 doubles，不访问生成服务、云抠图、GPU 或私有网络。
