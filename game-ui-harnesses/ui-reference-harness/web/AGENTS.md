# Local reference workbench

- The user explicitly requested this local website. Bind only 127.0.0.1 and
  reject foreign Host/Origin requests. No deployment, accounts or database.
- Reuse the parent core; do not manufacture plans, reviews, attempts or exports.
- In the user-approved single-click flow, Generate/Modify is the explicit
  one-image compute decision. The host freezes the current prototype, style,
  source image and feedback, binds that click to the resulting immutable plan
  digest and reserves once. Keep manual host exchange available. No automatic
  dispatch/retry on import, draft save, reload or recovery. UI/API tests use
  synthetic fixtures. A panel session permits an initial image plus at most
  three revision attempts; persist history and enforce the limit on the host.
- Keep project data, uploads, sample catalogs, design concepts and screenshots
  under ignored work/. Never bundle real user images into public source/builds.
- The optional showcase project is read-only. User-created projects are writable.
- Optional provider adapters are startup arguments, never browser uploads or
  stored UI credentials. The default host exchange works without a provider.
