# 未提交v4来源的独立新计划修订

0.72.0补齐已冻结但尚未执行来源的合法修订。原计划和原提示保持不变；用户改变
尚未执行来源的职责或绘画要求时，由reviseCoherentSources冻结新的v4子计划和批次，
新摘要必须获得新的单次计算授权。旧未用授权不会复制给子计划，也不因此增加预算。

资格严格限定为原ai_scene_generation_plan_v27、intent=isolated-layer-v4，父状态为
planned或authorized，且attempt、submission、result、terminal字段全部不存在。
仅改状态标签、执行字段为null或存在历史预留，都不能使已经执行/预留的来源变成
未提交来源。零调用border/canvas准备不属于此入口。既有已返回/终态父项的独立修订
规则继续保持；终态不自动重试。

新计划需匹配同asset、同接受参考和重建目标，并按当前spec/style/能力/scope重新编译。
编译批次前验证所有替换项；不合法的混批不得追加部分记录或改变blob。model仍统一
以planned创建新计划，reserve要求新计划摘要的独立授权。旧授权只能指向原准确
计划，不可被用于修改后的提示；当前批次选中的新方案不执行被替代的旧方案。

此能力不增加plan intent、提示格式或默认请求字节；仅扩充严格可判定的未执行父项
资格。既有计划、PNG、授权、未知终态和人工美术决定保持。它不会修改Studio HTTP
接口、调用图片模型、取消/抹去历史授权，或自动认证生成质量。所有测试为合成替身。
