后续状态：用户认为0.59水车地表比旧版更差，该准确候选已记录美术拒收。
0.60新项目改用[按参考量测的地表](measured-surface-v1.md)，不再默认固定32px过渡。
本页保留0.59合同和当时工程行为，不能将技术通过理解为用户美术接受。

0.59.0 的新项目使用 `ai_scene_coherent_project_v3`，单层职责仍为 v4，

## 来源共同约束

准确参考与粗布局接受后，程序编译一份 `ai_scene_visual_coherence_v1`，绑定
spec、style、requirements、参考原 PNG 和 accepted target。每个单层来源内嵌
同一份合同；批次禁止混用不同合同或把一项降回无合同。修订仍需新的准确预算。

共同要求包括原色、光照、笔触、远近明暗和各材质家族在最终显示大小下的细节
频率。砌石可以比自然崖石细，不要求所有石头同样大小。材质源正向描述表沿、
土/覆盖层、下方岩土作为连续绘画，要求上四分之一保留相邻过渡，而非分开的色带。
背景透视、局部小顶面沿用已接受的整体观感口径。

这些是参考相对约束，**没有自动从像素提取主题标尺**。可在新 brief 中传入
`visualObservations`，仅允许 `lighting/brushwork/materialScale/depth` 四个可选
字符串，每项不超过600字。它们来自明确人工观察，独立封印并在设计状态中显示。
未填写时仍有共同规则，原计划的 Style 段继续包含实际 style.rules。

相对宽高、粗锚点和表沿仅用于回拼元数据，不写入图片提示。图片始终只生成自身，
不能因使用共同规范而携带相邻图层。共享合同不授予美术接受或计算授权。

旧项目可零调用查看新提示：

```text
coherent coherence-review --root PROJECT --out FRESH_DIRECTORY [--observations JSON]
```

它输出共同合同、原参考、前后提示与校验清单，不写工作流、不冻结批次，不复用旧
授权。正式新计划与一次性确认仍是生成前置条件。

## 地形表沿和岩土的关系

旧派生将源图表沿独立压成8px，下方取不相邻的中心岩体；固定行切换会丢掉土层、
覆盖物下垂、裂缝及色块的连续关系。新 `joined-surface-field-v1`：

- 从同一原生材料图按相同横纵倍率采样，body505×253、surface overlay505×32。
- 表沿带从源高1/16开始，保留邻接的覆盖物→土→岩绘画；最后8行仅做Alpha渐退。
- 曲线下方按距表沿的竖向深度与已绑定的源行原点取样，在交叠区接回相同源行；
  横向两者共用world-x512映射。曲面三角插值属于近似，不承诺逐像素重建。
- 浅于32单位的实体裁短过渡带和UV，避免把完整过渡压缩进浅平台。
- 32px带按高度曲线竖向延伸，避免加深法线偏移使原本合法的坡面折叠；旧8/16px
  版本的法线几何保持原样。
- 不绘制草、根或接触阴影，不做语义分割、轮廓清理、调色或锐化；保留原PNG。
  源图本身的硬色带不会凭派生变成自然材料。

格子画刷仍有32相位×47拓扑，使用world-phase覆盖回退；曲线用连续相对深度。
两者不是像素相同的采样。新技术证据区分拓扑边界、材料过渡和实际美术审阅；
允许的32行过渡状态变化不冒充旧8px规则的通过。

运行包使用 `ai_scene_continuous_terrain_appearance_v4`，32px带及有理数
`surfaceOriginInBodyPixels` 随kit校验。CPU诊断图和Pixi共用编译网格、线性采样、
body后surface的绘制顺序；实际Studio截图仍独立保存。

## 构图、接地及未覆盖范围

新默认 `ai_scene_coherent_composition_v3` 将已审ground表沿转为可编辑曲线，
保留所有观测点和实际横向端点，避免floor/ceil扩出整格。端点水平、中间坡度限幅；
侧壁仍按端点垂直封底，**没有推断自然崖壁轮廓**。点间距不足32或曲线非法时
明确停止，不悄悄删观测点。作者使用v6已有实体交叠规则。

可声明 `contacts` 将 `content-bottom-center` 对到一条已审ground表沿。默认仅为
底中心位于其横向范围、距表沿不超过32单位的scenery/landmark提出接地；这是
公开的摆放约定，不能称为自动树根/房基识别。显式位置变换与同项contact互斥。
独立远处基座不会强行吸到主墙。接触处的自然遮挡和材质过渡仍需整景观察。

独立平台暂时保留原格子碰撞与外壳，记录参考表沿到实际落点的worldDelta。
附近位置搜索仍采用保守格子占用，不能宣称已消除所有布局偏差。环境大小/层序
仍可显式调整；没有自动改色来掩盖来源间的风格差异。

验收集中看地形体量、相对尺度、接地、表沿过渡和远近风格。技术/混层失败仍
分别处理，观感项不是每项都新增一次审批。不同主题的合成回归验证机制适用性；
新规则真实生图的跨主题稳定性需要新的预算和人工对照，不能由水车旧素材推断。
