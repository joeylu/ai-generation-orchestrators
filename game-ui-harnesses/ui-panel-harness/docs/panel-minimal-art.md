# 简约面板美术 · minimal-v1

本页记录minimal-v1落地时的历史验证。当前日常目录已采用[纯文字菜单精修默认](menu-defaults.md)，其他类型继续使用本页基础样式，旧包及本页原产物保持。

后续用户反馈：美术仍一般，本版不视为美术验收通过。新的[声音设置局部试稿](crafted-audio-study.md)仅供比较，未替换本版日常目录或历史证据。

用户认为 refined-v1 的生成面板仍不好看，本轮继续打磨实际 Pixi 面板。参考已安装的 ui-ux-pro-max 中的简约排版、间距、文字对比度和控件一致性规则，并对照已有的 Modern Mint 自有重绘。Skill 首次设计系统检索中的落地页结构不适用于游戏面板，没有采用；后续定向查询只取简约视觉与层级原则。

新日常目录为 `examples/modern-minimal.catalog.json`，主题版本 `0.9.0`，`surfaceStyle: minimal-v1`，编译器固定为 `0.19.0`。继续复用 PanelSpec、组件运行时、12个内置图标、Pixi预览及UGUI导出链路。

- 统一中性浅色／炭色表面、四种强调色、正常字重标题、细边框和圆角，去掉标题短线；菜单标题居中。
- 新生成默认使用32px内容边距；紧凑表单默认448px宽，设置默认从560px起按内容测量。明确尺寸、操作布局、局部按钮样式和源素材继续优先；普通编辑不升级保存的主题或重新排版。
- 设置滑杆的标签与数值位于轨道上方；滑杆、进度条、胶囊开关和输入框使用本地确定性生成的专属控件图形。原图标PNG不改写，深色面板减少徽章底色。
- 表单输入框48px高，短错误提示与标签同行，长提示保留独立行；首次打开空输入不显示红字，编辑后的错误正常提示。必填校验和提交禁用始终生效。
- 默认紧凑按钮48px高；Pixi居中文字对齐到逻辑像素。显式按钮尺寸和动作顺序保持原值。

新服务仅额外接受完整内容精确匹配的 `modern-refined@0.8.0` 与 `modern-navigation@0.7.0` 编辑上下文；生成只接受当前目录。旧面板按原版本回放，改变过token的目录没有兼容权限。新主题的边距可能使过小的组合尺寸失败，例如夹具的640px页签组合无法容纳明确指定的三按钮宽度，672px通过；不会偷偷压缩按钮。
