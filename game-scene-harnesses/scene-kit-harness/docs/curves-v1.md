# 侧视曲线地形原型 v1

0.54.0新增[作者v6上下分层规则](layered-terrain-v1.md)，允许横向重合而实体不相交。
下文保留旧v2合同，旧文件原有分区和编译字节不静默改写。

源码 0.14.0；本页保留 v2 曲线合同及 0.10.0 端点合并。策划通过控制点编辑丘陵、谷地与缓坡，同一轮廓派生石土填充网格、
草沿网格和碰撞建议。它是确定性的地图编辑扩展，没有新生图，也不代表派生美术接受。
本合同不覆盖洞穴、倒挂、垂直断崖、角色运动或物理引擎。

0.11.0 的矩形格子/曲线接头仅在显式 v3 中启用，见 [混合地形合同](mixed-terrain-v1.md)。
下述 v2 分区、文件及重放规则保持；不会把新混接行为静默加入旧版本。

## 作者格式与兼容

原 `ai_scene_document_v1` 及其编译输出保持不变；不会自动添加曲线字段。
显式 `enable-curve-terrain` 命令将草稿升级到
[`ai_scene_document_v2`](../schemas/scene-document-v2.schema.json)，新增必填 `curveTerrains`。
v1 继续拒绝该字段，v2 不允许省略或使用未知字段。空数组允许保留升级后的格式。

```json
{
  "curveId": "ground.hill",
  "familyId": "terrain.primary",
  "profile": "sideview-height-curve-v1",
  "baseY": 576,
  "points": [
    { "x": 64, "y": 448, "slope": 0 },
    { "x": 512, "y": 256, "slope": 0 },
    { "x": 960, "y": 448, "slope": 0 }
  ]
}
```

这是单条曲线字段示例，须置于完整 v2 地图内。位置和封底使用整数逻辑坐标，Y 向下；
`slope` 为控制点的 dy/dx，范围 [-2,2]。该限制只约束锚点切线，不是整段最大坡度
或可行走坡度保证。首尾切线必须为 0；内部点两侧共用一条切线。

首版要求 64×64 逻辑网格、同一地形家族。每图最多 16 条曲线，每条 2—32 点，
相邻点 X 至少相差 32，单条横跨不超过 4096。曲线保持由左到右的高度函数，向下
填充到 baseY。每段 Bezier 控制凸包须在地图内，且比封底至少高 16 个逻辑单位。
这是一条保守的校验规则，可能拒绝实际曲线仍有余量的编辑。

曲线之间、曲线与任何已占用格子列的水平区间必须分离，连共享端点也暂不允许。
所以无法在曲线正上方另放格子悬浮台；环境视觉实例不受此占格限制。
跨多个控制点的连续地面应写为同一条曲线。0.10.0 可以把两条相邻曲线的接头合并为
一个内部点，见下文；编译器仍拒绝两个独立对象共享/重叠区间。曲线/格子混接和
跨分块接缝属于后续合同，不把端点合并称为完整长地图连接方案。

## 轮廓编译

`src/curves.mjs` 的 `CURVE_PROFILE` 固定全部算法参数。相邻点按 cubic Hermite
插值，等价 Bezier 的两个控制点 X 为区间的 1/3、2/3，因此 x(t) 线性、不会折返。
共享锚点只采样一次，解析曲线在内部锚点具有相同 dy/dx。

程序按 de Casteljau 自适应细分；控制点到弦的距离不超过 0.5 逻辑单位、弦长不超过
32，递归深度最多 16，每条最多 2048 个采样点。输出坐标量化到 1e-6；几何误差
指标不是屏幕像素误差，极高缩放仍能看见折线。超预算明确失败，不降低质量后放行。

填充网格把每个地表采样点连接到同 X 的封底。草沿沿解析斜率的向内法线铺 8 单位
宽条带；内侧点须保持 X 单调、在域内/封底之上、处于采样实心轮廓内。急弯导致
条带折叠或越界时拒绝整个命令。不会剪掉失败部分或自动修形。

`ai_scene_compiled_v2.curveTerrains` 含表面点、闭合轮廓、body/cap 的 positions/uvs/
indices、采样距离、包围盒与 Profile；地形层 ID 来自原规则。原 grid 节点、碰撞边和
计数保留，曲线数量读取 curveTerrains.length，不混入 terrainNodes 格子数量。
`collisionSuggestions.curveContours` 复用同一批表面点及封底，始终标记
`walkability: not-assessed`。呈现、碰撞建议有共同几何来源，但尚未接入物理运动。

## 材质与 Pixi

石土 UV 为世界坐标 / 256，调整镜头或地图范围不会重置相位。草沿 U 为整条曲线的
累计折线长度 / 256，跨内部段连续；V 横跨草沿。移动控制点会改变后续弧长，因此
草沿花纹随形状重新排布。独立曲线的草沿相位分别起算。

已验证的连续材质预览快照升级为 `ai_scene_terrain_study_preview_v2`，从同一个
766 文件派生包额外保留 body-field/cap-field 原 PNG；752 张格子图片及旧派生包
原字节不变。它不创造新的生产 kit，原材料接受不自动变成曲线美术接受。

Pixi 入口可选 `resolveCurveMaterial(curve)`，返回 `{body,cap}` 两张宿主 Texture；
没有返回值时显示棕/绿工程色。body 双轴重复，cap 横向重复、纵向钳制，缩放使用
线性采样；曲线 Mesh/Geometry 由视图释放，共享纹理由宿主管理。
当前有 256 逻辑单位的重复周期；格子沿用固定坐标相位，混接视觉对齐尚未实现。

## Studio 操作与保存

曲线 C 工具显示圆形控制点和内部点的方形切线柄。圆点拖动修改整数 X/Y，方柄上下
拖动修改斜率；首尾斜率锁为 0。拖动期间仅显示临时轮廓，释放后执行一次替换命令。
Esc、失焦、指针取消及失去捕获丢弃预览；非法释放保留原文档和历史。
右侧也能选择曲线/点并填写 X、Y、斜率、封底，再一次应用。

“在右侧添加曲线小样”提供丘陵、谷地、缓坡三个模板：原子地升级（如需）、向右
扩 16 列并添加曲线，一次撤销恢复。模板是编辑起点，端点保持水平。
插入点取当前段中点的曲线位置/切线后量化到整数坐标及 0.001 斜率，可能略微改变
原形状；删除点只允许内部点。全部通过同一核心校验，无效操作整次拒绝。

Node 编辑器增加 enable-curve-terrain、add-curve-terrain、replace-curve-terrain、
remove-curve-terrain 四种命令。add/replace 的其他字段为 curve；remove 为 curveId。
可以与 resize-bounds 组成一次原子手势。曲线选择、镜头、草稿预览均不写作者地图。

## 邻近端点吸附与合并：0.10.0

仅支持一条曲线的右端连接另一条曲线的左端，或反向拖动左端连接另一条曲线的右端。
同一曲线的内部点、两个左端/两个右端、T 形接头和曲线/格子接头不在本轮范围。
打开地图、缩放、只点选和精确字段的普通应用不会自动合并或清理作者点。

端点手势移动至少 3 个屏幕像素后，最近的异曲线相反端进入 12 屏幕像素、且距离
不超过 64 逻辑单位时出现吸附圈和“松手合并”提示。判定同时考虑 X/Y 欧氏距离，
避免缩小后跨很远吸附。拖出范围恢复普通点拖动；取消手势丢弃预览。候选按距离排序，
等距按稳定 curveId 字典序选择；不会在所有附近点间任意游移。

松手执行一次核心 join-curve-terrains 命令，将移动端吸附到静止端的准确 X/Y，
只保留一个水平切线的共享锚点，保留左侧曲线 ID，移除右侧对象，其余锚点原值保留。
当前两端本来就相近时，可选中端点点“合并附近端点”；同样通过核心命令和完整校验。
合并后自动选择共享点，按一次撤销可恢复两条原曲线和合并前的位置，重做可再合并。

两条曲线必须使用相同材质家族、Profile 和封底 Y。总点数最多 32，合并跨度最多
4096，各点仍需 X 递增及最小间隔，地图边界/草沿折叠/剩余曲线与格子冲突继续全量
校验。不兼容时显示原因并整次拒绝，不修改任一条曲线、历史或已有重做分支。
不强行平均高度、不丢掉中间点、不自动截断超长曲线。

命令准确字段为 `{type: 'join-curve-terrains', curve, endpoint: 'start'|'end', targetCurveId}`。
curve 是完整的移动方曲线提案，targetCurveId 只能指向当前地图中的另一条曲线。
Node 核心先验证关闭的 v2 Schema，再按固定 CURVE_JOIN_POLICY 限制距离和接头关系，
最后重编译整个草稿。浏览器候选计算与核心使用同一纯函数，不单独复制合并算法。

填充重编译为同一网格，石土世界 UV 保持；草沿沿合并后的整条曲线累计距离，因此
原右段草沿相位会重新排列。碰撞建议变成一条闭合轮廓，接点不再有内部竖边。
共享点成为普通内部点，之后可调整其共用切线。仍不提供物理运动或美术接受保证。

该扩展只增加编辑命令，不更改作者/编译格式、原 CURVE_PROFILE 或旧文件字节；
0.9.0 的 v2 保存及导出仍可按原内容重放。已有两条近邻曲线仍保持两条，直到用户
执行实际合并手势或按钮，不在载入时悄悄升级其内容。

保存/打开使用完整 v2 作者文档，编译文件也明确为 v2。目录导出的外层格式仍为
ai_scene_export_v1，内含 v2 作者/编译文件，读取方须支持 0.9.0 曲线扩展。
原基础 kit 依赖闭包按原字节复制，试样材质仍由显式外观配置提供，没有打入该导出。
重填编译文件及清单哈希仍须通过从作者数据重新编译的严格比较。

启动可加 `--map LOCAL_JSON`：只在启动时读取所选本地文件，验证后建立编辑器；
HTTP 不接受路径。含曲线的初始地图会选择首条曲线并定位镜头，不修改作者默认镜头。

## 验证与后续

17 项新增核心回归覆盖版本隔离、已知 Hermite 数值、共享切线、密集解析点误差、
三种几何共源、UV、反例、原子历史、保存导出重放、重填摘要的伪造及 Pixi 资源释放。
7 项新增浏览器回归使用合成 kit/材料，覆盖实际网格呈现、控制点/切线拖动、四种取消、
非法参数、插入删除、保存打开、碰撞叠加、预览禁改及 1440/1024/390 宽度。

0.10.0 新增 18 项核心连接回归及 7 项浏览器回归。覆盖双向合并、静止端坐标、
ID/其余点保留、草沿/轮廓连续、阈值、拒绝原子性、取消、仅点选不合并、按钮、
保存打开和窄屏；全部使用合成 kit/材料。实际运行结果见执行文档第 28 节。

下一步优先建立曲线/格子接头、明确端点高度/切线/草沿相位，验证长段与跨屏连接，
再处理自然草沿和纹理周期。洞穴/倒挂应另选多边形拓扑合同，不能放宽高度曲线校验
冒充支持。真实材质在曲线上的视觉评审与正式美术资产包继续单独推进。
