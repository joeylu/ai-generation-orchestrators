## 8 步连续修改

来源：上一轮成功的真实 `eval-audio`，初始主音量70、静音关闭、恢复默认重置这两项。
在调用模型之前，确定性工具准备试玩主音量83、静音开启；修改上下文不含玩家试玩值。

1. 主音量默认值改为50，其余保持。
2. 主音量标签改为总音量，绑定与事件保持。
3. 在总音量与静音之间新增音效音量0～100、步长1、默认40；不加图标，重置仍只含原两项。
4. 恢复默认范围增加音效音量；模拟玩家把新滑条调到91后再修改。
5. 标题改为声音选项、最大高度480，其他布局保持。
6. 删除静音及其状态，同时清理重置引用。
7. 按钮显示文字改为恢复声音，动作不变。
8. 删除音效音量及其状态，同时清理重置引用，按钮只恢复总音量。

每步对完整 PanelSpec 比较，除明确请求的变化及新控件所需的新 ID/事件外，
所有既有 ID、绑定、配方、资源、字段、布局和行为必须保持。
试玩主音量83持续保留，创作默认值50独立保存；重置只作用于按钮明确列出的字段。
每步导出重开、单步撤销和最终整链撤销检查均不额外调用模型。

后续步骤的精确 context/schema 取决于上一步真实接受的结果，不能事先伪造为模型输出。
