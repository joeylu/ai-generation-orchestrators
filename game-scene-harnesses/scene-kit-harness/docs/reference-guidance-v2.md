请求主体清单中的独立设施必须保留；只排除未请求的额外道具。局部灯光/反光属于本体，

## 壁挂样本

当前城市样本明确将两组下部近景以自身短支架固定到左右既有主台前立面，中央开口
通到底框，由后方城市竖向立面覆盖。所请求的建筑、管线、设施完整入画，材料和画风
保持；不靠新增共享湿地面解决承托。

明确接触主台的station、utilities与foreground使用parallaxX=1，避免镜头平移使接触
位置滑开；zIndex保持层序。壁挂是本次装配意图，当前不宣称已有地形移动/擦除后的
自动父子约束，实际Kit/Studio仍须在来源完成后检查。

安装方式不能代替前景美术验收。壁挂、台面放置等只定义承托；仍为foreground的近景
群组，应在最终显示大小下具备独立主件、完整轮廓、可读体积与设计所需的局部遮挡/
框景作用。仅轮廓清楚、透明技术通过或已设前景zIndex不足以判定实现了前景设计。
体积和层次应由本体形状、受光面、暗部及组合关系体现，不用统一提亮、染色或巨大光晕
补救。该项属于人工美术检查，没有自动从图像认证；修正观察写入新审阅包，原包保持。

整景还需检查前中后景的可读层次。可在visualObservations.depth与各subject/sourceScope
中明确：远景概括细节与局部对比，后方环境居次，玩法主体承担主要阅读，近景以独立
体积、轮廓和局部遮挡靠前。前景不必整体最亮，局部灯光应服从场景焦点。使用统一
画风与材质原色，不把后期压暗/染色/透明度/景深模糊当作层次修复。缩小、减弱灯光
观察及实际Studio镜头移动检查属于人工验收，单纯叠放图层或设置视差不自动代表达成。
