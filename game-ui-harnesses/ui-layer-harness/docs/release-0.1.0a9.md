# UI Layer 0.1.0a9

标签：`ui-layers-v0.1.0-alpha.9`；CLI：`0.1.0a9`。
基线为 alpha.8 (`ca667a6e73b96205e82796aa25c838ce0b08f2af`)。

## 改动

修正官方 M1 动态预算提示强制合并卡框、可替换内容及图标的冲突。合板只决定
传输与生图分组，仍由基础规划合同、原图和独立 M2 确定归属。明确整体归位不能
校正素材内部被放大或移位的图形；不机械拆碎固定插画、读数卡或固定附饰。

M2 和单次最终整图复审显式比较内部大小与偏移、空白、边框厚度及另属控件遮挡。
最终复审 packet 增加来自实际冻结候选的 `ownedObjects` 和 `registrationMode`，
随既有请求摘要绑定。这些是未实测的原图定位提示，不是假造生成主体观察。
详见 [几何还原](GEOMETRY-FIDELITY.md)。

生图提示和参考裁片输入板保持原样；继续使用 v13、sheets、最多三路持续补位、
board v6 的纹理来源及复审绑定、原生 transparent_background，以及一次最终
composite_review。视觉差异仍为 warning，技术完整性错误停止，不自动重发。

## 验证边界

新增 5 项离线回归覆盖独立内容身份、原 M1 字节、M2 前不生图、整卡外框对齐而
内部过大、独立刚性归位、单次最终复审和内部定位摘要篡改；已有完整固定卡片
回归继续保留。精确离线测试、固定基准、独立安装检查与 CI 状态见发布附件
`offline-regression.json`，不能把合成 fixture 当作真实模型图像质量验收。

**本修订尚无新的真实模型验收。** alpha.8 的装备商店已导出 24/24 素材，独立
整图复审仍有 7 项视觉 warning。旧结果保持人工验收待定，不宣称这些问题已修好。
本次发布没有新增真实规划、生图或复审调用。后续真实验证须先冻结新规划范围与
有限预算，待新 M1 程序核算素材及请求数后，再确认生图与一次整图复审预算。

## 接入、升级与恢复

下载本标签的源码和 viewer 附件，先校验 `SHA256SUMS`，安装到新版本目录。
从 alpha.6/alpha.7/alpha.8 升级只影响新任务。已有任务继续使用原不可变安装及
完整运行目录，不覆盖旧配置、快照、授权、回执、失败状态或交付清单。

本版没有新增 stage、配置、授权类型或模型预算。消费端继续透传完整复审 packet；
正常规划仍为 M1/M2，显式启用修复时最多一轮修复及一次独立复审，预留两次额外
模型调用；默认逐素材和 body 调用为零。alpha.6 消费端仍须识别 alpha.7 引入的
planning_repair/planning_rereview，见 [规划修复](PLANNING-REPAIR.md)。

中断仅检查现有 reservation 或推进已验证结果，未知结果和超时继续终止且不重发。
新尝试使用新目录和新的用户决定。本版不恢复历史失败任务，也不操作 Docker；
Docker 消费端使用现有 stage 和预算即可。
