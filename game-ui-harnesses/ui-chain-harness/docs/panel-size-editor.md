# 生成后画布编辑

2026-10-16。本地 Studio 已提供生成后的画布选中、拖动位置、边角调整尺寸及显示文字编辑，复用现有 PixiUI、PixiJS Layout、皮肤和组件行为，不调用模型。原 `panel-size` 路由和文件名继续兼容。

## 使用入口

在**面板作品库 → 打开面板预览 → 画布编辑**进入。左侧选择面板整体、布局分组或内部控件，也可直接点击画布。重叠时用 **Alt + 点击**依次选择后方层级。选中框显示当前节点和实际宽高；画布提供网格底纹、放大、缩小、聚焦选中和整张画布视图，视图缩放不改变导出尺寸。

图层列表在选择和编辑状态更新时保留原有按钮及键盘焦点，当前选中节点同步滚动到可见范围。可以继续用键盘操作图层，不必在每次修改后重新寻找焦点。

**内容边界**默认开启：蓝色虚线表示所选内容所有者的 body 区域，橙色虚线表示父级可用区，属性栏显示对应逻辑宽高。body 是节点或运行时内容区，不是额外文件；其尺寸会扣除实际边框留白、标题、页签栏、操作栏或滚动条。无作者子槽的叶子控件只显示可用父区，库存仍使用独立格位/详情几何，不伪造统一 body。边界覆盖层仅帮助编辑，不写入作者文档或导出。

内容槽失败时，提示同时给出父容器和阻塞内容、失败候选的可用尺寸/所需尺寸、超出量及容纳当前内容的父容器下限，可分别定位相关控件或父容器。真实放不下的内容仍会拒绝；不会自动压缩文字或绕过安全检查。完整逐类型结论见[组件 body 审计](component-body-audit.md)。

- 自由父容器中的可编辑节点提供四角和四边共八个尺寸柄，可拖动控件或选中标签移动位置。外层 Panel/Dialog 位于固定画布的自由容器内，可直接移动。
- 自动排版中的节点提供右边、下边和右下角尺寸柄；位置继续由所属分组计算。要自由移动内部控件，先使用下述显式分组转换。
- 右侧输入 X、Y、宽度和高度即可实时预览，离开这一组输入区域或按 Enter 后自动应用。数值是逻辑像素，坐标相对于所属分组；属性栏显示共享布局求解器的实际矩形。自动排版节点的位置输入禁用。
- 选中文字或带文案的控件，右侧**文字与样式**可直接输入并预览，离开这一组输入区域后自动应用。Text 支持多行；标题、按钮、开关、勾选框、选项、页签、列表条目和弹窗操作按钮提供对应显示字段，Input 提供输入提示。可输入 12–96 的整数字号，使用颜色选择器或输入 `#RRGGBB`；输入字号或颜色会自动取消该项默认勾选，也可勾选恢复皮肤默认字号/自动配色。连续编辑同一组文案、字号和颜色只产生一步撤销，失败保留全部原始输入与上一次已应用的画布。
- 内部控件可分别调整宽高。显式修改原 fill/content 轴会将该轴改为 fixed；其他布局规则和最小/最大尺寸约束保留。程序确认实际尺寸与输入值一致才发布候选。
- 支持本次会话内撤销、重做和**恢复生成布局**。恢复会同时还原生成时的布局、文案与文字样式，只修改当前草稿且可撤销；保存后才成为新的本地编辑副本。
- 画布编辑中 **Ctrl+Z** 撤销上一步，**Ctrl+Shift+Z** 或 **Ctrl+Y** 重做；Mac 对应 **Cmd+Z / Cmd+Shift+Z**。焦点在属性输入、原生输入框或可编辑文字中时保留原生撤销，不回退面板布局。试玩、拖动/平移及忙碌期间不修改历史，长按不连续触发。
- **试玩**保留原来的组件行为和所选面板动效；试玩中产生的输入值、开关状态、滚动位置等不写回尺寸文档。

拖动期间由纯函数生成候选，并通过实际 Pixi 渲染实时预览；正式文档和撤销历史在松开指针后才提交一次。按 **Esc**、指针取消或窗口失去焦点会取消此次拖动。最新目标未通过检查时，整个手势回退到拖动前的有效结果，不自动夹到最小尺寸，也不保存中途某个曾通过的候选。

点击控件触发画布自动聚焦时，先按点击时的画面确定命中节点，再按聚焦后的视图计算拖动起点；相机的移动或缩放不会被计入控件位移及尺寸变化。

选框在屏幕上较小时，会精简中点或相邻手柄并缩小命中区，避免边柄被角柄遮挡；放大画布后可显示完整可用手柄。角柄可沿单一方向拖动，精确修改仍可使用右侧数值。

画布沿用生成前选择的 16:9 或 9:16，画布逻辑尺寸和比例不能在此修改。历史多版本面板可在顶部切换版本，各版本独立保存。已应用但未保存的修改、尚未应用的属性输入都参与版本切换和离开保护；取消离开继续保留当前调整及输入。

## 实时输入、自动应用与撤销

属性栏中的原始输入、实时预览候选和已应用文档分开管理。位置、宽高、字号、颜色选择器及默认样式勾选在下一动画帧预览；普通文字和 HEX 文本输入短暂停顿 160 ms 后预览。每次候选仍执行文档、布局、皮肤安全区及实际文字检查，不为实时反馈放宽约束。输入中只渲染独立的 Pixi 候选场景，不修改作者文档或撤销历史。

离开同一表单组时自动应用最新输入。在位置/尺寸组或文字/样式组内部切换输入框，不提前拆成多次提交；连续一组编辑完成后仅提交一次，对应一步撤销。单行输入按 Enter 完成，多行 textarea 使用 Ctrl/Cmd + Enter，普通 Enter 继续换行。原有 Apply 按钮已隐藏，无需再点击应用按钮。

切换节点、保存、下载、进入试玩及结构操作前，也会先尝试完成当前最新输入。有效值通过检查后才发布到作者文档；保存或导出使用这一结果。其他节点若仍有未通过检查的输入，会继续阻止保存、导出或相关操作并定位到待处理节点，不跳过输入。修正后完成该组编辑，或使用**还原此控件输入**恢复当前文档值，再继续操作。

最新输入无效时立即清除独立预览，恢复上一次已应用的作者文档和画布，保留无效原始值及完整错误。即使更早的输入曾预览成功，也绝不提交那个旧候选。无效输入按节点保留，切换后再返回可继续修正；它不进入撤销历史，但继续参与离开保护。

位置/尺寸与文字/样式两组都在输入旁显示本组的预览、应用或失败状态，并通过 `aria-describedby` 连接原生输入，不在逐次校验或 blur 时移动焦点。组级错误表示本组候选未应用，不推断某一个字段就是唯一原因。输入修回已应用值或恢复原默认样式、且不再存在对应草稿时，会清除该组旧错误及其全局定位；不会因此清除更新后出现的其他渲染错误。切换控件会重置当前属性栏反馈，原控件未通过检查的原始输入仍保留。

同一节点同时存在矩形和文字草稿时，切换节点、点击画布、保存或下载使用一个完整组合候选。例如 Text 从字号 32、高 60 同时改为字号 12、高 30，不再先拿旧字号检查新高度。程序复用原尺寸传播器，先合并全部白名单修改，再对完整文档执行布局、皮肤、文字及实际尺寸检查；通过后只产生一步撤销。单独在一组按 Enter 或离开该组仍只完成该组；最终组合不合法时，两组输入和上一次有效文档、场景及历史全部保留。

属性输入中按 Esc 取消本轮输入及候选，恢复已应用文档；这不会撤销更早已应用的修改。中文等输入法处于 composition 期间，不预览或提交未确认文字，待 composition 结束后再处理最新值。输入草稿仅在当前编辑会话内保留，不直接写入保存副本或下载文件。

未保存判断比较作者文档内容，忽略顶层 `revision` 计数。撤销回到已保存内容后，不会仅因版本计数变化继续标为未保存；如果仍有未应用输入，该输入继续参与离开保护。

## 工作区与视图导航

画布编辑占满 Studio 当前窗口可用区域，收起外层 Studio 导航和页头，保留返回面板入口、紧凑操作栏与状态提示。进入版本时默认聚焦面板整体，按面板实际矩形居中放大，避免把画布空白一起缩进小预览。**聚焦选中**重新取当前节点矩形；**整张画布**显示固定逻辑画布，最高按 100% 显示。聚焦与手动缩放最高 250%，最低 10%，倍率下限可能使极大矩形在小窗口中部分超出视口，不改作者尺寸。

- 编辑模式下在画布滚动鼠标滚轮，以指针位置为锚点缩放；`+`、`−` 按钮以视口中心缩放。
- 按住**空格 + 左键拖动**、**中键拖动**，或启用**平移**工具后左键拖动，可移动视图。平移优先消费指针事件，不同时移动或缩放作者节点；原生输入框中的空格继续用于文字输入。
- 试玩模式下普通滚轮仍交给控件；使用 Ctrl/Cmd + 滚轮可明确缩放视图。试玩与相机操作不写回面板默认值。
- **图层**和**属性**分别控制侧栏；**专注画布**暂时隐藏两侧栏，退出时恢复进入前的选择。窄屏默认收起两栏，展开时以覆盖层显示，每次只展开一栏。

折叠侧栏或改变窗口尺寸后，聚焦/整图模式重新取景；手动模式保留原视口中心对应的逻辑点。窗口或视口变化会取消正在进行的节点拖动或相机平移，避免使用过期坐标。相机平移还可通过 Esc、指针取消或窗口失焦回到本次平移前的视图。

相机、倍率、焦点目标和侧栏开关只属于视图状态：不修改 PanelDocument、不进入撤销历史、不触发未保存标记，不写入编辑副本或下载 JSON，也不调用模型。视图导航保留属性栏输入；输入完成后的自动应用、有效节点拖动或显式布局转换才产生作者文档修改。相机状态不跨重新打开持久保存。

## 自动排版与自由布局

选中自动排版分组时，使用**将此分组切为自由布局**；选中其控件时，可使用**将所在分组切为自由布局**。此操作明确释放一个分组的自动排列，按当前共享求解器的坐标和尺寸冻结该分组及其直接子项，保留节点层级、顺序、文案、行为和子项内部的嵌套布局。之后直接子项可以拖动位置及八个尺寸柄；其他分组继续自动排版。

转换会将相关自动尺寸固定，移除直接子项在自由父级中不再适用的弹性和单项对齐规则，最小/最大尺寸约束保留。网格转换保留当前每个格子的实际矩形，之后不再按统一格子重排。转换不增加节点，也不会将子项移动到另一个父级。可撤销转换以恢复原 flow，或使用恢复生成布局；本版没有独立的反向自动排版按钮。

画布根、空分组、包含隐藏直接子项或锁定直接子项的分组不提供转换；缺少可冻结的当前几何时明确拒绝。Panel、Dialog、Tabs、ScrollView 等内容槽根的位置仍由控件适配器管理，不能把该根当作自由子项拖动；可转换槽内的 Container 来编辑其直接子项。

## 尺寸与布局限制

本入口编辑现有节点的矩形、显示文案、字号、文字颜色及上述受控自由布局转换，不增加、删除、复制节点，不修改字体资源、文字对齐、槽位、分组层级、行为或皮肤素材。转换之外的方向、间距、列数和约束保持不变。横纵排列、嵌套、填充和内容自适应继续按[布局合同](layout-contract.md)求解，不提供任意结构编排或自动切换画布比例。

文案仅允许 `Text.text`、`Panel/Dialog.title`、`Button/Switch/CheckBox.label`、`Input/Select.placeholder`，以及 Select/RadioGroup 的 options、Tabs 的 tabs、List 的 items、Dialog 的 actions 中原有条目的 label。ID、数量、顺序、关联内容、初值、选中状态、校验和行为保持不变；Input 的实际输入值仍属于试玩状态。List 已有显式子行时编辑对应子 Button/Text，数据 label 不提供无效编辑。锁定节点及祖先不提供文案编辑。输入按纯文本处理，不执行 HTML。仅对新改值限制 Text 最多 32768、其他字段最多 4096 个 UTF-16 字符，兼容冻结源值；实际可容纳长度仍受原字号、换行和安全区限制。

13 类具有自身文字的组件允许可选 `props.fontSize`（12–96 整数逻辑像素）与 `props.textColor`（六位十六进制颜色）。样式只作用于该节点自己的文字；Select/RadioGroup/Tabs/List 的全部原有选项共享该节点样式，Panel/Dialog 的子控件继续使用各自样式。Slider/ProgressBar 仅在已有数值显示时提供字号和颜色，不修改其范围或数值；显式子行 List 仍编辑实际子控件。缺省属性沿用皮肤，恢复默认会删除覆盖字段，不将默认数值固化到旧文档。颜色忠实应用用户选择，显式色优先于自动角色配色；原皮肤对比度报告不代表自选颜色已通过，运行时另标记作者覆盖及视觉复核。字号变化对全部自身文字重新检查容量，不通过缩放素材改变视觉字号。

字号也可能增加 Panel/Dialog 标题、Tabs 页签栏或选项行的预留高度；满铺的内容槽因此放不下时，需先调整内部页面/滚动视口的高度来留出空间，再应用字号。程序不自动缩小子项或字体。旧包的编辑上下文只派生两项可选属性合同，不改冻结 registry、绑定摘要、默认属性、原始文档或旧修订身份。

程序先检查文档及同源 Yoga 布局，再检查实际 PNG 皮肤的最小尺寸、九宫格、内容安全区、父级内容槽和画布边界。空间缩小或文案变化时增加保守文字容量检查；浏览器还使用真实字体和皮肤渲染，拒绝新文字被截断。文案过长需先扩大控件和必要的父级空间，不能通过缩放整组、缩小字体、改变皮肤或裁掉文字来满足尺寸。

以下情况会明确拒绝，并保留上一次通过检查的文档、预览和撤销历史：

- 组件、文字或九宫格所需空间不足，或超过原有最小/最大尺寸约束。
- 内部内容放不进父布局、面板安全区或画布；可先扩大面板或上级容器，再调整内部控件。
- 皮肤缺少可核验的几何证据，或历史预览格式不能安全提取为可编辑文档。
- 节点或其祖先已锁定。统一网格尚未显式转换为自由布局时，直接子项由公共格子控制，尺寸柄和宽高输入禁用，并提示调整或转换上级分组；不接受运行时会忽略的子项尺寸。

错误提示完整显示并换行，不用省略号隐藏具体原因。错误能关联到阻塞节点时，提供定位操作，同步选中图层并显示对应属性，便于先调整上级容器或修正该节点；失败的输入仍可继续修改或还原。

流式与自由布局的越界提示也携带失败候选的内容区、当前占用和四边超出差值。例如分组可用 184 × 111、当前排列占用 184 × 112 时，明确显示“下边超出 1 逻辑像素”。Yoga 结果保留真实子项起点与网格行偏移，可定位所属容器；旧固定行列仅报告当前累计占用，不假定它是完整最小尺寸。界面使用有效文档查询名称，不使用旧文档尺寸代替失败输入的尺寸。旧固定容器中的隐藏子项不占用可见边界，但位置结构、显示恢复后的边界以及其他文档检查继续执行。

此处不提供 grid.cellHeight/cellWidth 或最小/最大约束编辑，不自动增加滚动区域。已有 ScrollView 的内容可保持自然高度，宽度仍必须放入其安全视口；布局无法容纳时需要用户选择其他有效矩形。拖动调整外层尺寸会保留锚定位置；数字修改仍居中的面板时沿用居中策略，已移动的面板保留其位置。原先贴合内容区的尺寸同步更新，滚动视口和 Tabs 页面继续预留各自安全区，独立控件不随整组缩放。程序检查通过仍是外观待验收候选。

## 原始结果与本地副本

**保存编辑副本**在本机追加一条版本，保存通过校验的尺寸、位置、文案与受控布局转换。原始模型计划、调用回执、生成文档、皮肤包、预览和交付清单均保留，不重新生成、不重新切图，也不替换冻结产物。

再次从同一个面板进入**画布编辑**，会读取所选版本最新通过来源、摘要和编辑校验的副本。没有有效副本时使用原始生成布局；其他页面已保存新版本时拒绝覆盖，需重新打开后继续。撤销/重做属于当前编辑会话，不是历史保存版本浏览器。

**编辑输入 → 自动应用 → 保存编辑副本 → 返回面板预览**：保存会先检查并自动应用当前有效输入，再保存作者文档；其他节点的无效输入仍需处理。普通预览保持只读，默认读取该版本最新已保存的布局，显示尺寸、位置、文案和自由布局修改；工作台内自动应用但未保存的草稿不会跨页面生效，也不会自动保存到本机。编辑页与预览页在当前浏览器标签中记住所选确切版本，刷新后保留，避免同方向多个版本串用副本；这里只保存版本选择，不包含草稿或试玩值。重新进入预览会重新读取最新保存结果，试玩值不持久化。

预览可切换**当前已保存布局 / 原始生成**。原始生成入口仍读取冻结预览包，原始交付下载、ZIP、计划和清单保持原样；编辑副本JSON可在画布编辑中下载。没有保存副本时明确显示原始布局；不支持编辑预览的历史格式会明确提示并显示原始生成。来源、修订或渲染读取失败显示错误，不将失败冒充已保存布局成功。

原始生成对照和原来的交付下载继续展示冻结结果。**下载 JSON**先完成当前有效输入，再下载已应用的编辑文档，即使尚未保存；无效或其他节点待处理的输入按上述规则保留、阻止并定位。文件沿用 `ui_panel_size_copy` 1.0 标识，PanelDocument 包含当前尺寸、位置、文案和布局，另有原预览和皮肤摘要、版本标识，以及已有的行为配置。

JSON 的 `portable` 部分是 `runtime-json` 资源快照：包含皮肤清单、清单声明的运行时纹理、材质 PNG 及其声明的来源 PNG、字体、许可证，以及编辑运行上下文和 registry、usage、template 三份派生合同。资源按文件去重，导出前核验声明的字节数和 SHA-256，继续绑定原皮肤；不是只保存资源路径。来源预览保留了三份原合同字节时，同时嵌入并标记 `original-source-bytes`；历史预览缺少原字节时标记 `derived-editor-context`，不把派生合同冒充原合同。

原组件 atlas 图集全集不嵌入该 JSON，文件也不是重新构建的独立消费包或 ZIP；当前没有该格式的网页导入入口。试玩状态、相机和未应用输入不导出。保存到本地和下载到用户选择的位置是两个独立操作。

本地保存文件位于 `work/studio/panel-revisions/<artifactId>/<variantKey>/<UUID>.json`，记录继续沿用 `ui_panel_size_revision` 1.0。每次保存生成新文件，绑定原预览、原文档和皮肤摘要，记录父版本及 `modelCalls: 0`，兼容已有尺寸副本。程序校验整个文档摘要及尺寸、位置、文案、受控转换白名单，同时检查版本链、并发冲突和路径安全；不要人工改写记录或生成清单。
