# 现有正文自动换行和内容高度

仅在本轮 operations 列出 set-text-wrap 时适用。{op:"set-text-wrap",rowId,wrap:"word"} 为一个现有 Text 正文开启自动换行。wrap:null 清除该行换行覆盖，恢复单行；清除后内容必须能放入现有单行槽。普通行标签、分组标题、按钮文字和多行输入不属于这个操作。

“说明太长了，自动换行，按钮往下让一点”可直接开启正文换行。程序按当前分组实际宽度计算分行、内容高度、后续控件位置及滚动，无需凭空设置固定高度或改画布。中文、英文、网址和换行符保留内容，分行由程序确定，模型不得向原文插入人为折行。长英文优先整词；单个长词或网址可按完整字素断开。

正文已开启换行时，set-text 可以替换最多1000个Unicode码点的正文，允许明确段落的LF/CRLF。正文未开启时仍为单行、最多120码点。新增长正文应先 add-row，再对该ID set-text-wrap；一批添加和启用换行，不能先发布溢出的中间状态。新正文的recipe使用当前目录可用Text配方，state:null。

保留行label、稳定ID、绑定、事件、输入值和未请求的其他样式；开启换行会把该行label放到正文上方，后续行按真实内容高度下移。超过面板高度时仅使用当前允许的滚动策略；overflow:error或宽度连一个完整字素都放不下时整批失败，不截断、不悄悄缩字号。多段长文可滚动阅读，不要求整段一次显示在视口里。

选中Text行时只修改该行。所选不是Text、或需要改其他行时，遵守选择作用域。全部必要要求都支持才返回完整操作；换行操作不赋予条件行为、动态文案或任意文字样式能力。每个操作逐字引用本轮请求，遵守同一十轮上限。
