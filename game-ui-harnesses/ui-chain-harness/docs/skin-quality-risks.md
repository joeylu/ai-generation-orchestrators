# 质量风险基线

运行 `npm run skins:quality-risks`，在 `work/skin-quality-risks/<运行ID>/` 输出逐项夹具、检查结果和 `report.json`。不调用模型、不修改真实皮肤或切线。夹具定义在 `tests/fixtures/skin-quality-risks.json`，像素与错误配置由测试辅助程序确定性构造。

本轮只评估 `inspectAssembly` 后处理预检，不能代表全部运行时、全套质量门或真实风格分布。错误真值来自构造时已知的像素位置、装饰范围与部件身份，不来自检查器自身的建议。

| 样本 | 预检表现 | 含义 |

## 当前决定与后续

### 第二轮：空资产拦截与保守风险提示

新增 `skin.empty-asset`：源裁切或适配结果全部alpha为0时预检失败；不可见RGB不算有效内容，低alpha但非空的艺术内容保留。该门应用于调用 `inspectAssembly` 的后处理及workflow预检，不代表所有低层工具都新增同样门。

切线/端帽诊断只采纳panel-slicer的 `repeated-center-bands-v1` 方法。配置边界比重复中心带边界浅超过1个像素时产生风险提示；比较按素材密度和输出倍率换算到像素，仅检查实际拉伸轴。源端帽在适配前独立比较，避免适配后的拉伸掩盖问题。不使用结构回退估计做此判断，不自动改配置，不升级为硬失败。

新报告：`work/skin-quality-risks/c0f78489-3825-4002-b25b-e0554125fff7`。同样10例缺陷现为6项阻止、3项提醒、1项静默漏检；2项正常对照无提示。裁空升级为阻止，穿装饰切线/过浅端帽新增提醒，相邻部件误裁仍漏检。提示不代表已证明视觉错误，合成集效果不能外推为生产检出率。

5项定向测试通过，包括低alpha、空心内容、密度换算、有效轴和接缝1像素容差。两套已有皮肤各30件预检通过且没有新增风险提示，记录在 `work/quality-recheck/3ed2cc3a-e510-40ef-adf0-b0b9cb83ea44`。这不等于新增规则已覆盖复杂真实纹理：非重复中心带纹理不会启用新启发式。未更改素材、运行时或4194预览。

维持显式待视觉审查，不引入session，不自动改切线。首轮证据不足以移除视觉环节。

透明空资产门和有限范围的端帽/切线提示已补齐。切线建议与现配置不同不能直接判错，人工配置可能有合理原因。相邻部件身份需要独立定位依据，不能仅靠纹理相似或源图摘要判断。

随后应增加复杂装饰、半透明、圆角、渐变等正常对照，以及经过人工标记的真实失败样本；分别统计阻止、提醒、静默漏检和误报。只有明确支持风格范围并获得更广泛验证后，才能讨论取消视觉查看。当前报告是开发诊断工具，不接入发布质量门，也不降低现有门槛。

新增样本时维护语料与必要的像素构造，重新生成报告，不手改旧报告。检测能力改进后重新比较结果；测试没有将现有漏检写成必须永久维持的行为。
