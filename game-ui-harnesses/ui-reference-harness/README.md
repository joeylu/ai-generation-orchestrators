# Shared Codex CLI transport

The checked transport modules in `web/adapters/` and their small supporting
modules are consumed by Scene Kit's optional local Codex adapter.

They preserve exact image arguments, reference fingerprints, durable
at-most-once dispatch evidence and terminal unknown outcomes. Local setup and
tool verification are described in
[Scene Kit's workspace guide](../../game-scene-harnesses/scene-kit-harness/docs/local-workspace.md).
