# 声音设置对齐与间距

用户指出Noto声音设置的排版仍不舒服。本轮只整理该面板的内容边界、纵向节奏与操作层级，沿用已有Apple方向、字体、线条图标及清晰滑块，制作浅深色前后对照。

入口：`output/audio-aligned-review-v4/review/index.html?panel=audio-dark`。左右可独立试玩，下载的是调整后的实际交付包。该次生成时的报告将用户美术认可记为 `NOT_RUN`，没有将候选设为日常默认。

后续用户反馈“好多了”，以本稿作为声音设置的排版参考；原验收报告保留生成时的状态，不回写历史回执。延伸的暂停/退出紧凑试稿随后被反馈不如上一版，不作为推广依据；各类分别采用的来源见[当前排版参考](visual-baseline.md)。

## 调整

- 消除设置区重复的20px缩进；图标沿标题左边界，标签与滑轨可见起点对齐。
- 百分比的实际字形右边界、滑轨末端、静音开关胶囊与保存按钮右边界对齐。数值更新和拖动预览均重新测量，0%、9%、70%、100%保持同轴。
- 音量与音乐之间通过留白分组，只在静音前保留一条分隔线。滑块行72px、行间16px，静音行56px。
- 面板宽度500→480px，标题24→22px，百分比16→14px；恢复默认降为灰色文字，关闭采用中性底色，保存保留蓝色主按钮。按钮高44px，动作行保留56px以满足已有配方下限。

没有替换字体族、文字内容、行对象、状态、绑定、事件、动作或原图标字节。原540×540画布保持，390px仍为固定画布等比缩放。参考本机 `ui-ux-pro-max` 的间距、对齐与视觉层级规则，没有安装新Skill或字体。

## 实现范围

新增显式 `grouped-v3` / compiler `0.25.0`，仅支持Slider/Switch分组与独立文字按钮区；其他控件组合、Tabs和按钮行外置图标明确拒绝。需要 `raised-v1` 滑轨几何；原有显式按钮布局仍优先。它是本地候选能力，不是通用设置面板已全覆盖的声明。

旧编译器分支保持原几何与交互，新数字对齐和拖动监听只对0.25.0安装；监听在销毁时释放，无持续帧循环。Pixi复用现有组件渲染API，没有修改Component Harness。UGUI源导出对声明的Slider值节点使用 `MiddleRight`，导入器仅对标题和声明的Slider值允许显式锚点；未运行Unity编辑器，不能宣称原生导入通过。

候选工厂只接受上一轮指定的程序夹具Noto声音结果，拒绝模型来源。构建器从保存的原包生成新包，严格保持业务和图标闭包，源文件不改写，没有真实模型或媒体调用、游戏接入或GitHub推送。
